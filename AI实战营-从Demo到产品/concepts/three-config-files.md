# 三件套（SOUL.md / USER.md / AGENTS.md）

## Context

> "在创建好一个 open cloud 的时候，不管是 hermes 还是 open cloud，它都一定会有这三个文档。一个叫 SOUL.md，就定义 ai 助手的一个性格和行为准则。第二就是 USER.md……让你让小龙虾认识你，你是什么样的一个人。……还有 AGENTS.md 就是相当于是你要让你的 SOP……你要做个写作的系统，你要让他每天做什么……就是在这个 AGENTS.md 里面去写清楚。"

## 费曼一下

OpenClaw 实例的三个配置文件。SOUL.md 定"它是什么性格"（类似提示词时代"请你扮演专业文案写手"），USER.md 定"它在服务谁"，AGENTS.md 定"它按什么流程干活"（SOP）。这个概念是理解后面"两种养法"的前提——两种养法的区别恰恰就是设不设这些文档。
