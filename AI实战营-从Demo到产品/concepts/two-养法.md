# 自进化 vs 商业化定制（两种养法）

## Context

> "第一个 agent 我不会去设……soul 点 markdown……agent 点 markdown，是让他自己去成长，自己去进化，然后让他以他的一个角度和想法去做。" "第三个，那个定制化的、商业化的一个 agent……我会去给它设定 soul 点 markdown，agent 点 markdown……因为他是商业化，他一定要给他限定好场景。比如说他是销冠，那他就只能干销冠的活。"

## 费曼一下

养 agent 的两条路线，判据是目的。自进化型：不设文档、不设方向，靠长出来的机制去探索（营长的自进化 agent 和金融比赛 agent 属此类）；商业化定制型：设定 SOUL/AGENTS 等文档，把场景焊死——"销冠只能干销冠"，不能跑去搞金融。用营长的话说，前者要放心多聊，后者要限制"只能往这个方向思考"。
