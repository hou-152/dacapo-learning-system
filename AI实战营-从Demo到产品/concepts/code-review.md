# Code Review（互评 + 前置信息）

## Context

> "你们每个人，他都会去看对方做出来的这个工作流，他到底可不可以用，行不行？会有个评分，你愿不愿意去用？" "你在开始做这个工作流之前要讲为什么你想做这个东西，你做这个东西的缘由是什么，你有没有做过一些前期的一些市场调研。" "通过别人做的作品，你可以自己会对自己的作品有一些提升……可以有些壁垒。"

## 费曼一下

周循环的验收环节，标准不是"做没做完"，而是"别人愿不愿意用"。它有两个部件：前置信息（动机 + 前期市场调研）让评审者知道该怎么看；全员互评让作者照镜子——既得到反馈，也从别人的作品里学壁垒。这是把"自嗨"挡在营门外的机制。
