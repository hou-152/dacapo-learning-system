# 工程化 Agent 项目

## Context

> "你们会带走一个工程化的一个 AGENT 的项目。这个 AGENT 呢，你不管是小龙虾也好，还是说你自己 WEB CODING 的一个网站也好，还是你自己搭的一个工作流也好，都可以。你一定可以带走一个工程化的、可落地的一个 AGENT 项目。"

## 费曼一下

第一期承诺的交付物。关键修饰是"工程化"：可落地、可复用、能交付，而不是一次性跑通的 demo。载体不限（小龙虾、自建网站、自搭工作流），但必须达到工程化标准——这是"从 Demo 到产品"落到每个人头上的具体形态。
