# 词效比

## Context

> "以前有个词叫人效比，现在我更加注重叫词效比。" "如果说你能形成一套比较严谨的一个词效比的概念的话，你在后面你去做 skill，或者做一些商业化落地的时候……你跟人家说，我这个 skill 只要大概多少多少 token，那别人呢可能要几万、几十万这种 token。其实你是有很大的优势的。"

## 费曼一下

人效比的 AI 版本——用 token 消耗来衡量 agent/skill 的性价比。它的作用是把"工程化"翻译成可对比、可谈判的数字：同样的结果、更低的 token 成本，就是商业化时对企业的卖点。这也是营长说自己很少拿 Codex/Claude Code 做开发以外杂事的原因：算力要用在刀刃上。
