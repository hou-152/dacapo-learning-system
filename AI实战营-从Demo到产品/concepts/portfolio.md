# 作品集（能力 > 学历）

## Context

> "你拿得出来三个作品。不管是工作流 agent 还是什么东西都好，你有三个作品，你拿给别人去看，人家就知道你有这个能力。" "如果说你什么都没有，你跟别人说：'哎，我有这个能力，我有那个能力'，别人为什么？凭什么相信你有这个能力。" "未来能力一定是最重要的……像商汤他已经不看学历了……他现在就是看你的能力，你能不能做这个事情。"

## 费曼一下

能力证明规则：口说无凭，三个可见的作品才是"结果"。它把营内产出和黑客松连成一条线（作品集 = 能力的证据），也是"能力大于学历"主张的落点——商汤的人才计划、SK 海力士都只看能力不看学历，而能力的凭据就是拿得出手的作品。
