# harness（把 agent 管住的那套工装）

## 定义

全文的锚概念。作者说她喜欢用 harness 这个词来描述「the tooling and practices we can use to keep AI agents in check」——我们用来把 AI agent 管住的工具与实践。它不是某一个工具，而是知识库、动态上下文、自定义 linter、结构性测试、巡逻 agent 的总和。

## 为什么重要

harness 原意是套在牲口身上的挽具——既限制它乱跑，又让它的力气能被用上。用在 AI 编程上是同一个意思：不是给 agent 松绑，也不是把它关死，而是造一副装置，让它的输出始终落在你能接受的范围内。
