## 技术约束

### 单 agent 学习交互
- 学习对话保持单 agent，快速响应
- 即时反馈在同一轮内生成（不等待 subagent）
- 上下文只加载当前概念及其直接依赖（按需加载）

### Subagents 后台任务
- 索引重建、批量分析、图谱生成用 subagents
- 生成结果保存到文件，主 agent 读取文件而非等待完成
- 可以并行启动多个 subagents（如：一个重建索引，一个分析反馈）

### 充分利用已有数据
- user-utterances.jsonl (875KB) 是核心资产，优先提取洞察
- 现有课程结构（dbs-learning 格式）保持不变
- 现有概念文件格式（定义 + 相关概念）保持简洁
