# 如实所现与牌一直在你手里｜学习计划

## 终局能力

结束时能用自己的话完整解释树林「还原真实尺寸」的操作系统：识别小我加工、拆穿叙事放大、管理注意力与语言、以身体和做事重建，并能把《牌一直在你手里》的四张行动牌（输入、能量、重复、出手）接到这条主线上，对自己一件真实的困扰或目标做出可被反驳的判断与行动方案。

## 任务锚点

判断「我此刻感受到的困难/焦虑，有多少是事件的真实尺寸，有多少是小我、叙事与想象额外加上的虚构份量」，并能据此选择切断加工、重新出手的具体动作。

## 来源边界

- 主来源：《如实所现》（树林，11 个 xhtml 章节：前言 + 九章 + 后记），已冻结 SHA-256。
- 串联来源：《牌一直在你手里》（树林，5 章），存于 `01-原始素材区/牌一直在你手里.epub`，在主线「重建」部分完成后作为行动篇补充来源接入，接入时按 user_supplied 记录哈希。
- 两书均为作者个人主张写成的操作手册，涉及情绪、抑郁、焦虑的叙述按「作者主张，未外部核验」处理，不作为医学结论。

1. 你脑子里那个声音不是你：小我、昏君比喻与切断自我对话（前言 + 第一章）
2. 叙事：组织社会的工具，也是精神鸦片（第二章）
3. 那些悄悄塑造你的力量（第三章）
4. 注意力是你唯一真正的货币（第四章）
