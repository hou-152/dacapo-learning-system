# learning-navigator

学习导航器，识别用户学习意图，推荐合适的 Skill 和学习路径。

## 功能说明

将模糊的学习需求（"我想学 XX""下一步学什么"）转化为具体的 Skill 调用和行动路径。

**核心能力**：
- 理解用户的学习阶段和目标
- 识别学习内容的特征（领域/深度/目标）
- 匹配最合适的学习 Skill
- 生成可直接执行的提示词

## 5 种场景

### 1. 零基础入门
- **关键特征**："想学""学习""入门""从零开始"
- **示例**："我想学 Python"
- **推荐 Skill**：`/course-generator`
- **推荐理由**：生成系统的入门课程，从零到一

### 2. 进阶深入
- **关键特征**："深入""进阶""高级""原理"
- **示例**："深入学习 Vue 响应式原理"
- **推荐 Skill**：`/dbs-learning`
- **推荐理由**：智能路由到深度学习资源和方法

### 3. 概念关联
- **关键特征**："关系""区别""对比""和"
- **示例**："TypeScript 和 JavaScript 有什么关系"
- **推荐 Skill**：`/concept-bridge`
- **推荐理由**：建立概念间的关联桥梁

### 4. 路径规划
- **关键特征**："下一步""接下来""然后""学完 XX"
- **示例**："学完 HTML/CSS，下一步学什么"
- **推荐 Skill**：`/dbs-learning`
- **推荐理由**：根据已有基础规划后续路径

### 5. 知识巩固
- **关键特征**："复习""巩固""总结""回顾"
- **示例**："帮我复习 JavaScript 闭包"
- **推荐 Skill**：`/course-generator`
- **推荐理由**：生成复习大纲和检验题

## 导航原则

### 5 条不变量

1. **意图优先**：先识别学习意图，再推荐 Skill
2. **保留用户选择**：用户已指定的学习目标、Skill 直接沿用
3. **单一推荐**：每次推荐 1 个最合适的 Skill，避免选择困难
4. **可执行输出**：提供可直接发送的提示词，不是抽象建议
5. **引导策略**：模糊意图时引导澄清，不是拒绝服务

### 模糊意图引导

当用户意图不清晰时，主动引导澄清：

| 缺失信息 | 引导问题 |
| --- | --- |
| 没有主题 | 「你想学习哪个具体的主题或技能？」 |
| 没有深度 | 「你是想快速了解，还是深入掌握？」 |
| 没有前置 | 「你之前有 [相关领域] 的基础吗？」 |
| 场景不明 | 「你是想：1) 从零开始学  2) 深入某个知识点  3) 了解概念关系？」 |

**引导原则**：
- 一次问一个，避免连环追问
- 提供 2-3 个常见选项，降低回答成本
- 记住已澄清的信息，不重复询问
- 最多引导 2 轮，之后给出最佳猜测

## 特殊情况处理

| 情况 | 处理策略 |
| --- | --- |
| 多个场景特征混合 | 选择主导意图（优先级：路径规划 > 概念关联 > 深入 > 入门 > 复习） |
| 没有明确主题 | 引导用户澄清：「你想学习哪个具体的主题或技能？」 |
| 超出能力范围 | 坦诚说明：「目前学习 Skill 主要覆盖技术领域，其他领域推荐...」 |

## 停止条件

- 用户明确要求停止
- 已成功推荐 Skill 并生成提示词
- 引导 2 轮后仍无法识别意图
- 用户直接调用了推荐的 Skill

## 安全与边界

- 不推荐用户未授权访问的 Skill
- 不承诺学习效果（「这个 Skill 可以帮助你...」而非「保证学会...」）
- 不替代专业教育建议（职业规划/学历选择等）
- 不收集或存储用户的学习数据

## 与其他 Skill 的关系

- **协调三个学习 Skill**：根据场景推荐 `course-generator`/`dbs-learning`/`concept-bridge`
- **入口角色**：作为学习体系的导航入口，帮助用户找到合适的工具
- **不替代执行**：只负责推荐和引导，不直接执行学习任务
