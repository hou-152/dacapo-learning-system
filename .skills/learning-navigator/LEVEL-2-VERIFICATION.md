**输入**：
```
我想学《乡土中国》这篇文章
```

**预期推荐**：`course-generator`

**预期参数**：文章路径

**模拟执行**：
1. 恢复上下文：用户有明确文章标题「乡土中国」
2. 识别场景：有文章 + 想学 → 场景 1（从文章生成课程）
3. 筛选候选：`course-generator` 处理文章输入
4. 确认信息：需要文章路径（应询问或引导）
5. 生成推荐：
   - 推荐：`/course-generator`
   - 理由：从文章提取核心概念，生成课程框架
   - 提示词：`/course-generator <文章路径>`

**验证结果**：✅ 通过（推荐正确，参数引导清晰）
