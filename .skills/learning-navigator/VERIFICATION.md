## 本地使用方式

### 方式 1：直接调用

在学习仓库目录下：
```bash
/learning-navigator
```

然后描述学习需求。

### 方式 2：带上下文调用

```
我想学《乡土中国》
/learning-navigator
```

导航器会从对话提取信息并推荐。

---

## 核心能力

1. **场景识别**：从对话恢复用户意图，判断 5 种场景
2. **候选筛选**：根据输入材料（文章/课程/概念/无）选择 skill
3. **参数引导**：缺失必要信息时，引导用户补充
4. **提示词生成**：生成可直接执行的 skill 调用
5. **边界清晰**：识别非学习场景，不强行推荐

---

## 仍未验证的风险

1. **边缘场景**：用户同时提到多个学习目标
2. **参数变体**：课程路径的不同表达方式
3. **前置依赖**：用户想学习但课程不存在
4. **概念库为空**：场景 5（基于掌握度推荐）无数据时的表现

**建议**：实际使用中遇到这些情况时，根据反馈优化。
