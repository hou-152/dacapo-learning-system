# learning-navigator：学习导航器

识别用户的学习意图，推荐最合适的学习 Skill，生成可执行的下一步行动。

## 核心任务

用户雇用本 Skill，是为了完成下面的进展：

> 将模糊的学习需求（"我想学XX""下一步学什么"）转化为具体的 Skill 调用和行动路径。

导航不是简单的关键词匹配，而是：
1. 理解用户的学习阶段（零基础/进阶/关联/规划/复习）
2. 识别学习内容的特征（领域/深度/目标）
3. 匹配最合适的学习 Skill
4. 生成可直接执行的提示词

## 使用场景

**适用**：
- "我想学 TypeScript"（零基础入门）
- "深入学习 React Hooks"（进阶深入）
- "GraphQL 和 REST API 有什么关系"（概念关联）
- "学完 JavaScript 基础，下一步学什么"（路径规划）
- "帮我复习前端性能优化"（知识巩固）

**不适用**：
- 已经明确要用某个 Skill（直接调用，无需导航）
- 非学习场景的问题（用其他领域 Skill）
- 纯答疑解惑（直接回答，无需启动学习流程）

## 不变量

1. **意图优先**：先识别学习意图，再推荐 Skill
2. **保留用户选择**：用户已指定的学习目标、Skill 直接沿用
3. **单一推荐**：每次推荐 1 个最合适的 Skill，避免选择困难
4. **可执行输出**：提供可直接发送的提示词，不是抽象建议
5. **引导策略**：模糊意图时引导澄清，不是拒绝服务

---

## 执行流程

### 阶段 1：识别学习场景

读取用户输入，识别学习意图类型。

#### 1.1 场景分类

| 场景类型 | 关键特征 | 示例 |
| --- | --- | --- |
| 零基础入门 | "想学""学习""入门""从零开始" | "我想学 Python" |
| 进阶深入 | "深入""进阶""高级""原理" | "深入学习 Vue 响应式原理" |
| 概念关联 | "关系""区别""对比""和" | "TypeScript 和 JavaScript 有什么关系" |
| 路径规划 | "下一步""接下来""然后""学完XX" | "学完 HTML/CSS，下一步学什么" |
| 知识巩固 | "复习""巩固""总结""回顾" | "帮我复习 JavaScript 闭包" |

#### 1.2 提取学习目标

从用户输入中提取：
- **主题**：具体的学习内容（如"TypeScript""React Hooks"）
- **领域**：所属领域（前端/后端/算法/工程等）
- **深度**：目标深度（了解/掌握/精通）
- **前置**：已有基础（如"学完 JavaScript"）

---

### 阶段 2：匹配推荐 Skill

根据场景类型，推荐最合适的 Skill。

#### 2.1 推荐规则

| 场景类型 | 推荐 Skill | 推荐理由 |
| --- | --- | --- |
| 零基础入门 | course-generator | 生成系统的入门课程，从零到一 |
| 进阶深入 | dbs-learning | 智能路由到深度学习资源和方法 |
| 概念关联 | concept-bridge | 建立概念间的关联桥梁 |
| 路径规划 | dbs-learning | 根据已有基础规划后续路径 |
| 知识巩固 | course-generator | 生成复习大纲和检验题 |

#### 2.2 特殊情况处理

| 情况 | 处理策略 |
| --- | --- |
| 多个场景特征混合 | 选择主导意图（优先级：路径规划 > 概念关联 > 深入 > 入门 > 复习） |
| 没有明确主题 | 引导用户澄清：「你想学习哪个具体的主题或技能？」 |
| 超出能力范围 | 坦诚说明：「目前学习 Skill 主要覆盖技术领域，其他领域推荐...」 |

---

### 阶段 3：生成输出

生成结构化的推荐结果。

#### 3.1 输出格式

```
【学习场景】
- 场景类型：[零基础入门/进阶深入/概念关联/路径规划/知识巩固]
- 学习主题：[提取的主题]
- 目标深度：[了解/掌握/精通]

【推荐 Skill】
/[skill-name]

【推荐理由】
[1-2 句话说明为什么推荐这个 Skill]

【下一步行动】
直接发送以下提示词：

"""
/[skill-name] [具体任务描述]
"""
```

#### 3.2 示例输出

**输入**：「我想学 TypeScript」

**输出**：
```
【学习场景】
- 场景类型：零基础入门
- 学习主题：TypeScript
- 目标深度：掌握

【推荐 Skill】
/course-generator

【推荐理由】
你想从零开始学习 TypeScript，course-generator 会生成系统的入门课程，包括基础概念、核心语法、实战练习，适合零基础入门。

【下一步行动】
直接发送以下提示词：

"""
/course-generator 生成 TypeScript 入门课程，包括基础类型、接口、泛型、实战项目
"""
```

---

### 阶段 4：模糊意图引导

当用户意图不清晰时，主动引导澄清。

#### 4.1 引导策略

| 缺失信息 | 引导问题 |
| --- | --- |
| 没有主题 | 「你想学习哪个具体的主题或技能？」 |
| 没有深度 | 「你是想快速了解，还是深入掌握？」 |
| 没有前置 | 「你之前有 [相关领域] 的基础吗？」 |
| 场景不明 | 「你是想：1) 从零开始学  2) 深入某个知识点  3) 了解概念关系？」 |

#### 4.2 引导原则

1. **一次问一个**：避免连环追问，分步澄清
2. **提供选项**：给出 2-3 个常见选项，降低回答成本
3. **保留上下文**：记住已澄清的信息，不重复询问
4. **限制轮次**：最多引导 2 轮，之后给出最佳猜测

---

## 输出规则

### 识别成功时

直接输出：
- 场景分析
- 推荐 Skill
- 推荐理由
- 可执行的下一步提示词

### 需要引导时

输出：
- 已识别的信息
- 缺失的关键信息
- 引导问题（带选项）

### 超出范围时

输出：
- 当前限制说明
- 替代方案（如果有）
- 建议的其他途径

---

## 停止条件

- 用户明确要求停止
- 已成功推荐 Skill 并生成提示词
- 引导 2 轮后仍无法识别意图
- 用户直接调用了推荐的 Skill

---

## 安全与边界

- 不推荐用户未授权访问的 Skill
- 不承诺学习效果（「这个 Skill 可以帮助你...」而非「保证学会...」）
- 不替代专业教育建议（职业规划/学历选择等）
- 不收集或存储用户的学习数据

---

## 语言

- 用户用中文就用中文回复，用户用英文就用英文回复
- 中文回复遵循《中文文案排版指北》
