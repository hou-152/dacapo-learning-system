# dbs-learning

交互式学习 AI，把课题拆成连续学习文章，并根据用户反馈调整后续深度、角度和节奏。

## 功能说明

维护自适应学习梯度，每一篇文章都接住用户上一轮的理解状态和兴趣方向，再推进下一步。

**核心能力**：
- 将课题拆分成连续学习文章
- 根据用户反馈调整教学深度和角度
- 自动管理学习进度和文件组织
- 支持基于项目知识基础的个性化起点

## 使用场景

- 系统学习一个主题
- 让 AI 连续写课
- 根据上一篇反馈生成下一篇
- 把某个方法论拆成课程

## 触发信号

用户出现以下意图时，进入本 Skill：
- 想系统学习一个主题
- 提到「下一篇」「学习反馈」「继续学」「带我学」
- 想把某个方法论拆成课程

## 文件存放规则

### 目录优先级

1. 用户明确指定目录：使用用户指定目录
2. 当前目录是项目目录：使用 `当前目录/学习课题/{课题名}/`
3. 当前目录是泛目录或系统目录：使用 `~/Documents/dbskill-learning/{课题名}/`

### 课题目录结构

```
{课题名}/
├── 00-学习计划.md
├── 01.md
├── 02.md
├── 03.md
├── .concepts.json       # 章节概念关联元数据（可选）
└── assets/
```

## 学习梯度调整

根据用户反馈自动调整下一篇的处理方式：

| 用户反馈信号 | 下一篇处理方式 |
|---|---|
| 没看懂、概念混乱、问题很多 | 降低抽象度，补例子，放慢节奏 |
| 看懂了但觉得没意思 | 换切入角度，连接用户真实问题 |
| 看懂了并提出应用问题 | 增加案例、判断方法和使用场景 |
| 明显掌握了 | 提高概念密度，进入下一层 |
| 提出具体问题 | 优先回应问题，再推进课程 |
| 反馈很少 | 保持当前难度，小步推进 |

## 概念联想机制

当课题目录中存在 `.concepts.json` 时，自动在文章开头展示：
- 本章核心概念（wikilink 格式）
- 相关概念（relevance > 0.6，按相关度降序）

这一机制将学习内容与概念库连接，支持后续的概念桥接和路径推荐。

## 知识基础确认

对于新课题，如果当前目录是项目目录，会轻量检索项目中与课题相关的内容，并询问用户：

1. 基于这些知识继续，减少基础讲解
2. 暂时忽略本地知识，从零建立完整框架
3. 只使用指定的文件作为知识基础

知识基础一经确认，记录在 `00-学习计划.md` 中，后续文章直接继承，不重复询问。

## 使用示例

```bash
# 开始新课题
/dbs-learning
> 你想系统学习哪个课题？

# 继续已有课题
/dbs-learning
> 继续下一篇

# 基于项目知识开始
/dbs-learning
> 带我学奥派经济学（按项目来）
```

## 与其他 Skill 的关系

- 可读取 `/course-generator` 生成的 `.concepts.json` 展示相关概念
- 可与 `/concept-bridge` 配合追踪学习进度
- 生成的文章可作为 `/concept-learning` 的输入源
