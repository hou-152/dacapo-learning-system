# 经验库

## Context

> "把他的经验库也很重要，就他所有的经验库才能组成他真正一个金融小龙虾的一个点。" "你看首先冲高不追，这都是他每次比赛当中就是出现失误的时候，他总结出来的一些经验，这些就是他自己进化的一个点。" "success 不等于执行。" "crown 的 prompt 要精简超长 prompts 会导致超时 error 任务根本没办法执行。"

## 费曼一下

金融小龙虾自进化的证据本体。经验库里存的不是策略，而是它自己踩坑踩出来的教训：冲高不追、开赛首日太保守、开盘 30 分钟不追涨、下跌途中不接盘、板块轮动要快；系统层面还有「自动化交易和 API 交叉打架」「多个决策者打架」「超长 prompt 导致超时」「success 不等于执行」这类工程教训。营长的点睛之笔是：雪崩不可怕，「雪崩有个好处，他会记经验」——经验库把每一次失败变成下次的起点，这就是「自进化」在文件系统里的样子。
