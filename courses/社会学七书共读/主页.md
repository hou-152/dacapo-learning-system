# 社会学七书共读

## 简介

把七本书的分工讲清，并发出第一个工具：「困境 → 议题」改写器。后面每一站都从你自己的一个真实麻烦出发，用这个工具换主语，再进对应的那本书。

七本书其实是一张地图的七个区块。一本一本单独啃，读完攒下一堆书名；按问题串起来读，每本书都在回答同一个大问题的一小块：**一个人的一生，有多少是自己选的，有多少是出生时就被排好的？**

阅读顺序按站点走：眼睛（01）→ 底图（乡土）→ 结构（分层）→ 家庭（生育）→ 性别 → 身份 → 思想地图 → 收尾。
