### 二、你问的三件事

**rerank 是什么**：不是向量匹配。四路检索各交一批候选之后，用一个「交叉编码器」模型逐条给（问题，候选）打分再排序——比只看向量更准，也更贵，所以只用在最后一步。整条链是：四路并跑 → 合并（倒数排名融合）→ 重排 → 按 token 预算裁剪。

**bank 是不是 embedding 的向量空间**：不是。bank 是**记忆库**（逻辑分区，按 `bank_id` 分：工作一本、私人一本），里面存的是拆好的记忆单元——实体、关系、时间、向量都在里面。向量空间只是其中一种索引，不是库本身。

**置信度从哪来**：目前看是 **LLM 在 reflect 时给的**——生成或更新观点与观察时顺带写一个置信度，属于模型自报，不是统计校准出来的概率。你的直觉对上了：这跟 Jev 那类「输出类型化判断＋置信度」的模型是两回事——一个靠训练出来的判别头，一个靠通用 LLM 自报。这条正好是 05 篇要拆的点（自报 vs 校准）。

顺带纠一处小记：embedding 的维度是配置项（常见 768～3072；你记的「三千多」对得上 3072 这一档），不是每个词配三千个坐标。

### 四、三条路怎么选

**A 云端（最快）**：注册 Hindsight Cloud，拿 API key，客户端直连 `https://api.hindsight.vectorize.io`。不装任何东西；前提是能访问该域名，数据在云端。

**B pip 嵌入式（推荐先试）**：你这台机器已经具备条件——

```bash
uv venv ~/.venvs/hindsight --python 3.12
source ~/.venvs/hindsight/bin/activate
uv pip install hindsight-all
```

跑通的最小脚本（key 在你自己终端里设，不写进文件）：

```python
import os
from hindsight import HindsightServer, HindsightClient

with HindsightServer(llm_provider="openai", llm_model="gpt-5-mini",
                     llm_api_key=os.environ["OPENAI_API_KEY"]) as server:
    c = HindsightClient(base_url=server.url)
    c.retain(bank_id="trial", content="Alice works at Google")
    print(c.recall(bank_id="trial", query="Where does Alice work?"))
```

跑通之后，可以再补一次 `reflect`，观察它会不会自己生出观点或观察。

**C Docker**：本机没有 Docker，先跳过；需要时再装 Docker Desktop。
