# Hindsight：会学习的 agent 记忆｜学习计划

## 学习目标

学完这门课，你手上应该多出四个可检查的动作：

1. 说出 Hindsight 押的判断（agent 的毛病大多源于缺记忆）和它相对「基础向量检索」的差别（四类记忆）。
2. 在自己的机器或云端跑通一次 `retain → recall → reflect`（哪种方式都行），留下命令与输出记录。
3. 按显影与退役判据拆一遍它的性能声称（LongMemEval 91.4% 与复现声明），写清哪几行可信到哪一步。
4. 给「要不要接进我的系统」出一个判断：接或不接、接哪一层、维护面多出什么；写成一句话 ＋ 一条反面证据。

## 学习路径

1. **01 概览**：它押的判断、四类记忆、三个操作、性能声称怎么读。
2. **02 翻成人话（降速）**：一句话拆成什么、bank、四路检索与重排；补上三条答案，澄清「不用训模型」。
3. **03 跑一次**：Docker／嵌入式 Python／MCP，任选最短路径，留下命令与输出。
4. **04 reflect 拆解**：观点与观察怎么生成、置信度怎么变；对照你的工作台（回填／疑问）。
5. **05 评测与论文**：LongMemEval、复现声明、arXiv 论文的可读部分。
6. **06 落地判断**：接哪一层、维护面、与 ai-memory 的分工；收束。
