# Hindsight 安装记录（2026-09-26）

本机实测；环境：macOS 26.3（arm64）、未装 Docker、未装 Homebrew、系统 Python 3.9、uv 0.12.5（自带 Python 3.12.13）。

## 一、最终可用配置（精简版，不装 torch）

```bash
uv venv ~/.venvs/hindsight --python 3.12
uv pip install --python ~/.venvs/hindsight/bin/python "hindsight-api-slim[embedded-db,local-onnx]" hindsight-client
```

- 装了什么：`hindsight-api-slim 0.10.1`（含 embedded-db=pg0-embedded、local-onnx=onnxruntime+transformers+tokenizers）、`hindsight-client 0.10.1`、`hindsight-embed 0.10.1`。
- 没有装什么：完整 `hindsight-all` 会拖 torch / sentence-transformers / mlx（数 GB），本机用 onnx 嵌入 + rrf 重排替代。
- 嵌入模型：`intfloat/multilingual-e5-small`（onnx/model.onnx，470MB，已缓存在 `~/.cache/huggingface`；中文可用）。

## 二、遇到的坑与修法

1. **pg0 内置 Postgres 缺 OpenSSL**：报 `Library not loaded: /opt/homebrew/opt/openssl@3/lib/libssl.3.dylib`（本机没有 Homebrew）。
   修法：下载 Homebrew 的 openssl@3 bottle（arm64_tahoe，3.6.4）解到 `~/.local/openssl3/`，再用 `install_name_tool` 把 `~/.pg0` 下 10 个文件里指向 `/opt/homebrew/...` 的两条引用改成该目录，并 `codesign --force --sign -` 重新签名；另把 bottle 里 `libssl.3.dylib` 对 libcrypto 的 `@@HOMEBREW_CELLAR@@` 占位路径也改成绝对路径。
2. **首启超时**：ONNX 模型首次下载超过默认 300s；先手动 `snapshot_download` 拉齐缓存，并把 `HINDSIGHT_API_MODEL_INIT_TIMEOUT` 调到 1800。

## 三、启动（当前正在运行）

```bash
export DYLD_LIBRARY_PATH=$HOME/.local/openssl3/openssl@3/3.6.4/lib
export HINDSIGHT_API_LLM_PROVIDER=deepseek
export HINDSIGHT_API_LLM_API_KEY=$DEEPSEEK_API_KEY      # 从环境读取，不写入文件
export HINDSIGHT_API_EMBEDDINGS_PROVIDER=onnx
export HINDSIGHT_API_RERANKER_PROVIDER=rrf
~/.venvs/hindsight/bin/hindsight-api --host 127.0.0.1 --port 8888
```

- REST API：http://127.0.0.1:8888 ；MCP：http://127.0.0.1:8888/mcp/ 。
- 停止：`pkill -f hindsight-api`。
