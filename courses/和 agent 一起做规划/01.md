# 01｜你和 agent 之间，那件中间物有多厚

> 材料：260921 期内参选材六篇（在 `assets/260921-选材/`），这一篇用 15 号 Maggie Appleton《和 agent 一起做规划，缺的是更厚的界面和共用的中间物》。
> 标【原文】的句子引自内参 15 号正文，那是内参对 Appleton 一文的转述与摘句，英文原文本次未取（缺口记在 `00-学习计划.md`）。
> 标【你】的句子来自你自己的课程记录与协议，不是我的推测。其余文字都是我用自己的话写的。
> 这一篇刻意写短，理由在第四节的末尾。

## 这一篇要解决的问题

你在《多 Agent 编排 2W2H》里拆过一件东西：张三把调研交给王麻子，中间要有交付物、通道、触发、验收、例外。Appleton 讲的是一模一样的机器，用在人和 agent 之间，只是她多问了一句你当时没问的话——这件中间物，现在为谁优化。

## 正文

### 一、先看她在骂什么

【原文】场景是这样的：你在自己惯用的 CLI 或桌面应用里，一个人，打开 plan mode 或挂上一个 skill，然后开始回答 40 道选择题。大约在第八题你就累了，开始一律选 A——那个标着「推荐」的选项。

问完之后，agent 丢给你一大墙 Markdown，再问一句：批准这个计划吗，是或否。

她的判断很直白：这不是一个好的流程。理由分三层，一层比一层深。

### 二、三层诊断

**第一层：计划是一段规划者自己不会走的旅程。**

她借的是 Suchman 1987 年那本书里的人类学材料：楚克航海者不提前画航线，只带一个目标出海，靠读风、浪、洋流和飞鸟随时调整；欧洲航海者先在地图上推出航线，出海后努力保持在航线上。

【原文】计划最好被看作临时行动的一种弱资源。

**第二层：规划者和旅行者不是同一个存在。**

这一层是你和 agent 规划特有的：人不上路，上路的只有 agent。于是所有重要决策被迫提前做完，而 agent 在路上遇到岔口时，身边没有能做判断题的人。

**第三层：两个世界互不可读。**

她引施乐复印机那项研究：机器只看得见按钮被按下、纸盒被打开，看不见人的犹豫、争论和手势；人只看得见屏幕上打出来的字。她说双方像隔着一个钥匙孔看对方。

数字放在一起更直观：人一分钟大约读 240 词，agent 一分钟能写 4500 词，差 19 倍。于是你整天做的事，是在一个密度远超消化能力的界面里做艰难抉择——许多人说和 agent 一起工作让人精疲力竭，她认为原因在这里。

### 三、她的解法：边界物

边界物这个词来自 Star 和 Griesemer 1989 年那篇论文，讲伯克利脊椎动物博物馆怎么把生物学家、捕猎者、出资人和大学管理者凑到一起干活。让他们能协作的是标本、标签、田野笔记、图纸和地图——同一件东西，在不同人的世界里被略微不同地使用，但大家都指着它说话。

Appleton 把这条搬过来：你和 agent 之间现在也有边界物，就是计划、提示词、skill、`AGENT.md` 这类文件。

【原文】它们主要是按 agent 看世界的方式设计的，优化的是 agent 的表现。

「更厚的界面」于是有了具体含义：用 agent 相对廉价、近乎无限的劳动，去造一层给人用的翻译，让被优先服务的那一方是人。

### 四、把你自己那套搬过来

【你】05 篇里，你给张三 → 王麻子写过这套接口：触发是「当张三收到的东西对王麻子有用的时候」，交付物是「调研报告」，通道是「短时间之内直接传」，验收是王麻子「确认是真的有用」，例外是「觉得没用，那就不用了」。

那五项就是边界物的参数表。Appleton 多加的是第六项：**这件中间物在为谁优化**。你当时的验收标准写成「有用」，而这句话对张三和对王麻子来说，含义并不一样。

拿你的系统盘一遍：

| 边界物 | 现在主要为谁优化 | 一处证据 |
|---|---|---|
| `AGENTS.md` / `CONTEXT.md` | 下一次会话的 agent | 它们是写给启动时的 agent 读的 |
| `02-课程真源/INDEX.md` | 机器 | 由脚本重建，人不手工维护 |
| 每篇末尾的「学习反馈」区 | 我，也就是下一篇的输入方 | 留给你的是一段自由文字 |
| `docs/回填打卡协议.md` | 双方 | 格式固定，人和 AI 都照它记账 |
| 这份选材 `assets/260921-选材/` | 偏 agent | 六篇全文加索引，仍然是一堵整理得很整齐的墙 |

最后两行的意思是：选材是我整理的，它对你是否好用，得看你的实际动作。这一篇写得短，也是为了不给你再添一堵墙。

### 五、本篇最小动作

十分钟，三行，写在下面的「学习反馈」里：

1. 从上面那张表里挑一件你最近一周真读过的东西。
2. 写一句：它上一次让你改主意，是什么时候？（想不起来，说明它目前没在为你优化。）
3. 用她的第一问回答一次：我在哪一处，把人暴露给了 agent 看世界的方式？

## 小结

1. 她在骂的那套流程你也熟：一堆选择题，加一墙 Markdown，最后一句「批准吗」。
2. 三层诊断分别是计划被当成脚本、规划者与旅行者分离、两个世界互不可读。
3. 她的解法是把中间物做厚，判断标准只有一条：它现在为谁优化。
4. 你已经有这套机器的半张图纸，也就是张三 → 王麻子那五项接口，差的是第六项。
5. 这门课剩下的五篇，围着同一个追问转：判断交出去之后，代价落在谁头上。02／04／18 给三种方向的答案，01 给一条最硬的边界。06 篇会把它们并排摆一次。
