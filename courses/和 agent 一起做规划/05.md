# 05｜课不是没人看，是没人问

> 材料：本课自己的痕迹（`02-课程真源/和 agent 一起做规划/`、`04-用户原话与费曼/`）、选材 15 号（Appleton）、以及附件 `assets/demo-边界物判据.html`。
> 标【你】的是你本轮原话；标【我】的是我的判断；其余文字是我自己写的。

## 这一篇要解决的问题

你否掉了我上节课的一个指标，又给了一个更要紧的数字。这一篇先接下那条纠错，再回答「为什么没走默认设置、为什么还费 token」，最后把你那三段设计用课程里现成的判据过一遍。

## 正文

### 一、先撤回一个指标

【你】「你那个 log 的那个东西老早就没用了呀。因为他自动化很多东西，他是没法去铺开的。」

【我】接受。`learner-log.md` 只在 3 门带 hash 后缀的课上出现过，那条管道依赖入口系统发的 request id，铺不到别处。拿它当整体指标不成立，04 里那个「3 门」应当降级成一条废弃管道的余额，不当成你的反馈留存率。

你指出的另一半更要紧：本课四轮反馈全在对话里，文件里一个字也没有。这一篇之前，我已经把 01—04 的反馈逐字回填进各篇文末，带来源标记，注明「用户未直接写入本文件」。

### 二、为什么没走默认设置

dbs-learning 的流程原文是：找到序号最大的那一篇，**阅读该文章末尾的「学习反馈」**。它假设反馈已经在文件里，没有定义「反馈还在对话里」该怎么办。

现存唯一的自动通道是：`learner-log.md` 里的 `DBS_USER_RESPONSE` 标记 → `08-脚本与工具/extract_marked_user_responses.py` → `04-用户原话与费曼/user-utterances.jsonl`。这条通道要反馈先经过入口系统才拿得到编号，所以它只覆盖到 3 门课，库里能读到日期的条目全在 7 月中旬。

【我】所以不是设置没生效，是这条链从来没接上：对话里的反馈没有入口。此前做回填的一直是人肉——我把它摘要进学习计划的「反馈摘要」，那是转述，不是原料。

Token 那一问也算得出来。每轮开始我要读课程文件、skill 文本与项目规则，本课四篇加选材索引约 8 万字符。在没有回填的情况下这笔开销是双付：先为读付费，再为丢失付费。

### 三、60%—80% 这个数字比我的更能用

【你】「我自己交互式学习的课，大概有 60% 甚至 70%、80% 后面都没再去翻过。打不打开，取决于我后续有没有产生新疑问。资料是有的，但疑问往往找不到。」

【我】这句话把「回访率低」从资料问题改判成了疑问问题。资料多不影响打开，疑问才影响。它和课程里已经装好的两件工具对得上：

- 她的结构层说的是同一件事：你读不懂 agent 内部那本账，只能靠外部回执去撞。
- 你账本里的开环报警（做完没下文、下轮不引用）算的是同一类漏。60%—80% 就是这个开环率的一个估计值。

你自己在 135 项目里定过一条同向的硬边界：不假设学习者知道自己缺什么〔来自记忆摘要，未回源核〕。落到工具上，就变成缺口由机器发现、人只负责裁决。这一条和你「疑问找不到」的抱怨是同一枚硬币。

### 四、你那三段设计，过一遍判据

| 你写的 | 它要成立必须满足 | 现在的风险 |
|---|---|---|
| 1 输入与清洗（对话区／文档／文件夹里找反馈，补上下文、溯源、对照、清矛盾） | **你不配合它也能工作** | 若需要你手动粘贴，回填率就等于你的勤快程度；四轮都没写已经是一次实测 |
| 2 自动化产出闭环（接 content-system 与内容工厂，做成费曼闭环） | 出口必须是你的一手判断 | 按你的账本，整理稿是复述，负收益。验收标准可以写成一句：产出里能数出几条你自己的一手判断 |
| 3 辅助材料定位（词汇表管溯源与清矛盾；手写笔记当链路图） | 词汇表要过第三条判据：改一个词，下游引用跟着改 | 做不到，它仍旧是命名而不是中间物 |

第三段里那条「手写笔记当链路图」已经有现成证据：【你】「我在侧边栏看了一下它的引用关系」——图在这一轮里已经承担了实际工作，它不是装饰。

### 五、本篇最小动作

附件是一份按 ELI5 那句话做的 demo：`assets/demo-边界物判据.html`（大图、字少、能动手，双击用浏览器打开）。它把三条判据做成了可以点的东西，第三条留了输入框，空着不答，结论就被封顶在「入场券」。

做三件事：

1. 用它判三件你自己的中间物，各生成一张收据。
2. 把三张收据粘回这篇的「学习反馈」区。
3. 如果三件里有哪一件被判成「更好看的墙」，写一句：它当初是为谁做的。

（这份 demo 本身也接受同一套判据的检查。它现在满足前两条；第三条要看你用它之后，下一篇会不会不一样。）

## 小结

1. `learner-log` 那条管道铺不开，那个指标撤回；缺口落在另一处：对话里的反馈没有入口。
2. 回填此前一直是人肉做的，我这一轮把 01—04 逐字补进各篇文末，并标了来源。
3. 默认设置没生效的原因很具体：流程假设反馈已经写在文件里。
4. 60%—80% 说明变量是疑问，不是资料；疑问要靠「缺口被发现」来产生。
5. 你三段设计里最硬的一条是第 1 段的验收：你不配合它也能工作。
