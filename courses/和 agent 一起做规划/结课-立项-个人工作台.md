## 二、目标卡

目标已经可以执行。

- **交付物**：一个最小工作台的第一版，跑通一条端到端链——对话里的反馈 → 打标 → 写回对应文章末尾的「学习反馈」区 → 被下一篇引用。
- **使用对象**：用户本人（个人工作台，不是对外产品）。
- **范围与规格**：只做三件事，其余不做。
  1. **画布**：Obsidian 形态，指向 `交互式学习真源/02-课程真源/`（占位表与各篇可见、可点、可改）。
  2. **分类器**：jev 或同类小模型，输入为一段对话反馈原文，输出固定四字段——属于哪一篇／属于哪一类判断（分类·生成·裁决）／置信度／要不要用户裁决。
  3. **写入动作**：把打标结果落到对应文章末尾反馈区，沿用 `BACKFILLED_USER_FEEDBACK` 区块格式。
- **完成条件**（任一不成立即未完成）：
  - [ ] 端到端跑通一次，且写入的那条反馈在下一篇里被真实引用（人工可核）；
  - [ ] 三周内，占位表里被触发取用并结清的条目 ≥ 3；
  - [ ] 反面证据：画布打开次数上升、占位触发为 0 → 判定为「更好看的白板」，回到第 2 条重做。
- **约束**：核心 idea 由用户自己推敲；代码可外包且不介意质量（「有就改呗」）；该用就用开源；不引入私有格式；密钥不进课程真源。
- **当前假设**（低风险、可纠正）：
  - 底座组合 = Paseo 管 Agent 编排 + Pi 管模型接入 + Obsidian 管画布与文件；不新建独立壳。
  - 「该废就废」指先前的 Flet 版《个人工作台》外壳不再续建，只按第三节取件。
  - jev 第一版只接打标，不接写句子。
- **下一步（一句）**：装 Paseo + Pi 并跑通一个最小会话，同时用 Obsidian 打开课程目录，然后把 demo 的四步回路接到「写入动作」上，端到端走一遍。
