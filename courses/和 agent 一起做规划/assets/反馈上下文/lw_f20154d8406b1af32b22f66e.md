# 学习反馈补上下文：01 篇

## 这条反馈在哪、属于哪一轮

反馈来自「和 agent 一起做规划」01 篇之后的一轮对话，原话存放于 [[01-交互式学习/04-用户原话与费曼/工作台视图/lw_f20154d8406b1af32b22f66e.md]]。学习计划「反馈摘要」的 01 行把它记成几件事：自述看懂、摘走「计划最好被看作临时行动的一种弱资源」、用自己的两个例子重讲诊断、追问边界物是否近似词汇表、把两个世界不可互读归因为成本高 [[01-交互式学习/02-课程真源/和 agent 一起做规划/00-学习计划.md]]。

回填口径：01—04 的用户原话已逐字回填进各篇文章末尾的「学习反馈」区（带 `BACKFILLED_USER_FEEDBACK` 来源标记），计划本身只留摘要与判断 [[01-交互式学习/02-课程真源/和 agent 一起做规划/00-学习计划.md]]。以下引用用户原话一律逐字，未做替换。

## 与课程的直接联系

1. **02 篇是这条反馈的直接产物。** 02 篇开篇逐字引用了反馈里的 PRD／视频那一段，并给出评价「这句话比原文更好用：它把『计划』切成了两类」——能在纸上做完的一类（PRD 拆 plans）与只有上路才知道的一类（视频能不能火）[[01-交互式学习/02-课程真源/和 agent 一起做规划/02.md]]。反馈摘走的那句「计划最好被看作临时行动的一种弱资源」是 01 篇正文里的【原文】句，01 篇声明它引自内参对 Appleton 的转述、英文原文未取 [[01-交互式学习/02-课程真源/和 agent 一起做规划/01.md]]。
2. **「成本太高」这一层被接住，又被补了一层。** 02 篇把黑客松那条（「要想真正读懂 Agent 在做什么，你得懂前端、后端、SQL、Java、Python 等各种各样的东西，而且它生成得又快」）判给成本层，另立结构层：施乐复印机的「钥匙孔」，加上【原文】「可解释性还没被解决」；该层与时间、成本无关，两层处方不同——成本层配更厚的界面，结构层配外部回执 [[01-交互式学习/02-课程真源/和 agent 一起做规划/02.md]]。
3. **词汇表那一问有正式回答。** 02 篇用三条判据（两边都能指着它说话／两边各自用它做不同的事／改动它两边的工作都跟着变）来判：词汇表满足前两条，第三条最弱，只算「入场券」；并把 `CONTEXT.md` 末尾 Language 一节当成现成一例，附一句「如果你指的其实是别的东西，纠我一句」[[01-交互式学习/02-课程真源/和 agent 一起做规划/02.md]]。
4. **一物多名／一名多物被拆开。** 02 篇区分「一物多名：找不到同一件东西（自证预言／反身性）」与「一名多物：以为找到了同一件东西（反身性在索罗斯与常人方法学）」，并写下判断「自证预言更像反身性里自我强化那一支的特例」；同篇声明这两条原文都没读、属二手概述，要当课题就记进显影台账 [[01-交互式学习/02-课程真源/和 agent 一起做规划/02.md]]。计划的显影台账确实各留一条，断点均写「原文未读」[[01-交互式学习/02-课程真源/和 agent 一起做规划/00-学习计划.md]]。
5. **这条反馈给占位表贡献了两条。** W-0921-1（来源标「01 反馈」）与 W-0921-3 都在「占位（等你回来的疑问）」一节，各带触发条件 [[01-交互式学习/02-课程真源/和 agent 一起做规划/00-学习计划.md]]。
6. **01 篇这一轮的最小动作是三行**（挑一件最近一周真读过的东西／它上一次让你改主意是什么时候／我在哪一处把人暴露给了 agent 看世界的方式）[[01-交互式学习/02-课程真源/和 agent 一起做规划/01.md]]；本条反馈没有逐条回应这三行，输入里也看不到对应回执。

## 矛盾双方（结构化见 conflicts）

- 反馈把「两个世界不可互读」归成单一原因「沟通和理解的成本太高了」；02 篇把它拆成成本层与结构层，并说结构层「和时间、成本无关」[[01-交互式学习/04-用户原话与费曼/工作台视图/lw_f20154d8406b1af32b22f66e.md]] × [[01-交互式学习/02-课程真源/和 agent 一起做规划/02.md]]。
- 反馈说「我觉得我做的这个边界物其实有点像词汇表」；02 篇判词汇表只过两条、第三条最弱，是入场券而非全部。
- 反馈问「自证预言」与「反身性」是否本质同一；02 篇反而指出更麻烦的是「一名多物」，并给了「自我强化那一支的特例」这个不完全同一的判断——两边都建在未回源的二手概述上。
- 反馈自述「我其实没有什么太多问题，算是看懂了」；课程口径是判断吸收看可检查动作、语气与长度不当证据 [[01-交互式学习/02-课程真源/和 agent 一起做规划/00-学习计划.md]]。

## 未知（结构化见 unknowns）

## 两条口径提醒

计划写明「判断吸收用『可检查动作』当证据；反馈的语气与长度不当证据」，痕迹快照也标「这是痕迹，不是掌握证据」[[01-交互式学习/02-课程真源/和 agent 一起做规划/00-学习计划.md]]——所以「算是看懂了」「第三遍看」是信号，不是掌握。同时计划自己写了「『没写进文件』不等于『没发生』，本课四轮反馈都走对话，即为反例」——所以 01 篇最小动作未见回执只能记作待核实，不能记作没做 [[01-交互式学习/02-课程真源/和 agent 一起做规划/00-学习计划.md]]。

另：材料与课程文本里的第一人称（01 篇标【我】的判断、标【你】的引用）属于课程写作方与课程记录，不是用户履历；本条反馈里的第一人称（ENTP、First Fly、黑客松）是用户自述，输入中没有可核对的旁证 [[01-交互式学习/02-课程真源/和 agent 一起做规划/01.md]] × [[01-交互式学习/04-用户原话与费曼/工作台视图/lw_f20154d8406b1af32b22f66e.md]]。
