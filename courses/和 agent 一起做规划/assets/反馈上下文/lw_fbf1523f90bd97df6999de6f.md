- 多 Agent 协调机制：课程方 [[01-交互式学习/02-课程真源/和 agent 一起做规划/08.md]] 要求「靠工件，不靠对话」「每次交接留一件物，不留一段话」；反馈所引推文方 [[01-交互式学习/04-用户原话与费曼/工作台视图/lw_fbf1523f90bd97df6999de6f.md]] 列 Paseo「多代理编排能力」等工具能力，但未说明它的编排是否产出绑定 run id / 任务 hash / 结果 hash 的工件。此条暂记为待核张力，不判谁对。
