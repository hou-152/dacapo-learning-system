### 材料把什么叫作“气运”

主文稿把它表述为“向善而行”以及可累计、可叠加的过程，同时把“运气”放在不可判断的一侧。[P01-T01](材料包-01/材料.md#p01-t01定义与系统主张)

这是文稿提出的定义与框架。当前证据可以确认“材料这样说”，尚不能确认“长期好运一定由这条链造成”。`最终一定会有好运` 仍是待检验主张。[P01-T01](材料包-01/材料.md#p01-t01定义与系统主张)

### 把抽象词拆成可观察的链

文稿中的宠物医院案例展示了较短的中间链：释放善意、主动询问、获得信息、建立关系、增加未来可调用的选项。[P01-T02](材料包-01/材料.md#p01-t02行动如何产生信息关系与后续选项的案例)

据此可以先使用一个工作假设：

`具体行动 → 对方可见的反馈 → 新信息／关系变化／能力练习 → 未来选项变化`

群聊也提出了三个可检查点：社会验证不能缺席；可以观察他人的反馈与反应；行动结果应回到原想法做修正。[P01-C01](材料包-01/材料.md#p01-c01质疑缺口需要社会验证机制) [P01-C02](材料包-01/材料.md#p01-c02群内提出的验证方法) [P01-C03](材料包-01/材料.md#p01-c03群内提出的行动反馈方法)

这条短链可以观察。它只覆盖了“行动怎样改变眼前条件”。从这些变化继续推到长期际遇，还缺时间、对照与其他解释。

### 做一个低风险行动实验

选择一个 7 天内可完成、即使失败也不会造成明显伤害的场景。按下面格式预先写好：

| 项目 | 你的预注册 |
|---|---|
| 场景 | 只写一个具体人或具体协作 |
| 行动 | 一次对对方有实际价值、成本可承受的动作 |
| 直接结果 | 对方是否收到、是否回应、是否采用 |
| 中间变化 | 你获得了什么信息、关系是否变化、能力是否被练习 |
| 反例条件 | 出现什么结果时，当前解释需要修改 |
| 替代解释 | 礼貌回应、既有关系、时机、随机波动等 |
| 回填时间 | 明确到日期 |

安全边界来自主文稿自身：不要用危险动作与不可逆代价测试“运气”。[P01-T01](材料包-01/材料.md#p01-t01定义与系统主张)

## 小结

1. 材料定义了“向善而行、可累计叠加”的气运框架；定义本身是来源主张。[P01-T01](材料包-01/材料.md#p01-t01定义与系统主张)
2. 信息、反馈、关系和能力变化构成较短、可观察的中间链。[P01-T02](材料包-01/材料.md#p01-t02行动如何产生信息关系与后续选项的案例)
3. 长期好运仍有多种可能解释，需要时间、反例与对照；群聊明确提出了社会验证缺口。[P01-C01](材料包-01/材料.md#p01-c01质疑缺口需要社会验证机制)
4. 本课把一次低风险实验只当作当前路由证据，不据此宣布掌握或因果证明。[dbs-learning 普通版｜路由判断](../../09-Skills/dbs-learning/SKILL.md#路由判断)
