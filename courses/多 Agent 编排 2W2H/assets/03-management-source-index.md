# 第 3 课｜管理学来源索引

## 主材料

- AI 内参：《Codex 里的多 agent 编排实操》，2026-07-28。
- 用途：提供 Codex 多 Agent 的角色、推理档位、上下文、权限与通信案例。

## 管理学原始来源

### Malone 与 Crowston：协调理论

- 论文：The Interdisciplinary Study of Coordination
- 作者：Thomas W. Malone、Kevin Crowston
- 发表：ACM Computing Surveys，1994，26(1)，87—119
- 链接：https://ccs.mit.edu/papers/CCSWP157.html
- 本课用途：用“管理活动之间的依赖关系”解释协调。

### Galbraith：组织的信息处理观

- 论文：Organization Design: An Information Processing View
- 作者：Jay R. Galbraith
- 发表：Interfaces，1974，4(3)，28—36
- DOI：https://doi.org/10.1287/inte.4.3.28
- 本课用途：连接任务不确定性、认知边界、信息处理需求与组织形式。

### Mintzberg：组织协调机制

- 论文：Structure in 5's: A Synthesis of the Research on Organization Design
- 作者：Henry Mintzberg
- 发表：Management Science，1980，26(3)，322—341
- DOI：https://doi.org/10.1287/mnsc.26.3.322
- 本课用途：连接相互调节、直接监督，以及流程、产出和技能标准化。

## 证据边界

- FACT：三篇来源都属于组织、协调或管理研究的原始论文。
- FACT：Mintzberg 原文明确列出 5 种基本协调机制。
- INFERENCE：将这些管理学机制映射到 Coordinator、Agent 消息、Skill、测试和推理档位，是本课程的跨领域解释。
- UNKNOWN：当前没有直接实验证据证明这套映射在所有 Codex 多 Agent 任务中都能提高绩效。
- RECOMMENDATION：先把映射用于理解和提出可检验假设，再用真实任务评价收益。
