# 多 Agent 编排 2W2H｜学习计划

## 学习目标

完成这组微课程后，学习者应能：

1. 用自己的话讲清多 Agent 编排的 Why、What、How、How good。
2. 用管理学解释多 Agent 编排中的分工、依赖、协调、授权、信息流和管理控制。
3. 建立“AI 内参案例 → 管理学母概念 → Agent 机制”的概念网络，并说明类比边界。
4. 形成一份经过本人回答与确认的“多 Agent 编排 2W2H”，不把材料摘要直接当作本人掌握。

## 学习路径

1. 案例层：从 AI 内参理解 Codex 多 Agent 的角色、上下文、权限和通信。
2. 理论层：用协调理论、组织的信息处理理论和组织设计解释案例。
3. 概念网络：连接分工、依赖、协调机制、集权／分权、标准化和管理控制。
4. 2W2H：把管理学理解收束成 Why、What、How、How good。
5. 确认：由学习者复述并修正，形成最终概念页候选。
