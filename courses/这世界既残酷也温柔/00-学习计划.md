# 这世界既残酷也温柔｜学习计划

## 学习目标

学完这个课题，你能：

1. 复述孙宇晨给书名立的判断：残酷指什么、温柔指什么，并能各举一个书里的例子。
2. 按五个 PART 提炼书里的核心判断群（主动选择 / 从未来看正确的事 / All in / 90 后新文明宣言 / 财富自由），每个 PART 至少复述一条判断。
3. 对每条判断做结构检查：他靠什么证据支撑、什么条件下成立、哪些部分只对他自己成立。
4. 每篇文章完成一个可检验的最小动作，全书结束汇总成你自己的「可复用判断清单」。
5. 用费曼方式向别人讲清楚这本书的一个 PART。
6. 学完之后交付一个带数字的 OKR，并用对应 skill 装进你的工作台，专注执行（07 反馈承诺，12 收尾交付）。

## 学习路径

1. 第一阶段（01-03）：题眼与 PART1。残酷与温柔的题眼、叛逆—和解的判断结构（01）；稳定工作的账与主动选择（02）；城市、父母、三观（03）。
2. 第二阶段（04-05）：PART2 做从未来看正确的事。心里有火光、不独立没人替你坚强（04）；自由选择、这个时代既残酷也温柔、校长马云教给我的那些事（05）。
3. 第三阶段（06-07）：PART3 All in 一个波澜壮阔的事业。一个人就是一个时代、当一个外星人、危机与机会并存的互联网时代（06）；全情投入或者一无所有、想好了就上路 + 提前调用《世界不会亏待真正对自己负责的人》的对结果负责三步（07，因用户「无限生成」反馈调整）。
4. 第四阶段（08-09）：PART4 90 后新文明宣言。你变得更好你便值得更好、不结婚不买房不买车（08）；摒弃穷人的思维模式、拥抱不确定性（09）。
5. 第五阶段（10-11）：PART5 我在财富自由的路上等着你。年轻人向钱看、普通人如何挣到第一个 100 万（10）；最不值钱的就是钱了、我是如何实现与理解财富自由的、已经有了 100 万如何用好它 + 附录粉丝问答（11）。
6. 收尾（12）：全书判断清单 + 费曼复述 + 落到你自己的行动清单 + 你的 OKR 定稿与工作台落地（07 反馈承诺），回查 01 存疑的「叛逆 → 卓越」。
