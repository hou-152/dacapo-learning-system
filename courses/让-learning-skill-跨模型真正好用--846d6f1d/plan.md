# 让 Learning Skill 跨模型真正好用｜学习计划

## 终局能力

能把 Learning Skill 的效果拆成真实学习结果、教学接口与模型行为三层，并据此设计一套让 Claude、Codex 和低成本模型公平比较的最小验收，而不是用测试数量或主观爽感单独下结论。

## 任务锚点

判断同一个 `dbs-learning` 在 Claude、Codex 和低成本模型上体验不同的主要原因，并设计一种既不加厚 Skill、又能提高低成本模型可用性的验收方法。

## 学习路径

1. 区分“合同测试通过”和“真实学习有效”，确定不可被代理指标替代的目标函数。
2. 理解能力为什么是模型、控制接口、工具和反馈 Loop 的系统属性。
3. 识别模型与语言带来的严谨度、深度、温暖度和执行倾向漂移。
4. 把三层机制合并为一套跨模型、低成本、真实任务驱动的最小验收。
