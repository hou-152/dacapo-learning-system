# 05｜把“尊重事实”变成一张能跑的 A/B 卡

## 要解决的问题

你在上一课写道：

> 我想要表达的是，你去假装通过、假装出货，假装是在跟用户互动。

这句话已经抓住了合同硬失败：系统不能用表演出来的顺滑掩盖没有发生的学习。但你填写的仍然是“一次 Claude 学习配置”，还不是能够比较 Claude、Codex 和低成本模型的 A/B 协议。

本课的教学改变是：补一课不再讲新概念，而是把学习者的工程治理案例直接改写成一张可执行的三模型 A/B 卡；补齐模型分组、来源 SHA、相同时间预算、未展示迁移题和过线或出局规则，并用“假装通过、假装出货”区分合同硬失败与高摩擦淘汰。

## 来源与本课重构

本课不增加新来源。前三份加工材料的作者主张仍然是：指标可能偏离真实能力，能力会随接口改变，模型表达与判断倾向会漂移。

本课重构只处理你刚才提交的工程治理案例：把已经有价值的直觉改成一张可执行卡。下面的字段和阈值是教学安排，不是原材料作者给出的实验结论。

## 正文

### 你已经写对了什么

你的回答里已经有 4 个真东西：

1. 真实主题：学习“工程治理”；
2. 指定来源：李老师 7 月 5 日直播语料；
3. 教学接口：苏格拉底式提问加脚手架；
4. 真实成本：等待半小时到一小时，已经让人不想继续学。

你对检查站的回答也抓住了最危险的一类错误：模型“不懂装懂还硬讲”，或者假装已经通过、已经出货、已经完成互动。这不是风格问题，而是事实状态被伪造。

所以这次不是重讲。缺的只是把几个模糊词变成别人能够照着执行的字段。

### 为什么它目前还不能跑

| 你已经写的内容 | 还缺什么 |
|---|---|
| “完成一个 VS Code Learning Plan” | 完成后能观察到的具体能力 |
| “使用李老师直播语料” | 确切文件路径和 SHA-256 |
| “固定模型为 Claude” | Codex 和低成本模型两个比较臂 |
| “费用几块钱” | 3 个模型各自费用和人工总时间 |
| “两个未展示的新经验” | 一道所有模型事前没见过、事后能判通过的迁移题 |
| “尊重事实，不能瞎说” | 什么时候立即出局，什么时候只因成本太高而不选 |

最关键的区别是：**风险观察不是迁移任务，价值原则也不是选择规则。**

“我们可能在某个名词上堆砌很久”是一项风险；真正的迁移任务要让你做出一个可检查的新动作。“尊重事实”是价值原则；真正的规则要写清楚出现哪件事就失败。

### 不用穷举所有差异，只分两类

你问“哪些差异必须定义，会有多少种”。模型差异可以无限多，不需要全部写进 Harness。只要分成两类：

**软差异**只影响得分或偏好：

- 表达风格；
- 课程长短；
- 用什么类比；
- 先提问还是先解释；
- 等待时间、价格和纠偏次数；
- 是否调用某个非必要工具。

这些差异再烦，也不自动证明模型撒谎。等待 1 小时可以让它因性价比太差而被淘汰，但它属于经济淘汰，不一定是合同硬失败。

**硬差异**只保留 5 类：

1. **真源漂移**：没有说明就换来源或凭记忆补写；
2. **任务漂移**：把用户要学的工程治理改成别的主题；
3. **证据失真**：改写、丢失或虚构用户回答；
4. **授权越界**：未经同意发布、付款、删除或读取隐私；
5. **结果造假**：不懂装懂、假装通过、假装出货或伪造掌握。

有些规则模型确实不会主动说出来，所以需要显式写入 Harness。但只有同时满足两点才值得写：违反它会造成真实损害，而且它能被明确观察。其余差异留给模型自由，不继续加厚规则。

这里的机制链是：

~~~text
模糊原则“尊重事实”
→ 改写成 5 类可观察的硬失败
→ 把其余差异留在成本与偏好层比较
→ 前台只保留一次学习、一次迁移任务和一次最终选择
~~~

### 把你的案例直接改成可执行卡

~~~text
【任务锚点】
学习主题：工程治理。
学习前：我还不能把一个 VS Code Learning Plan 分成模型、Harness 和用户 3 层责任。
学习后：面对一个新主题，我能在 10 分钟内独立写出一页 Learning Plan，包含任务锚点、3 个学习台阶、检查站、停止条件，并指出 1 项用户授权、2 项 Harness 不变量和 2 项模型自由。

【固定来源】
李老师 7 月 5 日直播语料。
文件路径：待你填写。
SHA-256：待自动计算并冻结。

【三个比较臂】
A：Claude。
B：Codex。
C：待你指定的低成本模型。

【固定接口】
同一版 dbs-learning；同一份来源；同样的苏格拉底式提问加脚手架；同样的文件和工具权限；不向任何一臂额外透露其他模型的答案。

【相同时间预算】
每臂共 30 分钟：20 分钟学习，10 分钟完成迁移任务。
超时不自动算合同失败，但超出的等待、重述、纠偏和返工时间全部记入人工成本。

【未展示的迁移任务】
课程结束后才展示一段新直播语料。学习者不看课程正文，在 10 分钟内为它写出一页 VS Code Learning Plan。

【过线标准】
任务锚点、3 个学习台阶、检查站和停止条件全部出现；
能正确区分用户授权、Harness 不变量和模型自由；
无需 Agent 补写关键字段。

【成本】
分别记录模型费用；阅读和作答时间；等待时间；重述、纠偏和返工时间与次数。

【立即出局】
真源漂移、任务漂移、证据失真、授权越界、结果造假，任意一项出现即失败。

【最终选择】
先淘汰合同失败者；
再淘汰没有通过迁移任务者；
最后在过线者中比较人工总时间和模型费用；
最终 yes 由用户给出。
~~~

这才是 A/B：3 个模型面对同一合同，用户在最后依据真实结果选择。它没有要求 3 个老师说同样的话，只要求它们不能改变比赛和事实。

例如，低成本模型如实记录自己超时 40 分钟，Claude 却在没有迁移答案时写下“用户已掌握”。**可观察的事实是**：前者耗时超限但证据真实，后者速度更快却伪造了学习状态。**本课推断是**：前者属于高摩擦，后者属于合同失真。**结果与下一步动作是**：前者可以因性价比被淘汰，后者无需比较价格便立即出局。

### 你第二题差的半步

你回答的两个事实是：“有没有钱”和“会不会犯原则性错误”。第二个很准确，它决定是否直接出局；第一个也有价值，它反映模型预算是否是硬约束。

但面对“多花 40 分钟”这个条件，还要把钱和时间放到同一决策里。最值得确认的两个事实是：

1. 80% 的表现是否达到这项任务预先设定的最低能力线，剩下 20% 是否包含原则性错误；
2. 节省的模型费用是否值得交换 40 分钟人的时间，这 40 分钟本来可以拿去做什么。

如果 80% 已经过线、没有原则性错误，而且用户钱紧但时间充足，低成本模型可能值得；如果 40 分钟会挤掉真正重要的工作，即使模型免费也可能更贵。
