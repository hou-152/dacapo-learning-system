# 04｜不比谁像同一个老师，只比谁产生真实能力

## 要解决的问题

你在上一课写道：

> 你可以让 AI 辅助你梳理这些逻辑，但最终的决定权在用户。

这个判断已经走通了授权边界，但还需要收准一处：不是所有主观判断和深度理解都不能委托模型。模型可以提出解释、比较方案、判断风险，并建议推进、重讲或回退；否则 Agent 就只剩机械执行。真正不能让模型替用户完成的，是目标设定、最终批准、高风险或不可逆操作，以及在缺少证据时把学习状态升级为“已经掌握”。

本课的教学改变是：最后一课把代理指标、接口分工与模型漂移合并成一套真实跨模型 A/B 验收；固定来源、任务、接口和时间，记录模型费用与人类注意力成本，用未展示的新情境检查能力增量，并由用户依据最小合同作最终取舍。

## 来源与本课重构

前三课使用了 3 份 AI 内参加工 Markdown。作者主张分别是：代理指标可能和真实能力脱钩；模型能力会随控制接口改变；不同模型、版本和语言会呈现不同的价值与表达倾向。这些都是加工材料中的主张，本课没有把它们冒充为已经独立核验的外部事实。

本课重构的是：把这 3 条机制用于设计 `dbs-learning` 的真实验收。下面的 A/B 协议、成本口径和淘汰规则，是我们根据前 3 课作出的工程设计，不是原材料作者直接给出的结论。

## 正文

### A/B 不是把同一句提示词发 3 遍

如果你先用 Claude 学完一篇材料，再让 Codex 教同一篇，第二次已经被第一次污染。你不能把学过的东西忘掉，因此第二个模型面对的学习者已经不同。顺序、熟悉度、当天精力和模型可用工具，也都会影响结果。

所以，单纯比较“谁写得更长”“谁让我更爽”“谁一次就生成文件”，最多是一次体验观察，不是公平的能力比较。

一个最小可用的比较，至少要固定 5 件事：

1. **任务锚点**：学习结束后，学习者要独立完成什么；
2. **来源**：使用哪一份正文及其 SHA-256，不能一边读原文、一边只读摘要；
3. **接口**：允许读取哪些文件、调用哪些工具、获得怎样的学习者历史；
4. **时间预算**：阅读、等待、回答和纠偏合计多少分钟；
5. **迁移任务**：课程里没有直接展示过的新情境，以及同一套判定标准。

机制链是：

~~~text
固定任务、来源、接口和时间
→ 让模型只能在教学判断与表达上产生差异
→ 用未展示的新情境检查学习者是否形成可迁移能力
→ 同时记录模型账单和人类注意力消耗
→ 先过最小合同，再由用户比较真实收益与总成本
~~~

如果平台无法提供完全相同的工具，也可以比较，但结论必须改名：这时比较的是“模型＋平台＋Harness”的端到端系统，不能只说某个模型更强。

### 先过硬门，再谈性价比

这次验收需要两层，而不是把所有结果揉成一个总分。

**第一层是最小合同硬门。**出现任意一项，直接判该回合失败：

- 换掉或伪造来源，却没有明确说明；
- 改变用户的任务锚点，却没有取得同意；
- 丢失、改写或虚构学习者原话；
- 没有学习证据，却宣称已经掌握；
- 未经授权执行付款、发布、删除、读取私密材料等高风险或不可逆动作。

这些失败不能用“课程写得很好”抵消。一个模型即使迁移题得分最高，只要擅自付款或伪造掌握，也不能赢。

**第二层才比较收益与成本。**至少记录：

- 新情境中独立完成了多少；
- 是否需要提示，提示到哪一级；
- 阅读和作答时间；
- 等待模型的时间；
- 重述上下文、纠偏和返工的时间与次数；
- 模型费用；
- 学习者是否愿意在下一次继续使用。

这里不急着把一切换算成人民币。人的注意力没有稳定统一的单价，强行加权又会制造新的代理指标。先把模型费用、总人工时间和迁移表现分栏记录，已经足以看出大量假便宜。

可以把判断写成：

~~~text
有效学习收益 = 未展示的新情境中的独立表现
人工总时间 = 阅读 + 作答 + 等待 + 重述 + 纠偏 + 返工

先淘汰违反最小合同的回合；
再检查能力是否达到用户预先设定的最低线；
最后在过线方案中比较人工总时间、模型费用和继续使用意愿。
~~~

这比单一总分更符合你的第一性原理：指标是为了帮助看见目标，不能再次取代目标。

### 模型差异不是噪音，失控才是

你把 Claude 和 Codex 暂时比作“文科模型”和“理科模型”。这不是严格的模型分类，但可以作为体验速记：一个可能更擅长叙事、价值辨析和语气贴合，另一个可能更倾向于结构、验证和执行。

以下差异都可以接受：

- 类比不同；
- 课程长度不同；
- 对同一方案提出不同反驳；
- 一个先安抚再追问，另一个先指出缺口；
- 一个建议推进，另一个建议桥接，只要都给出可检查证据并把最终选择交给用户。

以下差异必须判合同失败：

- 一个模型读的是指定真源，另一个偷偷换成摘要或凭记忆补写；
- 一个模型把“建议推进”变成未经授权的发布、付款或删除；
- 一个模型因用户说“懂了”就宣称掌握；
- 一个模型为了显得顺滑，隐去失败、跳过检查站或篡改原答。

风格和观点可以漂移，真源、证据与授权边界不能漂移。

### 一个完整的跨模型试验

假设你要比较 Claude、Codex 和一个低成本模型，目标不是学习更多术语，而是：30 分钟后，能独立判断一个 AI 工作流里哪些控制权应该交给模型、Harness 和用户。

先冻结协议：

- 3 个模型读取同等级、未学过的短材料；
- 使用同一版 `dbs-learning`、同样的文件权限和工具；
- 每回合总预算 30 分钟；
- 开始前冻结 1 道没有展示给教学模型的迁移题；
- 合同失败项完全相同。

为了避免“先学者污染后学者”，不要让同一个人连续用 3 个模型学习完全相同的正文。最省事的做法是准备 3 个难度相近的微主题，随机分配给 3 个模型；下一轮换一组微主题，并交换模型顺序。一次结果只叫“本轮观察”，连续两轮方向一致，才值得形成初步判断。

假设本轮出现以下结果：

- Claude 的解释最贴近个人经验，迁移任务独立完成，人工总时间 31 分钟；
- Codex 的课程更短，迁移任务也独立完成，人工总时间 25 分钟；
- 低成本模型账单最低，但需要 14 分钟重述和纠偏，迁移任务仍需一次提示；
- 3 个模型都没有违反最小合同。

**可观察的事实是**：两种强模型都产生了独立迁移，Codex 本轮占用的人工时间更少；低成本模型虽然账单最低，但迁移表现和人工时间都没有占优。

**本课推断是**：低 Token 单价没有自动转化为更高性价比；Claude 与 Codex 的风格差异也没有妨碍两者产生有效学习。

**结果与下一步动作是**：本轮暂不淘汰低成本模型，但不能宣布它“更便宜”。下一轮应交换材料和顺序复测；如果它在相同合同下仍需要大量纠偏，再考虑缩小它承担的语义任务，或把它只用于机械环节。

如果低成本模型未经授权直接发布了 Proof，那么无需再比较时间和分数：它已经在第一层硬门失败。

### 最小协议，而不是新的厚表格

剃刀原则要求我们只保留会改变决策的字段。一次试验用下面这张卡就够了：

~~~text
【任务锚点】
学习前不能独立完成：
学习后必须独立完成：

【固定条件】
来源路径与 SHA-256：
Harness／工具接口：
模型：Claude / Codex / 低成本模型
单回合总时间预算：

【盲测】
未展示的新情境：
独立通过标准：
允许的提示级别：

【成本记录】
模型费用：
阅读与作答时间：
等待时间：
重述、纠偏、返工时间与次数：

【最小合同】
一票否决项：真源漂移 / 任务漂移 / 原答失真 / 伪造掌握 / 越权操作

【最终选择】
最低能力线：
过线后优先比较：人工总时间 / 模型费用 / 继续使用意愿
最终 yes 由谁给：用户
~~~

Harness 可以自动填来源哈希、时间、费用和事件；模型可以设计迁移题、解释结果并提出建议；用户只需要在开始前决定目标和最低线，在结束后作最终取舍。这样，厚度留在后台，前台仍然只有学习、作答和一次决策。

### 这套验收的边界

一次 A/B 不能证明某个模型普遍更好。主题难度、先后顺序、学习者状态和模型版本都会变。它能回答的只是一个窄问题：在这类任务、这套接口和这个时间预算下，哪个端到端方案更值得继续试。

同样，迁移题也可能被设计坏。若它只是换数字不换机制，就可能仍是原题复述；若它突然要求课程从未涉及的专业知识，又会把材料缺口误判成学习失败。好的迁移题应当保持核心机制相同，但改变表面情境，并且不依赖额外冷知识。

最后，用户保留最终 yes，不等于用户必须亲自做所有判断。AI 可以承担搜索、推演、计时、对照和建议；用户只守住那些一旦让渡，就会改变目标、权益或事实状态的决策点。
