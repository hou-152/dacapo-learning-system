# 07｜前沿地图与面试答法：从四层架构到 2026 年的记忆军备竞赛

## 这一篇要解决的问题

理论骨架、ELI5 巩固都完成了。这一篇做两件事：给你一张 2026 年生产级记忆 / 知识库的前沿地图（主流方案、大公司、论文），然后把你六篇学的东西压成一段面试可以直接用的 60 秒答法。

## 正文

### 一、你学的东西，在 2026 年叫什么名字

先做一次翻译：你学的四层架构，学界和工业界有对应的主流语言。

**1. 分层记忆 = MemGPT / Letta 路线。** Berkeley 2023 年的 MemGPT 论文提出把 LLM 当操作系统，内存分层：主上下文放当前重要的，其余放外部存储，按需「换页」进来。团队后来商业化改名 Letta，现在做开源的 memory server，走 MCP 接口。
你学的四层架构，就是这条路线的一个工程版本。对应关系：滑动窗口 ≈ MemGPT 的主上下文；近期摘要 ≈ 外部存储里的压缩记忆。

**2. 认知分类 = CoALA 四类记忆。** 学界把 Agent 记忆分成四类（CoALA 认知架构）：

- 工作记忆：当前任务在脑子里过的东西 → 你的第一层（会话元数据）+ 第四层（滑动窗口）。
- 情景记忆：过去经历的具体事件 → 你的近期摘要层。
- 语义记忆：长期的事实、偏好 → 你的第二层结构化数据。
- 程序记忆：怎么做事的技能 → docs 里「重复任务沉淀 Skill」。

面试时两套语言都会说，50k 的样子就出来了：工程分层（docs 四层）+ 认知分类（CoALA 四类）。

**3. 检索增强 = RAG 家族。** 你学的最小链路是 RAG 的原型（Lewis et al., 2020）。2024 年之后有两个重要变体：

- GraphRAG（微软，2024）：把文档先建成知识图谱，回答「全局性问题」（这个主题整体讲了什么、实体之间什么关系），补普通 RAG 只会查局部片段的短板。
- HippoRAG（2024）：受大脑海马体启发，用图谱做索引，擅长多跳问题（A 和 B 通过 C 连起来）。

你自己已经学过的「迷失在中间」（Lost in the Middle, 2023）也在这里收口：长上下文中间位置性能下降，所以记忆要分层、要检索，不能全塞进上下文。

### 二、前沿公司怎么打记忆这场仗

- **OpenAI**：ChatGPT memory 产品化最早，跨会话记住用户偏好。
- **Anthropic**：2026 年 3 月把记忆功能免费开放，还出了「记忆搬家」工具，一键把 ChatGPT 的记忆导入 Claude——记忆成了抢用户的武器。
- **Google DeepMind**：Gemini 走百万级 token 长上下文路线，和「检索分层」路线形成对照，两条路线并存。
- **记忆层专业公司**：Letta（MemGPT 团队）、mem0（个性化记忆层）、Zep（时序知识图谱记忆，开源引擎叫 Graphiti）。它们大多通过 MCP（Anthropic 牵头的开放标准）暴露 memory server，你的 Agent 接一个 MCP 记忆服务就能拿到长期记忆。
- **国内**：Dify、FastGPT、扣子、腾讯元器都内置知识库 + RAG 组件，多数面向「把文档变成问答」的场景，生产级分层能力要看你怎么搭。

一个判断：记忆正在从「RAG 插件」变成「独立的基础设施层」。这也是为什么面试开始问 Agent 记忆——它已经从边缘问题变成岗位核心能力。

### 三、论文地图（面试提名字用的）

按学习顺序列：

1. Lewis et al., 2020，「Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks」——RAG 开山。
2. Liu et al., 2023，「Lost in the Middle」——长上下文中间失忆，你已经学过。
3. Packer et al., 2023，「MemGPT: Towards LLMs as Operating Systems」——分层内存。
4. Edge et al., 2024，「From Local to Global: A Graph RAG Approach」——GraphRAG。
5. Gutiérrez et al., 2024，「HippoRAG」——海马体启发的图谱记忆。
6. Wang et al., 2024，「A-MEM」——Agentic memory，借鉴 Zettelkasten。
7. Sumers et al., 2023，「CoALA」——认知架构与记忆分类。
8. 2025 综述，「Memory in the Age of AI Agents: A Survey」——面试前翻一遍目录即可。

不用全读。每篇知道一句话：它解决了什么问题、和我们学的哪一层对应。

### 四、面试答法：60 秒版本

面试官问：「Agent 记忆怎么做？」

一段可以直接练的答法：

> 我会把记忆分成四层，各司其职。第一层会话元数据放内存，用完就扔。第二层用户结构化数据走 JSON 键值存储，身份、偏好、关键决策直接精确拿。第三层把近期对话压缩成主题和实体进向量库，语义检索只在这一层用，还省 token。第四层滑动窗口保留当前轮原文。
> 这么分是为了避两个生产坑：精确信息和语义检索不能混，手机号、订单号必须键值精确查；用户状态变更要用双时间戳解决冲突，旧值掐断有效期，新值从当天生效，底层账本只追加，查询按任务投影视图，规则层管读写和合规。
> 最后，重复任务沉淀成 Skill 直接调用。学界把这套对应到 CoALA 的四类记忆，工业界有 MemGPT / Letta、mem0、Zep 这类记忆层，走 MCP 接入。记忆的终点是让 Agent 越用越像你。

这段话 60 秒能说完，覆盖：四层、两个雷、双时间戳、ledger / view / policy、Skill 沉淀、CoALA、前沿方案、MCP、收尾金句。练到不看稿能说，就是 50k 的答法。

### 五、学完之后的三个动作

1. 把 05 的最小一步做了：10 条口喷记录走四法进库。
2. 面试前把 60 秒答法练三遍，说给自己听。
3. 想深入时，读 Letta 的文档和 MemGPT 论文第一节，你会发现它们和你这七篇说的是同一件事。

## 小结

1. 你学的四层架构，学界对应 CoALA 四类记忆，工业界对应 MemGPT / Letta 的分层路线。
2. RAG 前沿：GraphRAG 管全局问题，HippoRAG 管多跳，长上下文和检索分层两条路线并存。
3. 记忆正在变成独立基础设施：OpenAI / Anthropic / Google 在产品层抢用户，Letta / mem0 / Zep 在服务层，MCP 是接入标准。
4. 面试用 60 秒答法：四层 → 两个雷 → 双时间戳 → Skill 沉淀 → 前沿名词收尾。
