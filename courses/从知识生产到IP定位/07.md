## 正文

### 「找选题」里的「找」，这个词就用错了

博主的起点是一个纠偏：直接研究选题本体，你得不到选题。去小红书、抖音搜「火锅选题火了」，把里面的观点换成自己的，他给的判词是：容易产出垃圾。这就是 01 讲过的反面流程：从别人的结果倒推。

为什么倒推不行？他在这一份里给了个狠比方：「找选题」就像说「我在喝饭」。饭只能吃，不能喝；
选题只能构造，无法被「找到」。
你能在网上刷到的，全部是别人做完的结果。
结果背后是一串决策：挑了哪些素材、怎么排列、用什么方式表达。这一串决策别人没给你看，你拿到的只是成品。

所以这条结论先立住：**选题是反复决策攒出来的结果，「找」这个动作不存在。**

### 选题本体：三个维度拼出一个选题

那这个「结果」长什么样？他把选题拆成三个维度：

1. **内容要素集合**：你手里有什么。概念、经历、画面、数据、人物，都是要素。
2. **要素关系的结构**：要素之间谁是主、谁是辅，摆成什么关系（对比、反差、递进）。
3. **主导内容的动作**：这条内容你在干什么——讲知识、下判断、讲经历，还是纯展示。

用他的开锁案例对齐。同一组要素：「隐性成本」这个商业概念 + 开锁师傅靠卖惨拖延时间。
大网红拍 A 视频：讲自己遇到开锁师傅的经历，最后 5 秒顺嘴提了一句「我问了豆包，这叫隐性成本」。
博主拍 B 视频：主讲隐性成本这个概念，怕你听不懂、怕你不感兴趣，配一个开锁的案例。

要素完全一样，选题完全不同：A 的结构是经历为主、概念为辅，动作是讲经历；
B 的结构是概念为主、案例为辅，动作是讲知识。三个维度里动了两个，就是两条选题。
女主播的例子同理：红吊带、雪地、抖音热舞是要素；白雪配红衣、天冷配吊带是反差结构；运镜和 BGM 什么时候进是动作。

顺带补一句他在开头说的「泛直」：基于深厚的理论去讲多数人感兴趣的话题，宽度就是这么来的——这是 02 的抽象上升法在选题层的样子。

所以定义可以收成一句话：**选题 = 挑出哪些要素、怎么组织它们的关系、用什么动作表达出来的一整套决策。**

### 为什么没有「第一步第二步」的通用选题法

看清楚这个定义，你就知道为什么全网找不到「选题万能公式」。关键在他举的一个细节：女主播为什么挑红裙子？因为她先想到「雪地里穿红裙子醒目」，有视觉冲突。挑要素（红裙子）和设计结构（跟雪地怎么搭）这两个决策是同时发生的，顺序拆不开。

多维度的决策同时发生，意味着能导出同一条好选题的路径有千万种。
他的比方：保时捷造车的方法和小米造车的方法完全不同，你问「什么是汽车」，得不到任何一家的造车法。
所以面对「给我第一步、第二步、第三步，选题就有了」这类要求，他的判词是：开口要步骤的人，手上缺的其实是本体。

技巧有用吗？
有用，他自己都给了一个：把最近让你情绪波动的事写下来，很快能出内容。
但他同时给了失效条件：每次都靠同一套技巧，内容很快枯竭，因为你始终没有接上选题的本体。
技巧是「有助于」构造选题的东西，10 个、100 个技巧也拼不出方法本身。

他自己怎么破这个局？切块。他说他野心没大到解决全部选题问题，只解决自己擅长的那一类：把自己高频做的几个决策（怎么生产知识、知识怎么和更多人相关、标题和开头怎么配对）逐层公开，揉成一个帮助构造选题的工具。你面对 149 条候选的处境一模一样：从自己那一类先做起来。

### 生成路径：战略目标在最前面

本体讲「选题是什么」，生成讲「怎么把它做出来」。他把生成排成一条顺序链：

**战略目标 → 选题生成 → 选题本体 → 传播设计 → 内容实现**

再用开锁的双案例对齐这条链。
大网红的战略目标是记录生活，所以日常经历直接生成了选题，概念只是顺带。
博主的战略目标是让人觉得他懂知识，所以日常必须不停发掘知识点，发现隐性成本之后，专门去找一个大众有共鸣的案例来配。
同一个知识点，战略目标不同，能选的结构就不同：想让人记住你的知识，只能讲 B 讲法。

这条链的最前端「战略目标」，接的就是 04 讲的议程：你反复打的那个判断。它决定后面四步怎么长。

### 拼上你的闭环

你的飞轮（候选稿 → 发布 → 反馈 → 提炼规则 → 下一篇验证）已经有后半段，这篇把前半段的操作层补齐。整条闭环现在长这样：

1. **素材池**：149 条候选 + 日常让你情绪波动的事 + 新学的概念。全部当要素，进池。
2. **构造选题**：从池里挑要素 → 定结构（谁是主谁是辅）→ 定动作（知识 / 判断 / 经历 / 展示选一个）。
3. **质检**：判、修、放嵌进三维度里——判管要素挑得对不对（有没有人听），修管结构怎么摆（怎么改有意思），放管切口开多大（抽象上升）。
4. **传播设计**：标题、开头、钩子。
5. **发布 → 反馈回池 → 提炼规则**：你的飞轮原样接上。

闭环成立卡在两头：池子有没有料，反馈有没有回池。中间的构造动作，这篇给了你第一版。

### 一句话的合格线

补一个跟你欠的那句话直接相关的边界。他用擦边女主播的例子反对把「解决问题」无限扩张：如果说所有短视频都解决了「我想看这个视频」的问题，这个词就没有区分度了，100 个不同的视频被压成同一句空话。

所以「这条在帮读者解决什么问题」这句有一个合格线：**换一条视频这句话还成立，就说明写得太宽，重写。**「帮读者解决问题」不及格；「帮 35 岁焦虑的人拿到『危机看行业曲线』的判断」及格。

## 小结

1. 「找选题」的「找」不存在：网上刷到的是别人做完的结果，选题是反复决策构造出来的结果。
2. 选题本体 = 三个维度：内容要素集合 × 要素关系结构 × 主导内容动作；要素相同、结构和动作不同，就是两条选题。
3. 多维度决策同时发生，所以没有「第一步第二步」的通用选题法；技巧（如写情绪日记）有用但会枯竭，出路是像博主那样切块，先解决自己那一类。
4. 生成路径：战略目标 → 选题生成 → 选题本体 → 传播设计 → 内容实现；战略目标（你的议程）在最前端。
5. 闭环两头卡命：素材池有料、反馈回池；判修放嵌进三维度当质检。

## 溯源备注（不用懂，不影响操作）

- 他借的说法：图书馆学的分面分类法（Ranganathan，1933——把对象拆成多个维度，各维度各自分类再组合定位），以及麦肯锡的 MECE（相互独立、完全穷尽）。三个维度的公式是分面分类在内容生产上的搬运。
- 他赌了什么：赌「理解本体的人自己会长出方法」，慢，但方法可迁移；对立面是直接发技巧，快，但枯竭。
- 断在哪：他断言没有通用选题法。这条要收窄：覆盖所有选题的通用法没有，同一类选题内部存在可复用的决策链——他自己要做 skill 就是证据。
- 「解决问题」的边界：这个词要有区分度，合格线见正文；你 04 那句「帮读者解决什么问题」就是拿这条线校准的。
