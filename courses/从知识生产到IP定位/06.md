# 06｜三把尺子的大白话版：判、修、放，加流量转化链

## 这一篇要解决的问题

接你的反馈：新闻学、修辞学、传播学三个词你不懂，练不出来。这篇先把三个名词拆掉，只留三个动作。然后用你的「学医 35 岁危机」当例题走一遍，最后接上计划的完整链：社会价值到流量转化。

## 正文

### 先拆掉三个名词

05 用学科名词包装工具，是我的问题。三个名词只干三件事：

- **判** = 这个题有没有人听。就是你 03 会打的第一问：多少人会一秒被这个问题卡住，多 / 中 / 少。
- **修** = 这个题怎么改才有意思。就两招：换一个具体疑问开头；抽象上升一层。
- **放** = 让切口变大。它和「修」的第二招是同一件事，抽象上升。

所以从今天起，你只需要记三个字：判、修、放。新闻学、修辞学、传播学忘掉，不影响任何操作。它们只是「为什么两问有效」的溯源，你不需要懂。

### 学医 35 岁危机走一遍

这是你带来的真实候选，拿它当例题：

- **判**：有没有人听。35 岁危机是大众痛点，「学医没有」天然反直觉。打分：中偏大，有人听。
- **修**：怎么改才有意思。题目现在预设「学医没有危机」，单面的，医学生会第一个反驳（规培低薪、超长学制）。改成对比：「程序员 35 岁被裁，医生 35 岁才刚起步」。
- **放**：切口变大。从「学医」抽象上升到「职业回报曲线」，所有焦虑 35 岁的人都进来，不只想学医的人。

三步走完，题面从「为什么学医没有 35 岁中年危机」变成「35 岁危机，差别不在年龄，在职业的回报曲线」。判断、修法、切口，一次清楚了。

### 社会价值到流量转化：完整链

这是 04 预告的最后一环，转写里的原话链是：

30 条视频解决「创业心态」这类问题 → 观众反复看到你在解决同一类问题 → 形成「这个人是解决 X 问题的人」的判断 → 有印象 → 基础流量 → 有人买你的产品。

钱怎么来，他给了双层解释：直接原因是视频转化了产品；根本原因是你帮一群人解决了一类问题。没有产品会怎样，就是直播有人打赏。

把链抽出来：**帮一群人解决一类问题 → 反复打一个点 → 观众形成判断 → 基础流量 → 转化**。

这条链的根在第一环：帮人解决问题。后面四环都是这件事的兑现。所谓流量转化，转的是你前面存下的社会价值。

接你的飞轮：你的输出窗口是候选稿 → 发布 → 反馈 → 提炼规则 → 下一篇验证。议程筛子放在发布前——每条内容发布前问一句：「这条在重复打哪个判断？」打不上任何判断的，先不发。

## 小结

1. 三个学科名词拆掉，只记判、修、放：判 = 有没有人听，修 = 改得有意思，放 = 切口变大。
2. 学医例题：判中偏大，修成对比，放到职业回报曲线。
3. 流量转化链：帮人解决一类问题 → 重复打一个点 → 观众判断 → 基础流量 → 转化；根在帮人解决问题。
4. 两层筛：先按「解决什么问题」分堆找议程，再单条过判、修、放。
5. 最小动作：挑 1 条候选，写一句「这条在帮读者解决什么问题」。
