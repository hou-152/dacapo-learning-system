## 正文

### 先认领：你自己已经推导出来了

你在反馈里写：

> 中间的这些决策集（SOP 1234）和选题强行关联起来，就像要去拟合一个黑盒决策。如果只能用结果去倒推，就会出现过拟合、以偏概全、矫枉过正。

这就是「为什么没有通用选题法」的答案本体。你推导出来了，只是没停下来认领。现在把整个论证摆齐，一共三条，你写的那条排第一。

**论据一：结果样本又少又偏，倒推必过拟合（你写的这条）。**

好选题是结果，结果背后站着一大堆你看不见的变量：发布时机、平台推荐、粉丝结构、运气。你能在网上看到的样本，全是发出来并且火了的——幸存者。样本又少、又只收幸存者，从结果倒推规律，必然过拟合：把运气当时机、把时机当规律。你说的「以偏概全」，机制就是这个。

**论据二：组合空间近乎无限，地图比地盘还大。**

看三维度：要素 × 结构 × 动作。随便动一个，就是新选题——同一组要素，结构一换、动作一换，选题就换了。通用法要覆盖所有组合，这张「地图」会比地盘本身还大，写不出来。保时捷和小米那个比方说的就是这件事：造车的决策空间太大，「唯一的造车法」在数学上立不住，两位老板只能各走各的路线。

**论据三：拟合该发生的位置在决策空间，样本在你的手里。**

通用 SOP 试图在「结果空间」里拟合，而结果空间的样本少且偏（论据一）。
有样本、有反馈的拟合发生在「决策空间」——你自己做的每个决策，做完就有反馈可回填。
你的飞轮里「提炼规则 → 下一篇验证」那一步，就是从自己的决策空间归纳局部规则。
博主的「切块做 skill」和你的飞轮，是同一个动作的两个版本：都放弃覆盖全部，都从自己高频做的那一类决策里攒规则。

三条论证摆完，「没有通用法」的边界也就清楚了，分两头讲：

- 覆盖所有素材的万能 SOP：写不出来（上面三条）。
- 自己那一类选题的局部决策链：写得出来。博主的 skill、你的飞轮，都是实例。

类比收尾：没有「写出畅销书的算法」，有「类型规范 + 编辑质检清单」。后者没用吗？编辑靠它吃饭。判、修、放就是你的编辑清单。

### 本体和生成：解剖图和生产线的区别

第二个卡点。两个词各管一张图：

- **本体 = 解剖图**。三维度（要素 / 结构 / 动作）把一个已经做出来的选题拆开，看它由什么组成。回答「选题是什么」。它是静态的，事后分析用。
- **生成 = 生产线**。五段链（战略目标 → 选题生成 → 选题本体 → 传播设计 → 内容实现）讲这个东西按什么顺序被造出来。回答「怎么把它做出来」。它是动态的，顺序结构。

两者容易缠在一起，原因很具体：三维度在两边都出现。五段链中间那一站「选题本体」，就是三维度定稿的那一刻。解剖图上你看到的是定稿之后的零件；生产线上你看到的是零件怎么被一个个定下来的。

用开锁双案例把生产线走两遍，一目了然：

| 五段链 | 大网红 A 视频 | 博主 B 视频 |
|---|---|---|
| 战略目标 | 记录生活 | 让人觉得他懂知识 |
| 选题生成 | 今天真遇到开锁师傅，事件直接生成 | 日常挖到「隐性成本」概念，「我有个东西想讲」 |
| 选题本体（三维度定稿） | 经历为主、概念顺带，经历型 | 概念为主、开锁案例为辅，知识型 |
| 传播设计 | vlog 拍法 | 从 10 个候选案例里挑传播力最强的开锁，配开头 |
| 内容实现 | 拍下来发出去 | 白板口播拍出来发出去 |

同一组素材，战略目标不同，后面四步全部不同——这就是「战略目标在最前面」的意思：它是生产线的头，扭一下，整条线的产出都变。

再拿你的学医题走一遍生产线，你会发现 07 那张四行卡填的就是中间两站：

1. 战略目标：让 35 岁焦虑的人记住「危机看行业回报曲线」（04 的议程）。
2. 选题生成：手里有「职业回报曲线」概念 + 程序员 / 医生对比素材。
3. 选题本体（三维度定稿）：概念为主、对比为辅，判断型——卡上那三行。
4. 传播设计：标题和开头怎么配对——09 讲，现在是空着的。
5. 内容实现：口播拍出来。

卡没填也没关系，走完生产线你会知道那张卡在整条链里的位置：它定稿的是第 2、3 站，收的是 06 欠的那句话。

## 小结

1. 「为什么没有通用选题法」你有三条论证：结果样本少且偏、倒推必过拟合（你自己写的）；三维度组合空间近乎无限，地图比地盘大；拟合该发生在决策空间——你自己的决策有反馈可回填。
2. 边界分两头：万能 SOP 写不出来；自己那一类的局部决策链写得出来。博主的 skill 和你的飞轮「提炼规则」是同一个动作。
3. 本体是解剖图（选题是什么，静态），生成是生产线（怎么造出来，顺序动态）；两者在「选题本体定稿」那一站交接。
4. 战略目标是生产线的头，扭一下，后面四步全变——开锁双案例、你的学医题，都验证这一点。
5. 四行卡 = 生产线第 2、3 站的定稿；第 4 站传播设计留给 09。
