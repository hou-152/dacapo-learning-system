# 02｜环节 3 补上 + 抽象上升：开口怎么从「没人听」开到「人人都问」

## 这一篇要解决的问题

先补你 01 反馈里指出的缺口：环节 3「找大众解释不了的现象」的对应做法——它其实就在你项目里。然后进入计划内容：抽象上升法（开头扩大、内容不变）、「精准流量 / 泛流量」二元论的拆解、以偏概全 → 合集的解法。

## 正文

### 先接住你的反馈：环节 3 的做法，你项目里已经有了

你把自己能想到的对应做法列了四项，环节 3 写的是「这个我确实暂时找不到」。做法在转写里其实讲了，而且和你 06-内容候选里的 149 条候选是同一套东西。

转写里他的原话：日常就要发现身边很多人的问题。他把 299 答疑群的聊天记录梳理出来，让 AI 看大家贡献的问题是什么；再加上他自己和 AI 的聊天记录，两个东西一起发给 AI，问一句——「有没有我们聊到的知识，能解决多数人心中的一个疑问」。这就是他的选题库。

「大众解释不了的现象」这个说法要翻译一下：你要找的其实是**疑问**，一条「大众常识解释不了、而你的框架解释得了」的疑问。他举的例子都是疑问开头：

- 「市场上最赚钱的为什么不是技术最好的人，而是最会销售的人？」（隐性成本）
- 「为什么我买了一个东西不用还买？」（剩余享乐，90 块手机支架）

对照你的项目：`交互式学习真源/04-用户原话与费曼` 和 `06-内容候选` 的 149 条候选，每条都带 evidence（用户原话）——那就是你的「答疑群聊天记录」。所以环节 3 的对应做法是：从用户原话池里捞「常识解释不了、树林框架解释得了」的疑问。你飞轮第一步「现实新现象」，落到操作上就是「原话池里的真实疑问」。

顺手给你一个检查项：他的问题池靠两个输入持续进料（群聊 + AI 聊天记录），你的原话池靠什么持续进料？如果进料停了，环节 3 就会断。这个检查项可以放进你的飞轮观察层。

### 抽象上升法：内容没变，开头扩大了

接着是环节 4。转写里最利落的一段是 Workbuddy 的例子：

1. 讲「Workbuddy 的几个用法」——泯然众人，1000 万人在用，轮不到你讲；
2. 升到「怎么不被 AI 时代抛弃、怎么用好 AI」——流量大了；
3. 再升到「人类如何在 30 分钟内学会任何一个新工具」——开口更大。

内容从头到尾还是 Workbuddy 那点用法，变的只是开头怎么切。他管这叫开口扩大：**你的开口足够大，底下的东西就比较深厚。**

他顺手处理了两个追问：

1. 「你这不是以偏概全吗？」——是的，单条就是以偏概全；但 50 条以偏概全就全了。合集同时解决两个问题：你的产出体系化（一个合集 N 条视频），观众不用啃书（把体系化知识拆成 50 个小点喂给他）。
2. 「凭什么信你的抽象？」——抽象不能凭空飘，必须落到多数人「一秒答不上来」的具体疑问上（90 块手机支架、开锁匠）。

### 干掉二元论：精准流量 vs 泛流量

他明说反对「精准流量 / 泛流量」这个二元论，理由是两头可以同时拿：找一个多数人大众关心的事情（大开口），在上面讲一个深厚的理论（深度）。例子是易中天品三国——三国家喻户晓（大开口），讲的是正史与演义的差别（深厚）。易中天不卖货，要是卖，转化极高。

反过来，断掉一头才是真问题：有流量没关注（每天讲「年轻人怎么赚钱」，泯于众人）；有知识没流量（讲隐性成本五个人看——但这是技巧问题，技巧在有限时间内学得会）。

判断可以压成两问：**开口问「多少人会一秒被这个问题卡住」，深度问「我的框架能不能把它讲穿」。** 两个都过，就是好题。

## 小结

1. 环节 3 的对应做法 = 从用户原话池捞「常识解释不了、框架解释得了」的疑问；你的 149 候选就是现成池子，进料是否持续是飞轮观察项。
2. 抽象上升 = 开头扩大、内容不变；Workbuddy 三级上升是标准样例。
3. 以偏概全 → 合集：单条以偏概全，50 条就是全，同时解决产出体系化和观众看不进书。
4. 二元论拆解：大开口 + 深理论可以兼得；判断两问 = 多少人被卡住 × 能不能讲穿。
