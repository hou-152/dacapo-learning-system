# 04｜让社会欠你钱：判断从你反复解决的问题里长出来

## 这一篇要解决的问题

接你今天的两个答案：「少」和「没有」。「少」说明第一问你会打了，这篇先判读这条候选怎么修。「没有」是议程缺失的证据，这篇讲两件事：合集的根本为什么是「让社会欠你钱」，实体餐馆的议程怎么变成基础流量。最后给你一条从「没有」走到「有」的倒推路径。

## 正文

### 先接两个答案

**「少」：你打出第一个分数了。**

02 你写「我无法判断」，03 给了两道例题，今天你能对「把自己当产品卖出去」打出「少」。02 到今天的区别只有一样：例题。这一问以后你都会打。

判读一下这个「少」：第一问打「少」的意思是切口窄，多数人第一秒没有被这个问题卡住，它和内容深浅无关。03 的候选 A（熵增）也是这个情况。修法参考 03：

1. 找一个具体疑问开头：「为什么你越努力包装自己，越没人买账」。
2. 把「把自己当产品卖出去」抽象上升一层，讲到多数人的处境：不讲「卖自己」，讲「别人是怎么定价你的」。

修完再打一次分，第一问应该会从「少」升到「中」。

**「没有」：这是 03 要你发现的证据。**

149 候选只留一个判断，你答「没有」。这个答案有用，它对应转写里的一句话：大多数人没有议程，所以没有印象，所以缺选题、缺人设。

先别急着憋一个词出来。03 讲过 IP 是结果不是起点：博主发了 100 条，大家才把维特根斯坦和他绑在一起。你一条还没发，「没有」是正常态。这篇解决的是路径：判断怎么长出来。

### 让社会欠你钱：合集的根本

博主说过一句话：我做内容的核心是让社会欠你钱。

拆开看他的抖音合集：创业心态、AI、商业逻辑。每个合集的根本是他在帮一群人解决一类问题。创业心态那个合集，30 条视频解决的是「一帮人创业心态有问题、不理解这个东西」。

钱怎么来，他给了双层解释：

- 直接原因：发了视频，观众转化了他的产品，赚到钱。
- 根本原因：他在社会层面帮人解决了几类问题。

没有产品会怎样，他的说法很直接：极端一点，你开直播，一堆人给你打赏。他还补了一句缩小范围：社会价值再缩小一点，是对你想要的用户的价值。

把这段话和 03 连起来看：合集对应一种判断，判断的原料是「你反复帮人解决的那类问题」。观众看到 30 条视频都在解决同一类问题，形成的是「这个人是解决 X 问题的人」。

议程是问题的结晶，它从你反复解决的问题里长出来。

### 实体餐馆：议程怎么变成基础流量

转写里最完整的例子还是那个餐馆。

餐馆老板平时怎么拍：今天拍菜好，明天拍和顾客冲突，后天拍员工离职，或者拍后厨。每条都独立，观众看完记不住任何东西。

换一个打法：老板想明白了一件事，这个餐馆要传递的判断是「干净」或者「负责」。然后所有讲法都往这个判断上打：

- 开除员工，因为这个员工有问题。
- 跟顾客吵架，因为那个原因。
- 装修成这样，因为爱干净。
- 每天检查，因为要干净。

每一条都在重复打一个点。观众对这个老板形成了一个判断，才愿意看下去。博主管这叫基础流量：这群人因为对判断有印象，终于明白你要说什么了。

把因果链抽出来：议程 → 每条内容重复打一个点 → 观众形成判断 → 有印象 → 基础流量。

三种判断可以并行参考：干净、营商、专业。它们最终体现在抖音的合集上。

### 议程的附带产出：不再缺选题

博主还讲了一件事：有了议程，选题会自己冒出来。确定了「员工」议程，一个个子问题都能拎出来单独讲，每一条都能当选题，人就不再缺选题。

这个和你的「没有」也有关系：没有议程时，149 条候选是一堆话题；有议程后，它们是同一个判断的 149 种讲法。

### 接你的飞轮：从「没有」走到「有」

路径是倒推，三步：

1. 把 149 候选按「这条在帮读者解决什么问题」粗分几堆。按问题分，不按课程名分，课程名是低级分类。
2. 找最大的那堆。你反复在解决的那类问题，就是议程的原料。
3. 判断词从「哪类问题 × 哪个反复管用的方法」里自己浮出来，先允许它丑。

博主的议程示范可以当参照：他想让观众形成的判断是「你在用传统学科的理论帮我理解我做内容的困境」。你的候选池里有熵增、如实所现、把自己当产品卖出去——它们合起来在解决什么，就是你要找的那个判断。

### 今日最小动作

从 149 候选里挑 3 条你最想发的，每条写一句「这条在帮读者解决什么问题」。写不出就写「写不出」，下一篇从例题再走一遍。

## 小结

1. 「少」= 第一问会打了；「把自己当产品卖出去」切口窄，修法 = 具体疑问开头，或者抽象上升。
2. 「没有」= 议程缺失，是正常态；不硬造词，走倒推。
3. 让社会欠你钱：合集的根本是帮一群人解决一类问题；钱 = 直接原因转化 + 根本原因用户价值。
4. 实体餐馆：议程 → 重复打一个点 → 观众判断 → 基础流量。
5. 有议程就不再缺选题；你的路径：按「解决什么问题」给 149 候选分堆。
