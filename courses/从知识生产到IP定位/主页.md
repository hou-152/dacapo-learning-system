## 这一课要解决什么

学完这个课题，你能：

1. 复述这个 100 万粉博主的反向创作流程（从「想搞懂一个问题」到「视频」，与「刷爆款 → 模仿」的顺序差异），并用自己的话拆解「隐性成本」「剩余享乐」两个案例。
2. 解释抽象上升法（开口扩大、内容不变）与「以偏概全 → 合集」解法，判断一个选题开口该开到哪一层。
3. 说清议程设置和 IP 定位的区别：IP 是结果不是起点；议程 = 想让观众对你形成的判断；低级分类（话题）与高级分类（判断）的差异；对外合集 + 对内报告的「两套」结构。
4. 说清为什么「选题」这个词没有定义（多元素复合问题），并能用新闻学 / 修辞学 / 传播学三学科的说法判断一个题值不值得讲、怎么修。
5. 把这条创作流程和你的飞轮（候选稿 → 发布 → 反馈 → 提炼规则 → 下一篇验证）对接：指出这条流程本身就是一个内容版的自迭代环，并落到你的 149 个内容候选上。
6. 用「内容要素 × 要素关系结构 × 主导内容动作」三个维度把一条候选构造成为可拍的选题，说清「找选题」为什么不成立，并把它嵌进你的完整闭环。
