# 12｜标题站：把卡变成一条能发的视频，和你的第一批清单

## 这一篇要解决的问题

两格收到，卡定稿：判断句「寄宿收走的账，从情感那里付」（采用聊天室 5/5 收敛的中层），念头「送孩子寄宿前多想一步」（家长版）。从 06 欠到现在的那句「帮读者解决什么问题」，五篇之后落了地——记一笔账：这是你的导出，充电。

本篇三件事：一，判读你这个组合——它比 09 的 A/B 二选一聪明，但也藏着一个要修的错位；二，进标题站，讲标题和开头怎么配对，用你的卡当场生成标题候选和开头骨架；三，交付 V1 第一批发布清单，闭环从图变成表。另外先纠正一个我的错误（正文里说）。

## 正文

### 先纠错：「30 岁」是我编的

09、10、11 的例题里我写了「30 岁路过母校还会打寒颤」——那个数字是我编的。你的真实数字是你自己说的：13 年寄宿、离开至少两年、深大在读。纠正之后素材反而更狠：时间反差从「三十岁还打寒颤」变成「**离开才两年，身体还记得**」。「三十年」靠年头吓人，「才两年」靠鲜活吓人——后者的观众全是同代人，正是你要的。以后所有题面用你的真数字。

### 判读你交的两格：第三条路

09 给的是 A（长期 IP，同路人）或 B（家长决定现场）二选一。你交回来的组合是：判断句用情感账（A 的锋利），念头用家长版（B 的落点）。判读：这是第三条路，而且成立——**一个内容三层**：同路人看到「被说中」（你的经历），系统看到「你反复打的判断」（情感账），家长看到「多想一步」（行动念头）。特劳特点的对立面（「吃苦是为你好」那套叙事）正好是家长念头的靶子。

要修的错位只有一个：视频是经历型，会自然结束在你自己身上；念头是家长向的——它送不出去，除非结尾给家长留落点。所以标题站多一个零件：**结尾 10 秒转场**，从「我的账」转向「正在做决定的人」。

### 标题站的机制：标题承诺，开头兑现

材料 2 里博主的高频决策链是：如何生产知识、知识如何和更多人相关、**标题和开头怎么配对**。配对的机制一句话：**标题是承诺，开头是兑现承诺的第一口。** 承诺太大开头接不住，观众有被骗感，三秒划走；承诺太小，白白浪费一个钩子。

拿你的卡生成三个标题候选：

1. **「寄宿 13 年，离开两年了，路过母校我还是会打寒颤」**——身体证据 + 真数字，最稳，V1 用它。
2. 「为什么离开寄宿学校两年了，我路过还会打寒颤」——疑问式，悬念最强，留给 A/B 测试。
3. 「寄宿教我的独立，是从情感那里收的利息」——判断句直接外露，最锋利也最抽象半档，发布后按回执决定要不要换。

开头骨架（30 秒，四拍）：

1. **0-3 秒，寒意开场**：「上周我骑摩托路过我母校，半个身子突然就凉了。」——身体证据直接上，零铺垫、零背景介绍。
2. **3-15 秒，蒙太奇**：学前班在那儿哭的画面切片，两三个就够，别讲全。
3. **15-30 秒，时间反差点题**：「在那儿哭的那年我六岁，现在我上大学了，路过还是会打寒颤。」
4. **中段放养老院类比**：「养老院的老人是后半生进去的，寄宿的孩子是情感刚要长的时候进去的。」——你素材里最锋利的一句，位置在中段，别放开头（开头留身体，中段留判断）。
5. **结尾 10 秒转场（家长落点）**：「如果你正在考虑送孩子去寄宿——多想一步：你省下来的时间，账会从他那里扣。」——念头在这落地。

全程纪律（聊天室裁决）：口语；不说「异化」，不说「情感成本」，只说「账」「扣」「付」。

### V1 第一批发布清单

闭环落地成表，这张表就是你的第一条视频的全部决策记录：

| 站 | 定稿 |
|---|---|
| 选题 | 寄宿寒意（真候选，素材池第 1 条） |
| 判断句 | 寄宿收走的账，从情感那里付 |
| 念头 | 送孩子寄宿前多想一步（家长向） |
| 要素 | 寒意、蒙太奇闪回、13 年、离开两年、养老院类比、开学众生相 |
| 结构 | 时间反差主轴 + 场景反差辅助 |
| 动作 | 经历型口播 |
| 标题 | 候选 1（A/B 备选：候选 3） |
| 开头 | 寒意 0-3 秒，零铺垫 |
| 结尾 | 家长落点 10 秒转场 |
| 发布位 | 建议视频号起跑（念头是家长向，家长在那里）；单平台跑通再谈矩阵 |
| 回填指标 | 完播率；评论区有没有人讲自己的寄宿故事（寒颤分布采集器）；家长向评论占比 |
| 排期 | 这条（沉重）下一条（图乐）交替——德西条款 |

发布位你有一票否决权：选你发得下去的那个平台。判断依据跟着念头走——家长向内容在视频号的密度高，同路人共鸣在抖音、B 站密；如果发小红书，xhs-title 那套标题公式要换装。

### 三个 skill 什么时候上岗

出口秤纪律：工具是编辑清单，先有稿再诊断，工具不代笔。

- **dbs-hook（开头诊断）**：你把开头 30 秒写成逐字稿，它上岗，查流失点。
- **dbs-resonate（文稿共鸣诊断）**：全稿写完、发布前跑一遍。
- **dbs-xhs-title（75 个标题公式）**：你定平台之后，发小红书才需要它。

所以顺序是：你写初稿 → 工具诊断 → 修改 → 发布 → 回填。

## 小结

1. 纠错：「30 岁」是我编的，真数字是 13 年寄宿 + 离开两年——「才两年身体还记得」比虚高的年头更狠。
2. 你的两格组合是第三条路：一个内容三层（同路人 / 系统 / 家长），成立；要修的只有结尾 10 秒转场给家长留落点。
3. 标题站机制：标题是承诺，开头是兑现的第一口；三个标题候选，V1 用身体证据版。
4. 开头四拍：寒意开场 → 蒙太奇 → 时间反差点题 → 中段养老院类比 → 结尾家长落点；全程口语，不说「异化」。
5. V1 清单已成表，从选题到回填指标全链定稿；三个 skill 等你的初稿上岗，工具不代笔。
