# 主题阅读｜学习计划

## 学习目标

完成这个课题后，你应当能够：

1. 区分基础阅读、检视阅读、分析阅读与主题阅读，并为不同任务选择合适层级。
2. 把一个宽泛主题压缩成可研究、可比较、有边界的问题。
3. 建立暂定书目，通过检视阅读筛选资料并修正研究范围。
4. 从多份资料中定位相关段落，建立中立术语、共同问题与争议地图。
5. 写出一份可追溯到来源、区分共识／分歧／未知、尽可能中立的讨论分析。
6. 在自己的真实主题研究上跑完一次最小主题阅读，并把个人判断作为后续应用层单独标明。

## 学习路径

1. 认清地图：分析阅读、检视阅读与主题阅读各自负责什么。
2. 定义问题：把宽泛主题压缩成可回答的研究问题，并设置边界。
3. 勘察领域：建立暂定书目，用检视阅读筛选候选资料。
4. 搭建比较框架：定位相关段落，统一术语，形成共同问题。
5. 构造争议地图：区分共识、分歧、条件差异、沉默与未知。
6. 完成真实演练：围绕你的课题产出一页中立讨论分析，并审查证据链；如需行动判断，再另设应用层。

> 学习路径会依据每一篇末尾的真实反馈调整；文章数量与顺序可以变化。
