# LLM Wiki 方法论｜学习计划

## 学习目标

（写成可检查的能力）

1. 能用自己的话说清「现查模式」与「知识编译」的差别，并各举一个自己生活里的例子。
2. 能把三层架构逐层映射到交互式学习真源，说出每层存什么、谁能写。
3. 能用摄入 / 查询 / 体检三个原子操作描述自己真源的维护流程，并说出 nashsu 两步摄入对这个流程的意义。
4. 能列出自己系统相对 nashsu 实现的 ≥ 3 个差量，并把 purpose.md 回填到一个真实课题试跑。

## 学习路径

1. 原理层（01–02）：为什么编译 → 三层架构
2. 操作层（03–04）：摄入 / 查询 / 体检 → 导航与方向文件（index / log / purpose / 审核队列）
3. 回填层（05）：知识空白检测 → 差量回填自己的真源
