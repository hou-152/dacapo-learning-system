# 迷失在中间：语言模型如何使用长上下文｜学习计划

## 学习目标

完成这个课题后，你应该能够：

1. 用自己的话复述《Lost in the Middle》的核心实验，准确说出自变量、控制变量和结果指标。
2. 区分“上下文装得下”“模型找得到”和“答案用得对”这 3 层能力。
3. 解释 U 型位置曲线，同时说清它受模型、任务和输入长度约束的证据边界。
4. 把论文转成一个可执行的位置鲁棒性测试，用于检查自己的 Agent、RAG 或长文分析流程。

## 学习路径

1. **看懂现象**：复原论文的受控实验与 U 型位置曲线。
2. **看懂测量**：比较多文档问答、键值检索、闭卷基线和 Oracle 基线。
3. **看懂边界**：检查模型架构、训练长度、查询位置和指令微调带来的差异。
4. **连接系统**：把论文映射到 RAG、长对话、Agent 上下文和规则文件。
5. **完成迁移**：为一个真实任务设计前／中／后位置交换测试，并形成判断卡。
