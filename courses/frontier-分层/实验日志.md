# frontier 分层实验日志

## 冻结的实验标准（2026-09-03）

1. **目标**：3-5 篇真实课程，验证 (a) 高频使用交互式学习的主导归因——A 性格适配 / B 前沿分层 / C 做中学（造工具才是学习）；(b) 新版 dbs-learning 能否跑通行为闭环（等级 2 证据）。
2. **单篇闭环定义**：反馈区选 A/B/C + 至少一条真实反馈 + 完成「试试看」+ 下一篇前回填调整结果，四项同时满足。
3. **成功判据**：闭环率 ≥ 80%；判断位移 ≥ 1 处（至少一处「这篇改变了我的一个判断或行动」）；第 3 篇后归因读数明确。
4. **归因判读**：主导动机「无聊逃避」→ A；「真实判断瓶颈」→ B；「想看工具跑得怎样」→ C。每篇开始前用户自记一句，转录后用户核对。
5. **反证信号**：≤2 篇反馈消失 → 闭环失败，按失败归因修 skill；反馈消失但改 skill 热情仍在 → C 成立；全闭环且动机以无聊/试工具为主 → A 主导。
6. **停止条件**：连续 2 篇无真实反馈 / 满 5 篇 / 用户喊停。
7. **复盘窗口**：第 3 篇后中期复盘；最迟 2026-09-17 关账。
8. **单变量纪律**：只验证、不改 dbs-learning 文件；课题中途不换，要换就结题重开。

## 白痴指数试算（第一样本，2026-09-04）

口径（九条术语已与用户确认）：指数 = (4 + 计划外重复步数) ÷ 4；4 步 = 读 → 试试看 → 选 A/B/C → 反馈一句；重复税 = 重新上手 / 同一卡点反复追问 / 返工重做 / 工具间来回切换，同一动作第 2 次起计；认知摩擦、计划内复习、第一次提问、错题循环第一轮不征税；试试看缺失不进指数（归闭环率管）。

| 篇 | 计划外重复事件 | 重复步数 | 指数 |
|---|---:|---:|
| 01 | 无 | 0 | (4+0)÷4 = 1.00 |
| 02 | 无（试试看缺失归闭环率，不进指数） | 0 | 1.00 |
| 03 | 同一卡点（结题指令）第 2 次表达「不太懂你问的是什么」 | 1 | (4+1)÷4 = 1.25 |

课题指数均值 = 1.08。
