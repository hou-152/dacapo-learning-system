# 沉淀：输出端断环的标准答案（dbs-standard-answer 研究）

日期：2026-09-04。输入：03 反馈中的命题「输出没有关闭条件，处方就是 MVP 和关闭句」+ 本课题实验证据。

## 直接答案

输出端有两个失败模式：启动失败（懒，摩擦过高）与终止失败（无限输出，无关闭判据）。MVP 治启动，关闭句治终止；两者都需要承诺装置外置。实验证据：三次跳过输出闸门、追问一次才过闸；草稿-确认模式一次过闸（摩擦降到「对/改」即输出）。

## 第一部分：知识与理论挖掘

### 命题审查

- 原命题：输出没有关闭条件；处方就是 MVP 和关闭句。
- 审查状态：保留 + 收窄（两个失败模式、两个处方、机制外置为第三要件）。
- 修正后：输出端有启动失败与终止失败两种模式；处方分别是最小单位与预写关闭句；两者都需要承诺装置外置。

### 理论地图

### 边界

发散阶段（选题、头脑风暴、写作早期）禁止关闭句；草稿与碎片允许不闭环，关闭只作用于最终交付。

## 第二部分：历史同构与标准答案

### 结构命题

个体知识工作者，依赖高可得性输入，被输入循环锁定，难以投入输出闭环建设，受完美主义与信息焦虑牵引。

### 历史案例

1. Lamott：一次一只鸟 + 烂初稿允许 → 启动失败的最小单位解。
2. 卢曼卡片盒：9 万张短卡片 + 链接重编 → 70+ 书、400+ 论文。最小单位 + 重编的复利证据。
3. 达尔文笔记：20 年零散小笔记 → 《物种起源》。最小笔记长成体系。
4. 富兰克林 13 美德：每日对照 + 一周一个变量。外置机制 + 单变量纪律。
5. 反例：Osborn 头脑风暴——发散期强制关闭杀死想法。
6. 失败样本：本实验用户——三次跳过输出闸门，handoff 追问后才过闸。

### 标准答案（条件性答案）

> 当任务属于产出型（有明确交付对象）时，反复有效的做法是：最小输出单位 + 预写关闭句 + 外置节奏约束。因为启动摩擦靠颗粒度降低，终止缺失靠执行意图补上，意志力波动靠承诺装置兜住。当任务处于发散探索阶段时，这个答案容易失效——碎片允许不闭环，关闭只作用于最终交付。

## 现实动作（3 个）

1. 关闭句前置：先写「我要拿它做哪个判断」，再写 2W2H。
2. 输入装 WIP 上限：欠关闭句的旧笔记达 3 条，停止新输入，先清欠。
3. 不新建自觉：把「每天一条最小笔记」挂进已有承诺装置（内参 365 挑战）。
