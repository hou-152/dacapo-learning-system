# dontbesilent 商业方法论｜学习计划

## 学习目标

- 能完整复述 dontbesilent 的翻身路径：失败三年 → 条件约束 → 第一桶金 → 方法论觉醒 → 内容爆发 → 被 AI 干掉 → 用 AI 重生 → 商业化。
- 能用自己的话讲清三大公理（营销即需求、模仿优于创新、目标驱动先于手段），并用它们分析一个真实生意。
- 能独立执行「找对标」：用三列 Excel 法（同行、预估收入、模仿难度）为任意赛道排出模仿对象。
- 能用 SOP 思维把自己想做的事拆成可交付的流程，并说清「内容即产品」的判断标准与一鱼多吃的操作。 
- 能说明「第一天就赚钱」作为生意检验标准的作用与边界。
- 能识别爆款内容背后的心理触发机制，并说明「方法的方法」的提取流程。
- 能讲清知识库与 Claude Code 流水线在内容生产中的分工，以及 dbskill 开源背后「知识编码」的逻辑。
- 能从 1,544 条推文中按主题检索并调用具体观点，用于自己的决策。
