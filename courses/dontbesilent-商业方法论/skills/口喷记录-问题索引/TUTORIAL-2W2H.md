# 口喷记录问题索引 · 使用教程（2W2H）

## What（这是什么）

「口喷记录-问题索引」是一个**把语音口喷记录变成问题索引**的标准作业流程技能。

输入：一段口喷记录（Typeless 导出 / 语音转文字 / 对话文本）
输出：一份按问题组织的索引（日期 + 问题 + 状态 + 出处）+ 一份"待答问题"清单

它不整理文字，不润色稿件。它只做一件事：**从你随口说的话里，挖出你真正在想的问题。**

---

## Why（为什么要用它）

你有 28 万字口喷记录（60 小时），但**字多不等于资产**：

- 散乱的记录，问 AI 什么都答不好——AI 找不到你关心什么
- 结构化的问题索引，AI 才能回答"我对 XX 的真实看法是什么""我反复纠结什么"
- 你反复问同一个问题 = 你的真实兴趣信号，散在记录里看不见，索引一列就现形

**一句话：没有索引的记录是素材，有索引的记录才是知识库。** 这个技能就是把素材变成知识库的那道工序。

---

## How（怎么用，四步）

### 第 1 步：给材料

把口喷记录丢进来。可以是一次性一大段，也可以是一个文件、一个时间段。

格式不限：粘贴文本 / 文件路径 / Typeless 导出都行。**记得告诉它时间范围**（哪几天/哪个文件），没有日期的索引不可用。

### 第 2 步：看它挖问题

技能会逐段读，每段回答三个问题：
- 这段在说什么？（一句话）
- 说话的人在问什么？（用你的原话）
- 这个问题答得出来吗？（能 / 不能 / 部分）

### 第 3 步：收索引

输出格式：

```
- 日期：2026-08-20
- 问题：我为什么总是反复重启 Logseq？
- 状态：未回答
- 出处：mic055_20260714
```

回答不了的问题会单独列在「待答问题」里——**别删，那是未来内容的种子。**

### 第 4 步：增量喂

下次有新记录，直接丢进来，说"继续"。它会追加到索引末尾，不重排旧条目；如果同一个问题又出现，会标注"重复出现于 YYYY-MM-DD"——重复就是信号，说明这件事你放不下。

**想跳过前 3 步直接看效果？** 直接问它："从这段记录里，我反复在想的问题是什么？"它会先挖问题再回答你。

---

## How much（需要多少投入，产出什么）

| 维度 | 预期 |
|---|---|
| **时间** | 第一批 1 小时记录约 10-15 分钟出索引；之后增量更快 |
| **质量** | 起步三条规则（每条记录≥1 个问题 / 标注原始日期 / 待答问题单独列），先粗糙后迭代，不追求一次完美 |
| **产出** | ① 问题索引（日期/问题/状态/出处）② 待答问题清单 ③ 高频问题统计（"你最近最常想什么"） |
| **门槛** | 零。不需要懂技术，只需要把记录丢进来、看索引、挑毛病 |
| **你的成本** | 唯一要做的事：**复核问题是不是你的原意**。挖错了就说"这句不是我想问的"，技能会改 |

## 常见问题

**Q：挖出来的问题不对怎么办？**
直接纠正："这句不是我的问题，我在想的是 XXX"。技能按你的反馈改，规则会记住。

**Q：一次喂太多处理不了？**
技能会建议分批：先处理一个时间段，跑通再扩大。不要一次塞 28 万字。

**Q：索引越来越多，怎么检索？**
直接问："2026 年 7 月我在想什么？""我关于找对标的问题有哪些？"——索引就是为这个建的。

**Q：这个技能以后能干嘛？**
索引攒够了，就是你的内容选题库、AI 训练素材、甚至下一门课的骨架。**先跑起来，再谈放大。**
