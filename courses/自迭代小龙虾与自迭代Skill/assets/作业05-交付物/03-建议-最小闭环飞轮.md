# 03 建议（最小闭环飞轮）

> 来源：06 篇学习反馈原文（你的作业建议，超规格交付）

## 主线判断

把「树林内容生产」做成一个能持续学习、自动执行、质量可控、经验可复用的 Agent 系统。「自动化写作 V2」是升级版；第一版「内容自动化系统」已荒废，只保留对 V2 有用的资产。

## 四个问题的答案

1. **输出窗口**：围绕现实新现象，用树林的知识框架形成判断，产出经过验证、能被用户发布并获得真实反馈的文章。当前窗口：候选稿 → 用户发布 → 反馈回填。大量产出停在候选稿，真实发布和反馈数据不足。
2. **减法**：砍掉第一版独立主线；砍掉没有反馈的批量生产；砍掉未被证明必要的架构（冻结的 Loop Engine、staged → formal 治理、复杂指标）。一句话：没有真实消费、没有反馈、不能改变下一轮决策的东西，暂不进入主线。
3. **自迭代**：证据 → 判定 → 小改动 → 下一轮验证 → 经验升级或回滚。每一圈只提炼 1 条可验证规则，下一篇真实文章再验证它。最小单位是「一条被下一轮证明有效的生产规则」。
4. **经验库**：观察层 experience-log.md（发生过什么）；教训层 memory/core/lessons-learned.md（跨任务错误模式和行动）；策略层（只收已验证有效的规则：适用条件、动作、证据、最近验证日期，待补「由谁验证」）。

## 最小闭环

一篇现实选题 → 一个 Task Packet → 一篇初稿 → 一次独立审计 → 用户发布 → T+7 反馈 → 提炼一条规则 → 下一篇验证。

飞轮跑通之前：不再扩张组件、不恢复批量生产。
