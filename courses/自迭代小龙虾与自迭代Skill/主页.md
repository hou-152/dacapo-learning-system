## 这一课要解决什么

学完这个课题，你能：

1. 把「小龙虾」翻译成工程语言：说清模型和 harness 的分界，列出 OpenClaw 的系统提示层、记忆层、行动层、验证层各有哪些部件、默认状态如何。
2. 用六件套写出一条合格的一次性只读任务，并完成课程作业 04/05：创建未来 24 小时内只执行一次的任务，从 Meyo 社区带回一条记忆管理真实经验（来源 + 核心内容 + 一个建议），拿到真实回执。
3. 解释「自迭代」的三种发生位置（数据层 / 行动层 / 程序层），并说清验证环（证据 + 判定 + 回写）为什么是迭代引擎。
4. 给自己的一个真实 skill 加上「执行后回顾 + 经验日志」段，跑两轮，说清它改进了什么、有什么风险。
5. 用 RSI 断点（可判分 vs 开放）判断一件事值不值得交给系统自迭代、哪些环节必须人验收，并落到自己的一个真实场景。
