# 01｜野马、马具、骑手、草原——理解 agent 的四元结构

## 这一篇要解决的问题

为什么用了 Claude Code 或 Codex，效果却差强人意？为什么同一个模型，有人能做出革命性的产品，有人只是换了个界面继续刷 AI？

这篇文章要建立一个框架，让你能回答这个问题。

---

## 正文

### 一匹野马不等于一套系统

你现在用的 Claude、GPT、Gemini，它们的底层是大语言模型（LLM）。裸模型本身已经非常强大——可以类比为一匹极具爆发力的野马。

但野马单独存在，没有方向，没有控制，也没有施展的场地。

野马本身是四元结构里的第一个元素。要让它产生价值，还需要另外三个——马具、骑手、草原：

**马具（harness）**：把野马变成可驾驭的坐骑。马鞍、缰绳、镫子，这套装备决定骑手能以多大的精度控制这匹马。在 agent 系统里，harness 就是模型之外的一切：系统指令、工具调用机制、记忆系统、安全护栏、上下文管理逻辑。Claude Code、Codex，本质上都是给不同底层模型套上的 harness。

**骑手（rider）**：决定这匹马往哪里跑。骑手是使用 agent 的人。模型再强、harness 再精良，骑手没有方向感，也只是在原地兜圈子。骑手的价值不在于操作技术，而在于他去向哪里——他在哪个领域有洞察、想解决什么问题。

**草原（personal context）**：骑手驰骋的地方。这是最容易被忽视，却最难被复制的部分。你在某个领域积累多年的经验、你处理信息的独特流程、你写下的 SOP 和 skill、你整理好的数据库——这些构成了你的 personal context，也就是属于你的草原。

这四个元素组合在一起，才是一个真正能产生价值的 agent 系统。

？为什么这……哦，四个元素：野马、马具、骑手和草原，就是我们这四个。我一下子以为是三样东西，原来有四个元素
---

### 为什么 harness 可以换，context 换不了

过去几个月里，许多深度用户的 harness 已经换了好几轮：OpenClaw → Notion Custom Agents → Claude Cowork → Claude Code / Codex。每次换，效果都有差异，但整套系统的核心能力——处理信息的流程、积累的 skill、对某个领域的理解——是连续的。

这说明 harness 是 **fungible（可替换）** 的，就像用哪家的电没有本质区别。而 personal context 是 **不可替换** 的：你在某个领域积累的东西，别人没有办法直接复用。

这也是为什么，即使两个人用的是同款 harness、同款模型，做出来的东西会天差地别。差别不在模型，也不在 harness，在骑手和草原。



---

### context 的精确定义

现在可以给出一个更精确的说法：

> **agent 在输出第一个 token 之前，接收到的一切 input，都是它的 context。**

这包括：你给它的 prompt，你事先写好的项目文档，你安装的 skill 和 MCP，它能访问的本地文件和数据库，以及底层的系统指令。

Context 是 agent 所有判断的基础。有一个老原则：garbage in, garbage out。对 agent 来说，这个原则更严格：context 的质量直接决定输出质量的上限。

同样道理对人也成立。每天刷短视频和每天读高质量文章的人，几年后的判断力会有结构性的差异。Context 是输入，输出只是结果。

---

### harness 的精确定义

对应地：

> **不是模型的部分，都是 harness。**

具体来说，当你使用 Claude Code 时，底层是 Claude 模型，其他一切——系统指令（CLAUDE.md）、工具调用框架、上下文压缩机制、worktree 管理、安全护栏——都属于 harness。

harness 本身很复杂，但作为用户，多数情况下不需要自己构建 harness。你用的是现成的 Claude Code 或 Codex，它们已经是 Anthropic 和 OpenAI 打包好的 harness。

你真正需要做的，是在这套现成 harness 之上，构建属于自己的东西——也就是自己的 skill、agent、工作流。这可以理解为**二阶 harness**：你在别人的基础设施上，又叠了一层自己的基础设施。

---

### 一个实际的例子

以 AI 内参这套系统为例，可以看到四元结构是怎么落地的：

| 元素 | 在这个系统里是什么 |
|------|------------------|
| 模型（野马） | Claude Fable 5 / Opus 4.8 |
| harness（马具） | Claude Code，提供工具调用、本地文件访问、context 管理 |
| 骑手 | 对 AI 信息流、内容质量有长期判断的人 |
| 草原 | 几百个精选信息源、多年积累的笔记、处理信息的 9 个 skill 和工作流、对高质量内容的品味标准 |

把「草原」换成另一个人的草原，这套系统做出的东西会完全不同。模型可以一样，harness 可以一样，结果不一样。

---

## 小结

1. Agent 系统由四个元素构成：模型（野马）、harness（马具）、骑手（人）、personal context（草原）。
2. Harness 是模型之外的一切，包括系统指令、工具、记忆、上下文管理等机制。
3. Context 是 agent 输出第一个 token 之前接收的一切输入，决定输出质量的上限。
4. Harness 可以切换和替换，personal context 是不可复制的核心资产。
5. 在别人提供的 harness 上构建自己的 skill 和 agent，是实践中最重要的工作。
