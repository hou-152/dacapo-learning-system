# context engineering 与 harness engineering｜学习计划

## 学习目标

- 能区分 context、harness、model 三个层次，说清楚它们各自的边界
- 能描述 context 的四个层级，知道每一层在实际使用中对应什么操作
- 能判断一个 agent 效果差的原因，出在 context 还是 harness
- 能设计自己项目的 context 结构（AGENTS.md、skills、prompt 习惯）

## 学习路径

1. **第一阶段：建立基本框架**
   - 野马 / 马具 / 骑手 / 草原四元结构
   - context 的定义：第一个 token 输出前的一切输入
   - harness 的定义：模型之外的一切

2. **第二阶段：深入 context 四层**
   - 第一层：system instruction
   - 第二层：项目文档（AGENTS.md / CLAUDE.md / docs）
   - 第三层：skills、MCP、个人工具箱
   - 第四层：prompt——把脑子里的 context 倒出来

3. **第三阶段：harness 的结构与选择**
   - harness 的组成原语（agent loop、runner、memory 等）
   - 不同 harness 的效果差异（本地 vs 云端，Claude Code vs Codex）
   - 二阶 harness：在现成 harness 上构建自己的 agent

4. **第四阶段：落地实践**
   - Single Source of Truth 的建立
   - 用看板（Linear / Notion）管理项目级 context
   - context 窗口管理与节约
