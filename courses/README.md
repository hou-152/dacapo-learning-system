# 课程真源

全部持久课程的唯一写入位置。新增课程只能建在这里，不得按工作目录另建课程根。

- `INDEX.md`：课程状态机械索引，由 `08-脚本与工具/rebuild_course_index.py` 生成，**不要手改**。
- 各课程目录的标准结构：
  - `00-学习计划.md`：学习目标、材料池、进度、占位（疑问）索引、反馈摘要。
  - `01.md`…：课程正文，文末带「学习反馈」区。
  - `结课-立项-*.md`：结课后留下的交付物、目标卡、红线与验收条件。
  - `assets/`：`选材/`（原文与索引）、`疑问/`（疑问卡）、`反馈上下文/`、用户材料。
  - `学习画布.canvas`：工作台生成的视图产物（JSON Canvas 1.0）。

## Agent 使用规则

- 找课先读 `INDEX.md`，再进对应课程的 `00-学习计划.md`。
- 已结课课程的正文不再改动；新增材料放 `assets/` 或另开新题。
- 课程正文、用户原话、Agent 连接分开保存，不互相冒充；文件存在不代表掌握。
- 引用原话时回 `04-用户原话与费曼/`；判定归属回 `05-证据原子/`。
