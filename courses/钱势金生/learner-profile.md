# learner-profile｜钱势金生首轮提炼

## 范围

本 profile 只基于《钱势金生》这一轮学习证据：答题、批注回应、`learner-log.md` 和 `[本人联想]` 边。它是首版，不是人格定论。

## 当前学习者画像

用户不是被动读者，更像“边读边把概念接到自己系统里的人”。

主要表现：

- 喜欢从第一性原理和长期主义出发做判断。
- 会主动把教材概念接到内容产品、亲密关系、表达、交易和行动接口。
- 费曼表达价值高，但会出现口误、跳步和半成品连接。
- 对“失败”有较强的重解释能力，倾向于把失败转成反馈。
- 对“行动接口”敏感，但写到最后一步时常常不够硬。

## 已观察到的强项

1. 概念联想能力强。能把钱格、行动接口、心灵货币、失败反馈接到自己的旧体系。
2. 抽象判断能力强。能用第一性原理、长期主义、人格压迫等框架判断赚钱机会。
3. 误差暴露诚实。04、04.5、07 里都直接说过不知道、没接上或只写半句，这让 loop 有机会修正。
4. 能接受补救篇。04 崩盘后插入 04.5，没有硬推 05，这是真正的学习证据。

## 已观察到的弱项

1. 行动接口容易停在方向，不容易落到“谁、何时、做什么、怎样算完成”。
2. 主动推荐自己的价值时，能写出对象和结果，但边界、验证标准和最小试验动作还不稳定。
3. 回锅测试弱于本篇检验，说明旧概念再调用需要继续训练。
4. 本人联想很多，但大多数还处于未验证状态，不能直接当事实使用。

## 后续教学参数

| 参数 | 设定 |
|---|---|
| 概念密度 | 保持，不因为卡住而删概念。 |
| 表达方式 | 用短链路、动作句和具体场景降低输出摩擦。 |
| 反馈回收 | 不再问“哪个概念全新”；概念新旧由库检索判断。 |
| 批注处理 | 读完一篇后必须先做批注回应报告，再决定入库和后文路径。 |
| 检验方式 | 保留 N-2 回锅；每轮至少 1 道迁移题或验边题。 |
| 入库规则 | 本人联想先标 `未验证`；经过碰撞后再升级。 |

## 未来优先训练题型

1. 行动接口题：把一句愿望改成一个最小动作。
2. 验边题：给一个新场景，判断旧联想是否成立。
3. 边界题：把主动推荐写得具体，同时避开过度承诺。
4. 复盘题：把失败拆成入口、对象、表达、信任、交付、价格等可修改项。

## 不能误读的地方

- 用户说“没懂”不等于要降密度，通常要换讲法和补动作。
- 用户的联想有价值，但默认未验证。
- 生成了新文章不算学习完成，只有答题、批注回应和路径改变算证据。
- CON 图谱是辅助复活，不是课程本身。

## 首版结论

下一课题启动时，可以直接带入这条 learner-profile：

> 这个学习者适合高密度材料，但每轮必须把抽象判断压到动作接口；批注价值高，需即时回应；本人联想先作为未验证边保存，通过迁移题和验边题逐步升级。
