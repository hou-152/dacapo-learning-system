# 拜物教｜学习计划

## 学习目标

你已在第 1 篇反馈中选定马克思的商品拜物教路线。继续学习后，你应当能够：

- 区分“拜物教”在宗教／人类学、马克思政治经济学和性偏好语境中的不同含义；
- 用自己的话说明“商品拜物教”的问题意识，并用一个现实商品、品牌或平台案例检验“哪些关系被物的形式遮蔽了”；
- 区分商品拜物教、技术黑箱／算法权威与拟人化／过度委托；
- 用一项具体 AI 服务的材料，而非泛泛的行业印象，检验你的判断。

## 课程范围

第 1 篇完成术语辨析。你已选择 A 路线：马克思的商品拜物教。第 07 篇以 Claude Code 辅助建立的视频工作流为例，拆开部署、培训、代做和模板四种交换对象，并将 Agent 元技能、心理按摩假设和完整单位经济放入同一张分析图。
