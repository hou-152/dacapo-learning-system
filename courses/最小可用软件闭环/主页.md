## 这一课要解决什么

亲手完成一个最小软件闭环，最终产出一个**可运行、可展示、能通过自己验收**的作品。拆成可检查的能力：

1. 能写出一个真实困境卡（四行 + 四问，落地到自己的具体场景）；
2. 能把这个困境收缩成最小闭环 + 列出明确的非目标；
3. 能和 Agent 真实完成一轮"复述→追问→比较方案→定最小版"的对话；
4. 能接一份真实数据/来源并验证它真的进了链路；
5. 能完成一次真实返工（复现步骤 + 实际 vs 期望 + 证据，修完跑回归）；
6. 能回到原始困境亲自验收，产出一个可打开、可操作、别人能看的作品。
