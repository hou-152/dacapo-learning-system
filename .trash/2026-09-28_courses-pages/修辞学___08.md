# 08｜结构：一篇文章怎样从开头走到结尾

## 这一篇要解决的问题

上一篇你主要高亮了开头的任务、张力来源、防御点和 Agent 开头生成卡。这一篇讲结构：开头把读者接进来以后，正文怎样一步步推进，让判断从一句话变成一篇能读完、能相信、能行动的文章。

## 正文

### 本篇基于的反馈

我从你的 Reader 高亮里看到 4 个理解状态：

1. 你继续抓住了开头的核心任务：相关性、张力、让读者先跟着判断走几步。
2. 你高亮了“那句判断从哪里来”，说明你仍然在守住判断不能外包的边界。
3. 你关注防御点，尤其是过早说“逃避思考”会让读者进入自我辩护。
4. 你高亮了 Agent 开头生成卡和张力来源，说明你在把执行层的术拆成可交给 Agent 的模块。

所以这一篇继续走工程化路线：把一篇文章拆成可以检查、可以外包一部分、但核心判断仍由你负责的结构。

### 1. 结构的任务是安排读者的理解顺序

文章结构承担的工作比目录装饰更重。它决定读者先看到什么，后相信什么，最后愿意做什么。

还是用这句判断：

> 判断不能外包，执行层面的术可以外包。

如果直接展开成一堆观点，读者可能会觉得有道理，但读完以后不知道怎么用。

更稳的结构是：

1. 开头：把读者带进 AI 写作的真实场景。
2. 问题：指出效率提高后，判断质量没有自动提高。
3. 区分：把“判断”和“执行层面的术”分开。
4. 机制：解释为什么 Agent 擅长展开，难以替你产生长期问题意识。
5. 边界：列出哪些任务适合交给 Agent，哪些任务要你先决定。
6. 动作：给一张卡，让读者下次使用 Agent 前先写核心判断。

这就是结构。它负责安排读者的理解路线，而不只是把内容排整齐。

### 2. 一个通用结构：场景、问题、机制、边界、动作

很多方法论文章可以先用这个结构：

1. 场景：读者在哪里遇到这个问题？
2. 问题：这个场景里真正卡住的点是什么？
3. 机制：为什么会这样？
4. 边界：这个判断在哪些情况下成立，在哪些情况下要调整？
5. 动作：读者现在能做什么？

拿“AI 写作”举例。

场景：

> 你打开 AI，让它帮你写文章。它很快给出标题、结构、案例和金句。

问题：

> 内容看起来完整，但你总觉得少了一口气。那口气通常来自判断，表达流畅度补不上它。

机制：

> AI 擅长沿着已有输入展开。你给它清楚判断，它能补结构、例子、反例和不同开头。你只给主题，它会优先生成通用内容。

边界：

> 当你已经有判断，Agent 很适合做执行层面的术；当你还没有判断，先回到阅读、观察、实践和复盘。

动作：

> 下次让 Agent 写之前，先写 3 行：我判断什么、读者是谁、读完要做什么。

这 5 步能把文章从“有观点”变成“能推进”。

### 3. 结构要处理读者的防御

前一篇你高亮了一个防御点：

> 你让 AI 帮你写文章，其实是在逃避思考。

这句话锋利，但很容易让读者自我辩护。

结构可以帮你降低防御。关键是先拆分，再判断。

先拆分：

> 用 AI 写文章时，容易混在一起的有两件事：让 AI 执行表达任务，和让 AI 替你完成判断。

再判断：

> 前者可以提高效率，后者会让文章看起来顺滑，但判断质量变薄。

再给行动：

> 所以写作前先交付给自己一张判断卡，再把执行任务交给 Agent。

这个结构没有削弱判断，反而让判断更容易被接住。读者先看到分类，再看到风险，最后得到动作。

### 4. 结构要留出反例位置

文章结构里要给反例留位置。没有反例，文章容易显得太满。

比如你说：

> 判断不能外包。

读者心里会出现反例：

> 有时候 AI 给出的判断也挺好。

> 有时候我就是想让 AI 帮我开脑洞。

> 有时候我没有判断，但 AI 能帮我整理材料。

这些反例都值得处理。

可以这样写：

> AI 可以帮你生成候选判断，也可以帮你把材料整理成几个方向。但最终采用哪个判断、为什么采用、要把读者带向哪里，需要你负责。

这样写以后，文章边界更稳。它承认 Agent 的价值，同时保住核心责任。

### 5. 给 Agent 的结构生成卡

现在你已经有三张卡：

- 论证卡：判断、场景、证据、机制、反例、动作。
- 开头生成卡：核心判断、读者状态、防御点、张力、入口版本。
- 结构生成卡：安排一篇文章从开头到结尾的推进顺序。

结构生成卡可以这样写：

```markdown
## 核心判断
判断不能外包，执行层面的术可以外包。

## 目标读者
正在用 AI 写文章、做内容、做课程的人。

## 开头入口
场景入口：读者用 AI 写文章，内容很顺，但总觉得少了一口气。

## 正文结构
1. 场景：AI 能快速生成标题、结构、案例和金句。
2. 问题：表达效率提高了，判断质量没有自动提高。
3. 机制：AI 擅长展开已有判断，难以替你承担长期问题意识。
4. 边界：AI 可生成候选判断，但最终采用和负责的人是你。
5. 动作：写作前先写 3 行判断卡。

## 结尾动作
给读者一张“交给 Agent 前的判断卡”。
```

Agent 可以根据这张卡生成初稿。你再检查 5 件事：

| 检查项 | 问题 |
|---|---|
| 顺序 | 读者是否从熟悉场景进入，再走到判断？ |
| 机制 | 文章有没有解释为什么会这样？ |
| 边界 | 有没有处理合理反例？ |
| 动作 | 结尾有没有具体下一步？ |
| 判断 | 全文有没有围绕一个核心判断展开？ |

这时 Agent 做的是结构执行。核心判断、读者选择和责任边界仍然由你给出。

## 小结

- 结构的任务是安排读者的理解顺序。
- 一个可复用结构是：场景、问题、机制、边界、动作。
- 结构可以降低防御：先拆分，再判断，再给行动。
- 反例要在结构里有位置，它能让判断更稳。
- 给 Agent 的结构生成卡，应该包含核心判断、目标读者、开头入口、正文结构和结尾动作。

## 下一篇预告
