# 费曼学习法

用自己的语言解释一个概念，直到能让他人听懂。暴露理解缺口，而不是掩盖它。

## 在 dbs-learning 中的应用

- **费曼速度循环（use）**：以终为始 → 最小知识地图 → 任务化费曼 → 真实任务 → 高杠杆反馈
- **Learner-first 费曼循环（master）**：定焦 → 先生成 → 诊断 → 最小补救 → 重新生成 → 变式迁移 → 路由
- 核心判据：学习者没有照着答案，用自己的话生成解释、判断或方案
