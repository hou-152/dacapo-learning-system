### What 1：成绩、技能与智力分别是什么

可以先建立三个层次。

#### 成绩：这一次做得怎样

成绩是某个任务、某套评价标准和某个时间点上的输出。考试分数、代码测试通过率、内容点击率、图片偏好胜率，都属于成绩。

成绩高度依赖任务边界。一个系统在题库分布内成绩很高，进入新分布后可能迅速失效。

#### 技能：在一类任务上稳定做到什么

技能比一次成绩更稳定。它意味着系统在某个领域形成了可以重复调用的行为结构，例如解某类方程、生成某种画面、修复某类代码错误。

技能可以来自模型内部，也可以由整个系统共同承载：模型负责推理，Skill 提供程序，工具执行动作，记忆保存经验，Evaluator 拦截错误。

#### 智力：用多少新经验获得多大范围的可迁移技能

François Chollet 在《On the Measure of Intelligence》中提出了一个非常适合本课的定义：智力可以理解为一个系统在给定先验、经验和任务范围下的**技能获得效率**。论文特别区分了任务技能与智力，因为大量先验知识或训练经验可以买到很高的任务表现，却可能遮住系统面对新问题时的泛化能力。[来源：Chollet，2019](https://arxiv.org/abs/1911.01547)

这涉及先验知识或者训练经验，它们可以买到很高的任务表现。而这种表现会在一定程度上转化为“元学习”的能力（我更愿意把这种泛化能力称为元学习能力）。

元学习的能力非常重要，甚至可以说，这是我们一生的课题。

沿用这个口径，可以写出一个概念式：

> 技能获得效率 ≈ 面对新任务形成的可迁移能力增量 ÷ 新增经验与外部干预成本

这个概念式只承担课程中的概念区分，不属于现成的心理测量公式。
分子看学会了多少、能迁移多远；分母看用了多少例子、反馈、算力和教师干预。



于是，你的两个学生可以拥有接近的考试技能，同时呈现不同的技能获得效率。

### Why 1：为什么第一类学生让你感到“有灵性”

你喜欢和第一类学生聊心理学、社会学，因为他能跨领域接住结构。这里至少包含两种合理解释：

1. 他在更广的领域积累过隐性经验，只是这些投入没有表现为刷题；
2. 他能用较少的新信息形成更高层的表征，并把表征迁移到陌生主题。

仅凭日常观察无法确定两者各占多少，所以“灵性”不能直接等同于高 IQ。不过，你感受到的跨领域生成力，确实比单科分数覆盖了更大的任务范围。

经典的专家—新手研究提供了一个可用线索。Chi、Feltovich 与 Glaser 让物理专家和新手给题目分类，研究发现两者组织问题的方式存在差异：专家更多依据底层物理原理，新手更多依据题面对象和表面特征。[来源：Chi 等，1981](https://onlinelibrary.wiley.com/doi/10.1207/s15516709cog0502_2)

这揭示了表征的价值：

```text
表面表征：这道题长得像我做过的哪道题？
结构表征：这道题由什么变量、关系和约束组成？
```

结构表征压缩了题目数量。一个抽象关系可以覆盖许多表面不同的问题，所以强学习者需要的例子更少，迁移范围更大。

### Why 2：刷题可以把结果推近，却不保证一般能力收敛

反复练习会积累领域技能。它能让第二类学生在熟悉分布上非常强，甚至超过天赋更高但缺少训练的人。

练习的作用也有边界。一项覆盖音乐、游戏、体育、教育和职业领域的元分析发现，刻意练习能够解释一部分成绩差异，解释比例随领域显著变化；研究结论没有支持“练习可以解释全部差异”。[来源：Macnamara 等，2014](https://www.psychologicalscience.org/journals/psychological-science/0956797614535810/)

你的“差距并不大”需要补上作用域：

> 在训练充分、目标稳定、评价指标明确的狭窄任务中，两条路径的可观察成绩可能收敛。


在“地球 Online”这个大世界开放游戏里，很多问题是没法直接用成绩去解释的。它的大多数指标既无法量化，也没有教程，更没有像分数这种可以作为替代的考核指标。

正因如此，当我们面对这种开放性问题的时候，很容易陷入“自我感觉良好”或“过度归因”的陷阱，比如一些（厚黑学）强行归因。

换到陌生问题、跨领域迁移或评价标准突然变化时，差异可能再次扩大。学校考试尤其容易把范围压窄，因此它能测到任务技能，却很难单独说明一个人的广泛适应能力。

### What 2：人类学习与当前 Agent 学习存在一个断点

学生在一次次反馈中，长期记忆、问题表征和策略可能发生持久变化。下一次遇到问题时，学习者本身已经和上一次有所不同。

许多当前 LLM Agent 使用固定的底层模型。一次调用结束后，模型参数没有变化。它看起来“学会了”，可能来自三种外部变化：

- 新经验被放入下一轮上下文；
- 反思被写进外部记忆；
- 成功动作被保存为可检索的 Skill。

`Reflexion` 明确使用语言反馈和情景记忆改善后续决策，同时不更新模型权重。[来源：Shinn 等，2023](https://arxiv.org/abs/2303.11366) `Voyager` 通过自动课程、技能库和环境反馈持续积累能力，也绕过了模型参数微调。[来源：Wang 等，2023](https://arxiv.org/abs/2305.16291)

这些系统确实发生了学习，但学习的载体位于 Agent 系统层：

```text
固定模型
＋不断变化的记忆
＋不断增长的 Skill 库
＋不断调整的课程与反馈
＝越来越有能力的 Agent 系统
```
对，就是这些东西要放进脑子里面的，肯定是要克制的。比如说我们生物学意义上的长期记忆、短期记忆和工作记忆，这个记忆本身是在不断变化的。

关于我们提到的几个模块，我是这样理解的：

1. Skill 库（技能）：
   虽然平时不知道有什么用，但它可能在某个瞬间去积累，并不断进行调整。

2. 课程和反馈：
   我觉得这是一种“元认知能力”和“对技术世界的认知能力”。

在 GPT-4 转向 o3 的过程中，它一开始是从一个通用的大语言模型转向了一个推理模型。在这个转变中，虽然我很讨厌用“文理分科”这种表达，但这里确实可以体现出这种变化：
* 它是从语言模型转向了推理模型，也就是说，语言模型是推理模型的基础。
* 而不断调整的课程反馈，则是为了增加我们的通用知识和元知识，进而帮助我们转向推理方向。


因此，“Agent 变聪明了”至少有四种含义：

| 变化位置 | 发生了什么 | 更准确的说法 |
|---|---|---|
| 当前上下文 | 本轮得到例子、提示或反馈 | 会话内适应 |
| 外部记忆／Skill 库 | 经验跨任务保留下来 | 系统积累了技能 |
| 模型参数 | 训练或微调改变内部表征 | 模型学到了能力 |
| 学习机制 | 新任务只需更少经验即可掌握 | 技能获得效率提高 |

前两种足以显著提高任务成绩。后两种更接近“学习者本身发生改变”。

还有就是我自己实践出来的，用“道、法、术、器”的框架去积累的一些心得。

如果用这个框架来看，我们个人作为 人肉 Agent 的智能是有限的。我们的上下文窗口，包括我个人，就是一个非常显著的“短上下文窗口”的人。

### What 3：Harness 能把低能力 Agent 补到什么程度

然后我在想，Harness 对应我们个人到底是什么呢？就是用我前面写的，对照在“人”的这个比喻到底是什么？

Harness 对弱模型的帮助可以分成三层。

#### 第一层：补偿

把大问题拆小、限制行动空间、提供模板、增加检查器，让弱模型少犯错。这相当于教辅、口诀和监考。

补偿提高可靠性，也会产生支架依赖。任务稍有变化，旧规则可能失效，系统需要人继续补洞。

#### 第二层：积累

把成功经验沉淀成记忆、Skill 和可复用程序。系统下一次无需从零开始，教师的重复劳动被转化成基础设施。

这时教师工作没有消失，它改变了位置：

> 总教学负担＝即时指导＋Harness 设计＋反馈标注＋长期维护

弱模型配厚 Harness，可能显著降低即时指导；同时，设计和维护成本会上升。强模型的优势常常表现为它在陌生任务上需要更少的支架和修补。

#### 第三层：提高可教性

系统从许多任务中学到“怎样更快学会新任务”。元学习研究把这个目标表述为：在多种任务上训练模型，使它面对新任务时，只需少量样本和少量更新就获得良好泛化。[来源：Finn、Abbeel 与 Levine，2017](https://proceedings.mlr.press/v70/finn17a)

这一层改变的是学习效率。它对应你问题里最接近“低智向高智转变”的部分。

### Why 3：认知架构究竟指什么

世界模型描述智能体怎样理解世界。认知架构描述观察、记忆、推理、评价和学习怎样组织成一个持续过程。

在这门课里，可以把认知架构压缩成四个问题：

1. **怎样表征**：系统抓住表面特征，还是形成变量、关系与因果结构？
2. **什么被保留**：一次成功只留下答案，还是沉淀为可迁移的规律？
3. **怎样发现误差**：系统能否区分不知道、做错了和环境已经变化？
4. **反馈改变哪里**：改变当前输出、外部记忆、模型参数，还是学习新任务的方式？

所以，知识量只是认知架构处理的对象之一。更深的区别落在**更新算子**上：同样收到一次反馈，系统究竟如何改变自己。

低能力 Agent 经常需要人逐条规定行为，因为它从一次反馈中提取的可迁移结构很少。高能力 Agent 能从少量反馈里推导更广的规则，也能判断哪些规则只适用于局部。

### 回答你的核心问题：低能力 Agent 能不能转向高能力

答案取决于你要改变哪一层：

- 追求特定任务结果：可以依靠工具、记忆、规则、搜索与反馈，让弱模型逼近强模型；
- 追求跨轮次成长：需要让经验进入持久记忆或 Skill 系统，并经过验证和检索；
- 追求模型内部能力：需要训练、微调或其他参数更新机制；
- 追求更高智力：需要提高面对新任务时的技能获得效率与迁移范围。

更多 Loop 可以增加经验。Loop 中有没有把经验压缩成可迁移结构，决定了系统是在重复受教，还是逐渐变得好教。

这也给“让老师省心”一个更严格的定义：

> 省心程度取决于系统面对新问题时，需要多少新增指令、反馈和维护，才能形成可迁移的正确行为。

一个系统在旧题库里全自动运行，只能证明旧题已经被工程化。进入新题仍能快速学习，才提供了更强的智力证据。

## 小结

1. 成绩衡量一次输出，技能衡量一类任务上的稳定表现，智力更接近跨任务的技能获得效率。
2. 两类学生可以取得相近分数，同时在所需经验、支架依赖和迁移范围上保持显著差异。
3. 当前 Agent 的成长可能发生在上下文、外部记忆、Skill 库、模型参数或学习机制中，需要说明变化的位置。
4. Harness 能补偿弱模型并积累系统技能；任务越新，支架成本与迁移能力越能暴露两类系统的差异。
5. 认知架构的核心问题是反馈怎样改变系统，以及改变能否压缩成可迁移结构。
