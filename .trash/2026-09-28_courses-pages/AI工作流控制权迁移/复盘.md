## How

**教学机制**：每篇遵循 v4.5 交互式学习方法论——

1. 读上一篇的学习反馈、费曼练习、检查站
2. 按四个维度诊断：准确性 / 机制 / 边界 / 迁移
3. 判断 route：advance（继续）/ recalibrate（重讲）/ bridge（桥接缺口）
4. 下一篇的主题、深度、角度由诊断结果决定

**关键自适应事件**：

- **02 重写**：旧版用「仓库 vs 工作台」隐喻，学习者反馈「？不懂」「检测站」。新版用 5 分钟前刚发生的真实内参检索（15 篇→3 篇）当例子，概念落地。
- **03 重写**：预生成版讲 Skill 设计哲学，跳过了学习者当前的缺口（搜索机制不懂、Loop 理解停留在字面）。重写版用学习者自己找文章的过程当 Loop 演示材料。
- **05 错误推进被学习者叫停**：学习者在 04 反馈还没写的情况下，系统推了 05。学习者说「等一下，我还没有呢，我还没学完你就推是什么鬼？」→ 05 撤回至 .trash。事后在 05 里这件事被用作「Harness 规则层在工作」的实例。
- **三篇内参文章成为课程证据**：学习者在 02 费曼练习里自己搜了 4 篇内参文章想推翻课程判断。其中 3 篇（Harness Engineering / Skills→可复用工作流 / Agent 注意力瓶颈）成为 04 的核心证据——不是教材料指定的，是学习者自己选的。

**关键学习跃迁**：

1. 「来源池和证据包」从概念到操作：学习者实际执行了一次检索→筛选→区分「入选」和「有用但不入选」
2. 「Harness」从黑箱到自己的系统：从「真不理解」到「Claude Code 就是 DeepSeek 的 Harness」
3. 「厚 Harness 薄 Skill 强模型」独立推导：与 GPT 对话后推翻了 GPT 的结论，合成到课程框架
4. 「Loop = 负反馈调节」：连接控制论和生物学底层原理

## How Good

**学习者形成了自己的判断**（不是复述课程内容，而是基于证据的独立判断）：

> AI 工作流的控制权正在从模型内部迁移到模型外部。驱动力来自模型能力内化 + 工程控制点迁移 + 人的注意力瓶颈三重叠加。最终形态是厚 Harness + 薄 Skill + 强模型：Harness 管调度验证和边界，Skill 只写模型不能推断的东西，人只在高价值判断节点介入。

**三条独立的个人洞察**（不是被教的，是自己走通的）：

1. 「能外包思考过程，不能外包理解本身」（04）
2. 「厚 Harness、薄 Skill、强模型」（05）
3. 「Loop 就是负反馈调节」（08）

**验证方案已建立**（怎么知道这个判断是错的）：

- 验证 1：模型继续变强，Harness 反而变薄 → 推翻「厚 Harness」判断。观测方式：每半年盘点 CLAUDE.md 规则数量
- 验证 2：人的介入频率不降反升 → 限定「注意力瓶颈驱动 Loop 设计」判断。观测方式：记录一个月内主动介入次数
- 验证 3：薄 Skill 在实践中反复失败（失败率 > 30%）→ 限定「薄 Skill」判断。观测方式：改薄一个真实 Skill，跑 10 次

**学习者自己能做的事**（结业时可验证的能力）：

- 为一个真实任务定义来源池、证据包和任务锚点
- 将任意 Skill 改写为「触发条件+输入+动作+验证」四字段薄格式
- 用「心跳→输入→处理→验证→决策」五阶段画一个最小 Loop
- 认出自己系统里已经存在的 Harness 层（规则/记忆/工具/验证/公理）
- 为任何一个判断写可被事实修正的验证方案
