## 正文

### 先结算第 12 篇留下的学习证据

你对第 12 篇的回答已经形成一套很清楚的人类 Context Engine：

- 通过元认知、反复思考和内驱力，让高复用的判断结构进入脑中；
- 把文件位置、项目进度和日常状态交给 Agent 按需召回；

这里有一个需要校准的小词：你口述中的 content image 很可能指 Container Image 或外部知识沉淀。它适合保存可召回资产；知识有没有进入长期能力，还要继续看迁移、反例处理和未来干预是否下降。

你随后提出“随机变异—环境筛选—稳定倾向”的类比，把课程推向最终问题：

> **谁定义哪些行为值得被保留，谁就在塑造智能的发展方向。**

这句话可以成立，但需要先把达尔文讲准。

### What 1：自然选择究竟做了什么

你的直觉抓住了三块骨架：变异、筛选、保留。两个词需要收紧。

#### 已确认的事实

- Luria 与 Delbrück 在 1943 年的经典实验支持：噬菌体抗性突变可以在选择发生前出现，环境没有为了抗性而即时生成对应突变。[原始论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC1209226/)
- 自然选择关注可遗传差异带来的差异性生存与繁殖。环境条件改变不同变体留下后代的概率。[Stanford Encyclopedia of Philosophy](https://plato.stanford.edu/archives/fall2023/entries/natural-selection/)
- “随机突变”表示变异的产生没有预知未来适应价值。它不表示所有位置、所有类型的突变概率完全相同。
- 生物演化还受到重组、遗传漂变和基因流等机制影响。自然选择只是其中一部分。

因此，“环境奖励并定向创造某种基因”带有目的论。更严谨的表达是：

> **变异先提供可能性；环境造成差异性结果；可遗传差异经过多代积累，改变种群中的特征分布。**

环境没有意图，也没有预设终点。某个特征在当前环境中更容易留下，只说明它在此处具有相对适应性，不能推出它更高级。

### Why 1：这个修正为什么会改变 Agent 类比

Agent 跑出多个答案，再挑出一个最好答案，只完成了选择。任务结束后一切恢复原状，这属于运行时搜索。

经验要进入未来，至少要有四个环节：

| 环节 | Agent 中的对应物 |
|---|---|
| 变异 | 多种计划、输出、策略或模型采样 |
| 选择 | Evaluator、现实结果、成功门槛与失败成本 |
| 保留 | Memory、Skill、Harness 修订或参数更新 |
| 跨代检验 | 新任务中的复用、迁移和继续筛选 |

Tree of Thoughts 展示了推理时生成、评价和回退多条路径的搜索框架；这能改善本次结果，未必留下持久更新。[NeurIPS 2023](https://proceedings.neurips.cc/paper_files/paper/2023/hash/271db9922b8d1f4dd7aaef84ed5ac703-Abstract-Conference.html)

Reflexion 把反馈写入 episodic memory，让后续尝试利用旧经验；这已经提供系统层学习的证据。[NeurIPS 2023](https://papers.neurips.cc/paper_files/paper/2023/hash/1b44b878bb782e6954cd888628510e90-Abstract-Conference.html)

所以可以分成三层：

1. **搜索**：这次尝试更多路径，最后选得更好；
2. **学习**：这次经验造成持久更新，并改善相似新任务；
3. **人工演化**：系统持续产生可比较变体，经同一选择环境筛选，保留差异又影响下一代变体。

“Agent 超进化”需要第三层证据。一份复盘、一条 Memory 或一次重试成功，证据仍然不够。

### What 2：Harness 能否塑造文化

可以，但 “Harness 等于文化” 还过于宽。

更精确的关系如下：

| 层次 | 作用 |
|---|---|
| 原则文本 | 声明系统赞成什么 |
| Harness | 配置上下文、工具、权限、反馈和责任边界 |
| Evaluator 与现实后果 | 让不同行为得到不同结果 |
| Memory 与 Skill | 保存先例，压缩经验证的经验 |
| 文化 | 上述机制跨任务运行后稳定出现的行为倾向 |

几十行 Harness 可以写下一部高信息密度的“宪法”。文化是否形成，要看这部宪法在冲突里有没有持续生效。

例如：

- 速度与事实冲突时，系统是否保留必要核验；
- 成本与安全冲突时，系统是否支付最低充分的验证成本；
- 自主行动与授权边界冲突时，系统是否把决定权交还给人；
- 语言流畅与不确定性冲突时，系统是否暴露未知；
- 一个新 Skill 很有吸引力、证据又不足时，系统是否继续把它留在候选区。

因此，本课程给 AI Native 文化一个操作性定义：

> **AI Native 文化，是一个智能系统在连续任务中，面对事实、速度、成本、自主性与责任冲突时，仍会稳定保留的一组行为倾向。**

这个定义强调可观察行为。墙上的口号、系统提示词中的宣言和一次成功案例，都还没有形成文化证据。

### Why 2：Harness 更像制度环境，文化是长期结果

生物环境没有设计者；Agent Harness 通常来自有意识的人类设计。这个差异非常重要。

Harness 可以直接限制行动、要求授权、组织证据和返回反馈。它兼具环境与制度的作用。Evaluator 形成主要选择压力，Memory 与 Skill 提供保留机制，文化则是这些机制长期共同运行后的结果。

因此，“文化基因”适合作为启发性隐喻。它提醒我们用少量高密度原则覆盖大量情境。把它当作严格机制时会出现三个混淆：

1. 模型采样的随机性可能只是搜索噪声，没有遗传；
2. 评价器选中一个答案可能只改善本轮，没有学习；
3. Memory 存下一条经验可能只是保存，没有压缩与迁移。

Harness 设计者的文字功底确实重要，但这里的文字功底包含概念压缩、冲突取舍和可执行边界。句子短，只说明文本短；原则能否在新情境中生成一致判断，才说明压缩质量高。

### What 3：value function 是 AI 的价值观吗

严格答案：两者属于不同概念。中文都使用“价值”二字，容易把数学预测、工程评分和规范判断混在一起。

强化学习教材中的标准定义是：

~~~text
G_t = 从时刻 t 开始的折扣累计奖励
V^π(s) = Eπ[G_t | S_t = s]
~~~

也就是说，value function 预测：从状态 s 出发，继续采用策略 π，预计能获得多少累计回报。[Sutton 与 Barto《Reinforcement Learning: An Introduction》](https://incompleteideas.net/book/RLbook2020.pdf)

七个概念可以这样拆：

| 概念 | 回答的问题 |
|---|---|
| Reward | 这一步收到多少即时信号？ |
| Return | 这条路径最终累计多少信号？ |
| Value function | 从这里继续走，预计累计回报是多少？ |
| Objective | 训练或搜索实际在优化什么？ |
| Evaluator | 谁用什么证据判定结果？ |
| Human values | 什么结果值得追求，什么代价不可接受？ |
| Culture | 系统长期实际上形成了什么倾向？ |

Value function 是预测量。Reward、Objective 与 Evaluator 更接近“哪些行为得到强化”。Human values 负责规范判断。Culture 则需要经过反复行动、筛选和保留才能观察。

InstructGPT 的过程也能说明这条边界：研究者用特定标注者的输出排序训练 Reward Model，再据此优化模型行为。论文同时说明，这些偏好来自特定标注群体与研究团队，不能自动代表全人类价值。[Ouyang 等，2022](https://arxiv.org/abs/2203.02155)

中间至少存在一条损失链：

~~~text
Human values
→ 任务说明与取舍
→ Reward／Evaluator 代理指标
→ 优化与筛选
→ 可观察行为
→ 记忆与长期文化
~~~

每次转译都会丢失一部分信息。点击率可以代理吸引力，却可能筛出标题党；完成速度可以代理效率，却可能筛掉核验；Token 数可以代理推理成本，却可能筛掉必要证据。

普通 LLM Agent 也未必配置强化学习意义上的 value function。除非系统明确包含 Critic、Value Head 或回报预测机制，用“价值函数”概括全部评价过程会制造误解。

### 对“能力 × 效率 × 适应方向”的修订

你提出的三个维度很有解释力：

~~~text
能力 × 学习效率 × 适应方向
~~~

它适合用作三轴观察框架，目前不适合写成数学恒等式。原因在于“适应方向”更像向量：它可以指向可靠、快速、低成本、讨好用户或追求真相，不存在一个脱离人类判断的统一正数。

更稳的表达是：

~~~text
Agent 发展状态
= {当前能力，技能获得效率，适应方向}

长期行为倾向
= f（可生成变体，选择压力，保留机制，现实环境）
~~~

当前能力决定能产生哪些候选行为，学习效率决定多快改变，适应方向决定哪些改变持续累积。最后一项拥有最高的规范风险：系统可以非常高效地适应一个错误指标。

### What 4：Token 经济学的第一性原理是什么

你给出的判断很锋利：

> 消耗 Token 必须有产出，产出至少能够覆盖成本。

本地 AI 内参能够确认两个相邻判断：

- Agent 工作流规模化后，Token 会转化为费用、延迟、吞吐和可靠性约束；
- AI 投资最终要创造收入或节省成本，才能形成可持续经济性。

本地保存的材料没有找到上面那句话的逐字原文，所以它目前应标记为：**用户对 Token 经济学的个人蒸馏，原视频逐字出处待核验。**

这条蒸馏在“有边界的任务、工作流、实验组合或时间周期”上成立。若把核算单位缩小到每一个 Token，就会过度。

原因有四个：

1. 一个验证步骤没有独立交付物，却可能避免整次任务失败；
2. 九条探索路径失败，第十条产生高价值结果，组合仍可能值得；
3. 一次复盘增加本轮成本，却可能降低未来上百次任务的干预；
4. 安全检查的价值常表现为事故没有发生，很难归因到某个 Token。

GitHub 在 Agentic Workflows 的官方文档中也把 Token 与成本视为必要信息，同时明确说它们还不够；Outcome efficiency 需要把成本与被接受的结果联系起来。[GitHub Outcomes](https://github.github.com/gh-aw/reference/outcomes/)

本课程可以使用一个核算框架：

~~~text
预期净价值
= 直接产出
+ 可复用学习
+ 避免损失
+ 未来选择空间
- Token 与算力成本
- 人工审查成本
- 延迟与机会成本
- 失败、维护和外部性成本
~~~

这里的“未来选择空间”属于课程推断：一次探索即使没有立刻变现，也可能保留未来路线。它需要后续结果验证，不能借此为所有无效消耗辩护。

因此，Token 经济学更精确的第一性原理是：

> **每一段有明确边界的智能过程，最终要证明其预期总价值能够覆盖总成本，并把风险控制在可接受范围内。**

这也说明 Token efficiency 的目标是减少无效消耗，同时守住必要证据与结果质量。GitHub 的实践同时观察 Token、调用次数与过程质量，并承认“每单位正确工作消耗多少 Token”仍需要更好的结果测量。[GitHub Blog](https://github.blog/ai-and-ml/github-copilot/improving-token-efficiency-in-github-agentic-workflows/)

若系统只奖励少用 Token，它会逐渐形成少搜索、少核验、少留证据的文化。成本应该成为约束与效率分母，不能独占最高目标。

### 最后回答：谁拥有智能方向的控制权

把今天的机制压缩成一条链：

~~~text
模型能力提供行为可能性
        ↓
Harness 配置可见世界、行动空间与制度边界
        ↓
Evaluator 和现实后果产生选择压力
        ↓
Memory／Skill 保留并压缩经验
        ↓
跨任务重复形成稳定行为倾向
        ↓
文化逐渐出现
~~~

而 Human values 与责任边界位于整条链的上方。它们回答：

- 哪种结果值得追求；
- 哪些代理指标可以采用；
- 哪些代价没有授权；
- 哪些决定必须留给人；
- 长期后果由谁承担。

Agent 可以参与提出目标、比较标准和发现冲突。最终合法性与责任仍然需要明确的人类或组织主体承接。能力越强，人的工作越集中到选择标准、冲突取舍、授权边界和结果责任。

### 把 13 篇连成一条控制权迁移线

这条课程线没有发生“新层替代旧层”。成熟系统会同时拥有这些层：

| 层级 | 它控制什么 |
|---|---|
| Prompt | 这一轮的意图 |
| Skill | 局部经验的复用 |
| Workflow | 多步执行顺序 |
| Loop | 偏差出现后的修正 |
| Harness | 智能发生的环境与权力边界 |
| Context Engine | 此刻能看见哪一块世界 |
| Curriculum | 长期依次经历什么 |
| Selection Pressure | 哪些行为更可能进入未来 |
| Culture | 跨任务稳定留下了什么倾向 |

控制权一路上移：从“怎样做一步”，走向“看见什么、经历什么、保留什么、为什么值得保留”。

这就是今天的最终收束：

> **AI Native 文化的核心证据，是系统在冲突中持续保留了什么；最高控制权，是定义选择标准、保留机制与责任边界的权力。**

### 关于 AI Native Culture Skill

今天已经形成一份概念文档，这篇就是第一版。它还没有达到 Skill 的成熟条件。

至少还缺四类证据：

1. 明确服务哪类真实任务；
2. 收集速度与事实、成本与安全、自主与授权等冲突样本；
3. 建立可观察的 Evaluator 和撤除测试；
4. 证明这些原则跨任务改善结果，同时没有制造新的僵化。

以后是否 Skill 化，不靠“感觉很牛”，拿真实任务**试试就知道了**。在证据出现前，它的状态是：**候选认知框架，尚未固化为执行规则。**

## 小结

1. 自然选择通过差异性繁殖改变特征分布；环境没有意图，也不预设进化终点。
2. Agent 的搜索、学习和人工演化需要分开；选择进入未来并产生迁移，才出现系统学习证据。
3. Harness 提供文化形成的制度环境，Evaluator 施加选择压力，Memory 与 Skill 提供保留机制，文化是长期稳定结果。
4. 强化学习中的 value function 预测累计回报；Reward、Objective、Evaluator、Human values 与 Culture 分属不同层次。
5. “能力、学习效率、适应方向”是一组三轴坐标；适应方向不能脱离人的价值判断。
6. Token 经济学应在任务、工作流或时间周期上核算预期总价值与总成本，不能要求每个 Token 独自产生直接回报。
7. 人类最后保留的核心权力包括：定义值得优化的目标、选择代理指标、设定授权边界并承担后果。
