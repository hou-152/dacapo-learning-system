# Loop Engineering

AI 工作流演化的第四阶段（Prompt → Skill → Workflow → Loop）。

## 核心定义

不再围绕一次提示词优化，而是设计一个能持续启动、执行、验证、修复的循环系统。人从操作者变成目标、验证标准和失败处理策略的设计者。

## 五个组件

1. 定时任务（心跳）
2. 工作树隔离
3. 项目知识体系
4. 连接器（MCP 等）
5. 子 Agent 分工

## 与 Skill 的关系

Loop 不会消灭 Skill，但会削弱用户手动记住 100 个文件、决定调用顺序的必要性。Skill 从用户界面的按钮，退到 Loop 在特定状态下调用的策略模块。
