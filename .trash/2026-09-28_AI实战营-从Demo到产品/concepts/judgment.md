# 判断力

## Context

> "判断力对于小龙虾来讲是一个很重要的一个形成的一个过程，就是这个时候就为什么说你要就我跟小龙虾前期一开始是一直聊了有一周的时间，每个小龙虾都是。" "通过这一周的聊天然后让他去形成他自己的一个判断力……对一个事物我是怎么看的然后从你的角度你怎么看……不断的去刺激他，去让他有自己会产生一些判断。"

## 费曼一下

针对"小龙虾无法获取现实反馈、无法形成判断"的解法。营长认为判断力是聊出来的：前期每个小龙虾连续聊一周，反复"我是这么看的，你怎么看"，再加上长期记忆和短期记忆，大量交互之后它才会慢慢形成自己的判断。判断力在这里被当成 agent 与"只会输出"之间的分水岭。
