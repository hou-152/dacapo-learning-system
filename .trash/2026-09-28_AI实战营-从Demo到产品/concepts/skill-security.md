# Skill 安全审计（供应链防御）

## Context

> "这个 skill 它是没有经过安全审核的，你安装进去，它里面就有可能有病毒……有些人想入侵你这个服务器，那他就可能在里面放一些胡七八糟的一些东西。" "本地安全尤其注意你的这个 skill……是很容易被注入一些问题的，有可能别人就会把你的数据盗走……或者说把你这个服务器当做肉机。" "需要去安装一个 security 的这个安全审计。就是每次你再去装 skill 的时候，要经过这个 skill 的安全审计之后，再去装这个 skill 是最安全的。" "如果说你的小龙虾是共享给别人的，那么你要去做好每个 SECTION……之间的这个安全一定要做好……做好隔离。"

## 费曼一下

机制边界与防御结构概念。边界：skill 是供应链入口——未审核的 skill 可能带毒、被注入，本地部署时服务器可能被当肉机；防御：装前必须过安全审计，共享小龙虾时必须做 session 之间的隔离，云端"有一些预警"、本地风险更高。没有这个概念，读者会把"随便装 skill"当成默认安全操作。
