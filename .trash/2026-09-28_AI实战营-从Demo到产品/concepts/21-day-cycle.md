# 周循环（21 天机制）

## Context

> "每个人在周一的时候需要去定一个你们自己这一周要做的一个自动化的工作流……然后周二到周六，就是你们就去把你们这个工作流给他打磨好……周六的时候，你们录好你们的一个演示视频，在周日我们会进行一个 code review。"

## 费曼一下

21 天被切成三个相同节拍的周循环：周一定方向、周二至周六打磨、周六录演示、周日评审。机制的本质是"每周必须拿出一个可被他人查看的产物"，用固定节拍把"想做的事"逼成"被看见的作品"。没有周循环，前面所有承诺都只是口号。
