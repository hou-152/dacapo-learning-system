# Skill 自进化四步（experience-log.md）

## Context

> "你可以借鉴他的这个思路去改造自己的一个 skill，在你的这个 skill 的流行流程的最后一步，加上执行完成后回顾本次的执行，然后提取可复用的经验，再写入经验库。" "第一，执行完成后，回顾本次的输入、过程、结果；第二，提取 1-2 条可复用经验，什么有效、什么无效；第三，将经验追加到 experience-log.md；第四，下次执行前，先读取 experience-log.md，根据历史经验调整策略。"

## 费曼一下

Harness 的平民版落地法——不装任何新东西，只在 SKILL.md 里加四行逻辑：回顾 → 提炼 → 写进 experience-log.md → 下次先读。营长明说这就是 Harness 六步里的「反思改进 + 知识沉淀」两步。这个概念的价值在于把「自进化」从一个听起来很玄的框架，降维成任何一个学员当晚就能改的 skill 补丁，是全课最可执行的一条指令。
