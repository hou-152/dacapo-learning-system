# 养小龙虾（原生 vs 预装）

## Context

> "小龙虾的关键点是在于养。" "就好像你拿到了一个……你你开的一个原厂车和各种各样的改装这个车……你拿的一个就是原厂车，你可以随意去改，改成各种各样都行，它的核心点就是在于养养到后面，你可以养出自己的这种机制。" "你不可能拿着 workbody 去交付……你更多的是拿你自己这种原生的这种 open cloud 去交付。"

## 费曼一下

营长最核心的方法论隐喻。「养」的对立面是「预装」：一出生就聪明的小龙虾，等于内置好了各种规则和厂商机制，你反而不知道怎么用它做自己的事；原生小龙虾像原厂车，想改成什么样都行，养的过程本身就是价值——你会被迫思考怎么进化、交付时能用哪些方案。这个概念还带一条商业底线：真正交付时不能拿 WorkBuddy 或大厂 cloud 充数，必须用自己原生 OpenClaw 搭出来的东西，「老板我给你装个 WorkBuddy 收你一万块」是行不通的。
