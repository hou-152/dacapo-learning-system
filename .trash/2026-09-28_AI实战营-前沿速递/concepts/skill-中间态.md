# Skill 的中间态（与工程化思维）

## Context

> "skill 它其实有点类似于插件的这种感觉。它虽然是中间带，但是它会存在一段时间，而且 skill 它最重要的不是你做出来这个 skill，而是你在不断做 skill 的过程当中，你不断产生的工程化的思维，还有一种你的整个思路的一个进化。" "就 skill 它就，替代掉了软件中的某个功能，那么你就不需要说我再去用 web coding 的形式去做一堆代码……它是你做交付过程当中的一环。"

## 费曼一下

学员担心「模型能力增长后，skill 会变成副作用、只是中间态」。营长接受「中间态」的判断，但把价值从产物挪到了过程：做 skill 练出的是工程化思维，这种思维不会因为 skill 过时而作废——就像拖拽式工作流变成了各种工作流，「都有以前的影子」。同时 skill 有当下的实用价值：交付时用它替代软件的某个功能，省掉写代码的成本（5000 块的活儿，skill 比 vibe coding 成本低得多）。这个概念是整个课程的开场锚点：工具会换代，做工具的过程中长出的思维不过时。
