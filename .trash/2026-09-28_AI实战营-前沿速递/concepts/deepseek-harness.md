# DeepSeek Harness（agent = model + harness）

## Context

> "就先讲一下这个 deepseek harness 这个公式，它就是 agent 等于 model 加 harness。" "他把整个 a 卷的完整的一个生生命周期变成了需求，理解到任务拆解到工具调用到结果评估，再到反思改进，再到知识沉淀，就等于说放在以前你的小龙虾做完一件事情，下一次做同样的事情还得从头再来。" "它不再是在屎山上堆屎山，他每次修改都可以有干净的依赖管理。"

## 费曼一下

营长介绍的自进化框架，一句话公式：agent = model + harness。模型只负责理解和生成，「怎么做事情」这件事本身被 harness 系统化——需求理解、任务拆解、工具调用、结果评估、反思改进、知识沉淀六步闭环。它的意义是对比出来的：没有它，小龙虾每次做同样的事都要从头再来；有了它，做完自动复盘、存经验、下次自动用。配套口号「一切皆插件」：模型、工具、技能、会话、沙箱全部可插拔，agent 可以自己修改自己的 harness，摆脱「屎山堆屎山」。
