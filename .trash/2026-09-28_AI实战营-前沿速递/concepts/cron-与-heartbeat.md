# cron 与 heartbeat

## Context

> "把所有的这个 crown 就是它的 crown 有个好处，它不会受到上下文的一个干扰。" "这个就是 crown crown 它就是能帮你去自进化。" "主要是它的 HEARTBEAT.md……当前的核心是 C file 的比赛状态的一个监控……周末休市的时候基本上就是回一个 heartbeat OK，防止它关机了。"

## 费曼一下

金融小龙虾自动化的一对机制。cron（定时任务）是金融能力的真正所在：盘前复盘、盘前研究、开盘执行、铁律收尾、晚间复盘——每一场比赛都有一排 cron，它不受上下文干扰，而且覆盖「今天 + 明天」的任务，第二天按第一天的复盘再定计划，所以「cron 就是能帮你去自进化」。heartbeat（心跳）是另一种机制：HEARTBEAT.md 负责监控比赛有没有执行、周末休市回一个 heartbeat OK，防止实例被云厂商关掉、防止宕机后要人为重启。两者分工：cron 管「该做的事」，heartbeat 管「别死掉」。
