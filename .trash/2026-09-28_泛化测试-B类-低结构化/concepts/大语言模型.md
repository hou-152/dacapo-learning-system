# 大语言模型（LLM）

## 定义

大语言模型（Large Language Model, LLM）是一种基于深度学习的 AI 模型，通过在海量文本数据上训练，学会理解和生成人类语言。代表性模型包括 ChatGPT（GPT-4）、Claude、Llama 等。

大语言模型带来了革命性的交互方式，用户可以用自然语言与 AI 对话，而不需要学习特定的命令或语法。

## 为什么重要

1. **自然交互**：用户用日常语言提问，无需学习技术术语
2. **通用能力**：可以处理多种任务（问答、写作、编程、翻译等）
3. **上下文理解**：能理解多轮对话，保持上下文连贯性
4. **快速迭代**：模型能力持续提升，应用场景不断扩展

## 前置概念

无

## 类型

- **闭源模型**：GPT-4、Claude 等，通过 API 调用
- **开源模型**：Llama、Qwen 等，可以自己部署和微调
