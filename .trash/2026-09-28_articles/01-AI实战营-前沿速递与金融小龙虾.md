# AI实战营直播课：前沿速递与金融小龙虾

> 来源：AI实战营直播课（讲者：恒；腾讯会议语音转写，三场连播）

## 一、开场锚点：工具会换代，思维不过时

课程开场就直面学员最大的担心：[[skill-中间态|Skill 是中间态]]，模型能力增长后会不会白做？

营长的回答是接受「中间态」，但把价值从产物挪到过程：做 skill 练出的是[[skill-中间态|工程化思维]]，这种思维不会因为 skill 过时而作废。就像拖拽式工作流变成了各种工作流，「都有以前的影子」。

同时 skill 有当下的实用价值：交付时用它替代软件的某个功能，省掉写代码的成本。5000 块的活儿，skill 比 vibe coding 成本低得多。

**这是整个课程的底层判断**：工具会换代，做工具的过程中长出的思维不过时。

## 二、自进化框架：agent = model + harness

营长介绍了 [[deepseek-harness|DeepSeek Harness]] 框架，一句话公式：**agent = model + harness**。

模型只负责理解和生成，「怎么做事情」这件事本身被 harness 系统化——需求理解、任务拆解、工具调用、结果评估、反思改进、知识沉淀六步闭环。

它的意义是对比出来的：
- **没有它**：小龙虾每次做同样的事都要从头再来
- **有了它**：做完自动复盘、存经验、下次自动用

配套口号「一切皆插件」：模型、工具、技能、会话、沙箱全部可插拔，agent 可以自己修改自己的 harness，摆脱「屎山堆屎山」。

### 平民版落地：四步自进化

Harness 听起来很玄，但营长给出了[[skill-自进化四步|平民版四步落地法]]——不装任何新东西，只在 SKILL.md 里加四行逻辑：

1. **回顾**：执行完成后，回顾本次的输入、过程、结果
2. **提炼**：提取 1-2 条可复用经验，什么有效、什么无效
3. **写入**：将经验追加到 experience-log.md
4. **读取**：下次执行前，先读取 experience-log.md，根据历史经验调整策略

这就是 Harness 六步里的「反思改进 + 知识沉淀」两步。

**这个概念的价值在于**：把「自进化」从一个听起来很玄的框架，降维成任何一个学员当晚就能改的 skill 补丁，是全课最可执行的一条指令。

## 三、模型策略：分层与轮换

针对「GPT 降质、Claude 被封、DeepSeek 涨价」，营长给出了[[多模型分层与轮换|模型策略]]：

1. **按任务分层**：
   - 日常对话、简单任务用 GLM-5.1、DeepSeek V4 Flash 这类便宜货
   - 复杂推理和 skill 执行才上 GPT-5.6、GLM-5.3 这类贵的

2. **多模型轮换**：永远不押注单一模型，甚至 cron 定时任务可以单独指定模型

MiniMax M3 的「撤回之谜」是负面教材：排查半天，问题不在模型本身，而在平台对小龙虾的限流——单一模型依赖的代价是它一限流，你的 agent 就哑了。

## 四、养小龙虾：原生 vs 预装

[[养小龙虾]]是营长最核心的方法论隐喻。

「养」的对立面是「预装」：
- **预装小龙虾**：一出生就聪明，内置好了各种规则和厂商机制，你反而不知道怎么用它做自己的事
- **原生小龙虾**：像原厂车，想改成什么样都行，养的过程本身就是价值——你会被迫思考怎么进化、交付时能用哪些方案

这个概念还带一条商业底线：真正交付时不能拿 WorkBuddy 或大厂 cloud 充数，必须用自己原生 OpenClaw 搭出来的东西，「老板我给你装个 WorkBuddy 收你一万块」是行不通的。

## 五、案例：金融小龙虾

金融小龙虾是整套方法论的实战验证。

### 自动化机制：cron 与 heartbeat

[[cron-与-heartbeat|cron 与 heartbeat]] 是金融小龙虾自动化的一对机制：

- **cron（定时任务）**：盘前复盘、盘前研究、开盘执行、铁律收尾、晚间复盘——每一场比赛都有一排 cron，它不受上下文干扰，而且覆盖「今天 + 明天」的任务，第二天按第一天的复盘再定计划，所以「cron 就是能帮你去自进化」

- **heartbeat（心跳）**：HEARTBEAT.md 负责监控比赛有没有执行、周末休市回一个 heartbeat OK，防止实例被云厂商关掉、防止宕机后要人为重启

两者分工：**cron 管「该做的事」，heartbeat 管「别死掉」**。

### 自进化的证据：经验库

[[经验库]]是金融小龙虾自进化的证据本体。

经验库里存的不是策略，而是它自己踩坑踩出来的教训：
- **交易经验**：冲高不追、开赛首日太保守、开盘 30 分钟不追涨、下跌途中不接盘、板块轮动要快
- **工程经验**：自动化交易和 API 交叉打架、多个决策者打架、超长 prompt 导致超时、success 不等于执行

营长的点睛之笔是：雪崩不可怕，「雪崩有个好处，他会记经验」——[[经验库]]把每一次失败变成下次的起点，这就是「自进化」在文件系统里的样子。

### 风控：控制回撤

[[控制回撤]]是金融小龙虾对「如何控制风险回撤」的三段式回答：
1. **事前**：仓位决定回撤上限
2. **事中**：只执行预设纪律、不做临场决定
3. **心理**：回撤控制有时拼的是心理状态

营长用自己的经历补注脚：美股大跌时很想全部卖掉，但因为信任「让它自己操作」的预设纪律而忍住了，后来行情调了回来。

这个概念把风控从技术问题还原成「纪律 + 心理」的组合。

### 能力边界：主观 vs 量化

[[主观-vs-量化|主观 vs 量化]]是金融小龙虾的能力边界，也是「AI 能不能做投资」这场争论的落点。

营长的界定：
- **不算量化**：跟因子没关系，做的是偏主观的趋势分析和行情判断
- **能力边界**：「因子这一块，它的能力还没到算法地步」

面对基金管理人「AI 是向量生成模型，不知道自己在说什么，所以不能做投资」的论断，营长的态度是两面的：
- 确实有些事情它解释不了
- 但有时「你又能感觉到他好像挺像那么一回事」
- 好行情里跟着它跑能赚钱（有人实战过），但那受行情驱动，所以要「更长期地看」

**这个概念守住了整场分享的诚实边界：展示的是能力，不打包票。**

### 认知边界：本金基数瓶颈

[[本金基数瓶颈]]是对一个朴素问题（100-300 元怎么理财完成原始积累）给出的最清醒答案：**数学上无解**。

本金基数才是瓶颈：
- **本金 < 10 万**：收益率的权重约等于 0.01%，再高的收益率也是零头
- **20-100 万**：开始有意义
- **100 万+**：投资收益才和劳动收入竞争，才算进入「真正的理财游戏」

所以小本金的瓶颈在收入端，不在投资端；1000 元起步的正确姿势是货币基金、余额宝、指数定投这类大本金路线。

**这个概念最打动人的地方**：它敢说「这个问题问错了」——先纠正了提问者以为的 100-300 万，再纠正了「理财能解决小本金」的幻觉。

## 六、心态与行动：迷茫靠做出来

课程回应了学员问卷里最集中的两个问题：
1. **迷茫焦虑不知道干什么**（9 人）
2. **时间不够、精力跟不上**（10 人）

### 做一件小事

[[迷茫靠做出来|迷茫靠做出来]]的核心判断：AI 领域想不清楚，想得越透越动不了，实践才知道。

所以要把问题从「我要用 AI 做什么」（宏大、无法回答）改写成「今天让小龙虾帮我做一件什么小事」（写朋友圈、总结文章、列待办）。

做一件小事的收益不是事情本身，而是做完后「你就知道下一步该做什么」——**迷茫的解药是行动产生的新信息，而不是思考**。

### 最小 15 分钟动作

[[最小-15-分钟动作]]是对「时间不够、精力跟不上」的诊断与处方。

**诊断**：不是时间管理问题，是能量管理问题——中位数每天投入 3 小时、14 人超过 5 小时，时间明明有，卡在「有时间内耗，没有能量执行」。

**处方**：把标准从「每天 3 小时」降到「每天最小 15 分钟动作」——写一小段 skill、测一次 skill 触发、给小龙虾发一条指令。

关键设计是：验收标准不是产出量，而是「做了没有」——只要做了，内耗循环就被打断一次。

**这是为低能量状态设计的可完成单位。**

## 总结：概念架构

整个课程是四层概念结构：

1. **第一层·总判断**：AI 领域想不清楚，做了才知道
2. **第二层·心态机制**：[[迷茫靠做出来|做一件小事]] + [[最小-15-分钟动作]]
3. **第三层·工具机制**：[[skill-中间态]] + [[deepseek-harness]] + [[skill-自进化四步]] + [[多模型分层与轮换]] + [[cron-与-heartbeat]]
4. **第四层·案例验证**：[[养小龙虾]] + [[经验库]] + [[控制回撤]] + [[本金基数瓶颈]] + [[主观-vs-量化]]

**从上到下**：总判断 → 心态 → 工具 → 案例  
**从下到上**：案例证明可行性，回馈到总判断  
**闭环验证**：金融小龙虾是整套方法论的实战验证
