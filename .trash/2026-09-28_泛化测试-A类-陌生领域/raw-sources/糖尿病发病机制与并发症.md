# 糖尿病的发病机制与并发症

## 引言

糖尿病（Diabetes Mellitus, DM）是一组以慢性高血糖为特征的代谢性疾病，由胰岛素分泌缺陷和/或胰岛素作用障碍引起。根据世界卫生组织（WHO）统计，全球糖尿病患者人数已超过 4.2 亿，预计到 2045 年将达到 6.9 亿。糖尿病不仅影响患者的生活质量，其慢性并发症更是导致心血管疾病、肾衰竭、失明和截肢的主要原因。理解糖尿病的发病机制对于预防和治疗至关重要。

## 1. 糖代谢的生理基础

### 1.1 胰岛素的作用机制

胰岛素是由胰腺β细胞分泌的肽类激素，是体内唯一能够降低血糖的激素。其作用机制包括：

1. **促进葡萄糖摄取**：胰岛素与靶细胞（肌肉、脂肪组织）表面的胰岛素受体结合，激活细胞内信号通路，促使葡萄糖转运蛋白 4（GLUT4）从细胞内转位到细胞膜，增加葡萄糖摄取。

2. **促进糖原合成**：在肝脏和肌肉中，胰岛素激活糖原合成酶，促进葡萄糖转化为糖原储存。

3. **抑制糖异生**：胰岛素抑制肝脏中的糖异生途径，减少肝脏葡萄糖输出。

4. **促进脂肪合成**：胰岛素促进脂肪酸合成，抑制脂肪分解。

### 1.2 血糖稳态调节

正常情况下，血糖水平维持在相对恒定的范围（空腹 3.9-6.1 mmol/L）。这种稳态由多种激素共同调节：

- **降糖激素**：胰岛素（唯一）
- **升糖激素**：胰高血糖素、肾上腺素、皮质醇、生长激素

进食后，血糖升高刺激胰岛β细胞分泌胰岛素，促进组织摄取和利用葡萄糖；空腹或运动时，血糖下降刺激α细胞分泌胰高血糖素，促进肝糖原分解和糖异生。

## 2. 糖尿病的分类与发病机制

### 2.1 1型糖尿病（T1DM）

1型糖尿病是由自身免疫介导的胰岛β细胞破坏，导致胰岛素绝对缺乏。

**发病机制**：

1. **遗传易感性**：特定 HLA 基因型（如 HLA-DR3、DR4）增加患病风险。

2. **自身免疫攻击**：T淋巴细胞识别β细胞抗原（如胰岛素、GAD65），启动免疫应答，产生针对β细胞的自身抗体（如 IAA、GADA、IA-2A）。

3. **β细胞凋亡**：细胞毒性T细胞和炎性细胞因子（IL-1β、TNF-α、IFN-γ）诱导β细胞凋亡，当 80-90% β细胞被破坏时，出现临床症状。

4. **环境触发因素**：病毒感染（如柯萨奇病毒B4）、肠道微生物失调等可能触发易感个体的自身免疫反应。

### 2.2 2型糖尿病（T2DM）

2型糖尿病占所有糖尿病的 90-95%，主要由胰岛素抵抗和β细胞功能逐渐衰竭引起。

**发病机制**：

1. **胰岛素抵抗**：靶组织对胰岛素的敏感性下降，主要机制包括：
   - **受体后缺陷**：胰岛素受体底物（IRS）磷酸化异常，PI3K/Akt 信号通路受损
   - **脂毒性**：游离脂肪酸（FFA）积累抑制胰岛素信号传导
   - **炎症因子**：肥胖相关的慢性低度炎症，脂肪组织分泌 TNF-α、IL-6 等炎症因子
   - **线粒体功能障碍**：氧化磷酸化效率降低，活性氧（ROS）增多

2. **β细胞功能衰竭**：
   - **代偿期**：初期β细胞通过增加胰岛素分泌量来代偿胰岛素抵抗
   - **失代偿期**：长期高血糖导致β细胞凋亡，细胞数量减少
   - **糖毒性**：慢性高血糖抑制胰岛素基因表达，下调 PDX-1 等转录因子
   - **淀粉样蛋白沉积**：胰淀粉样多肽（IAPP）在胰岛中沉积，导致β细胞损伤

3. **遗传因素**：多基因遗传病，已发现超过 400 个易感基因位点（如 TCF7L2、PPARG、KCNJ11）。

4. **环境因素**：肥胖（尤其是中心性肥胖）、缺乏运动、高热量饮食、衰老等。

### 2.3 其他类型

- **妊娠糖尿病（GDM）**：妊娠期首次发现的糖代谢异常
- **单基因糖尿病**：如青少年成人型糖尿病（MODY）、线粒体糖尿病
- **继发性糖尿病**：胰腺疾病、内分泌疾病、药物诱导等

## 3. 糖尿病的慢性并发症

慢性高血糖导致的代谢紊乱是糖尿病并发症的病理基础。

### 3.1 微血管并发症

**糖尿病肾病（Diabetic Nephropathy, DN）**：

- **发病机制**：
  - 肾小球高滤过、高灌注
  - 晚期糖基化终末产物（AGEs）积累，与受体（RAGE）结合，激活氧化应激和炎症
  - 系膜细胞增殖，细胞外基质（ECM）过度沉积
  - 足细胞损伤，基底膜增厚
  
- **病理分期**：
  1. 肾小球高滤过期（GFR 增加）
  2. 微量白蛋白尿期（30-300 mg/24h）
  3. 大量白蛋白尿期（>300 mg/24h）
  4. 肾功能不全期
  5. 终末期肾病（需透析或移植）

**糖尿病视网膜病变（Diabetic Retinopathy, DR）**：

- **发病机制**：
  - 视网膜毛细血管基底膜增厚
  - 周细胞凋亡，血管渗漏
  - 视网膜缺氧诱导血管内皮生长因子（VEGF）表达
  - 新生血管形成（增殖期）
  
- **临床分期**：
  - 非增殖期（微血管瘤、出血、硬性渗出）
  - 增殖期（新生血管、玻璃体积血、牵拉性视网膜脱离）

**糖尿病神经病变（Diabetic Neuropathy, DNP）**：

- **发病机制**：
  - 多元醇通路激活：葡萄糖经醛糖还原酶转化为山梨醇积累，导致神经细胞渗透压失衡
  - 神经营养血管病变，神经缺血缺氧
  - 氧化应激损伤髓鞘和轴突
  - 神经生长因子（NGF）减少
  
- **临床类型**：
  - 远端对称性多发神经病变（最常见）
  - 自主神经病变（心血管、胃肠、泌尿生殖系统）
  - 单神经病变

### 3.2 大血管并发症

**动脉粥样硬化**：

糖尿病患者发生心肌梗死、脑卒中和外周动脉疾病的风险显著增加（2-4倍）。

- **发病机制**：
  - 内皮功能障碍：高血糖和胰岛素抵抗降低一氧化氮（NO）生物利用度
  - 脂质代谢紊乱：甘油三酯升高，HDL-C 降低，小而密的 LDL-C 增多（易氧化）
  - 血管炎症：单核细胞浸润，泡沫细胞形成
  - 血小板功能亢进：凝血倾向增加
  - AGEs 促进动脉粥样硬化斑块形成

## 4. 糖尿病并发症的共同病理机制

### 4.1 晚期糖基化终末产物（AGEs）通路

葡萄糖与蛋白质、脂质、核酸的氨基发生非酶糖化反应，形成 AGEs。AGEs 通过以下机制致病：

1. 交联胶原蛋白，改变组织结构（如血管壁僵硬）
2. 与 RAGE 结合，激活 NF-κB，诱导炎症反应和氧化应激
3. 捕获脂蛋白，促进动脉粥样硬化

### 4.2 氧化应激

高血糖增加线粒体 ROS 生成，超过抗氧化防御能力，导致：

1. 脂质过氧化，破坏细胞膜
2. DNA 损伤，激活 PARP，消耗 NAD+ 和 ATP
3. 蛋白质氧化修饰，功能异常

### 4.3 多元醇通路

高血糖时，醛糖还原酶活性增强，将葡萄糖转化为山梨醇，消耗 NADPH（抗氧化所需），山梨醇积累导致细胞渗透压升高和功能障碍。

### 4.4 蛋白激酶C（PKC）通路

高血糖激活 PKC，导致：

1. 血管通透性增加
2. 血管内皮功能障碍
3. 基底膜增厚
4. 细胞因子和生长因子表达异常

### 4.5 己糖胺通路

葡萄糖-6-磷酸进入己糖胺途径，生成 UDP-N-乙酰葡萄糖胺，引起蛋白质 O-糖基化异常，影响基因表达和细胞功能。

## 5. 治疗策略

### 5.1 控制血糖

**T1DM**：
- 外源胰岛素替代治疗（多次皮下注射或胰岛素泵）
- 血糖监测（自我血糖监测或连续血糖监测）

**T2DM**：
- 生活方式干预：饮食控制、增加运动、减重
- 口服降糖药：
  - 二甲双胍（减少肝糖输出，改善胰岛素抵抗）
  - 磺脲类（促进胰岛素分泌）
  - DPP-4 抑制剂（延长 GLP-1 半衰期）
  - SGLT2 抑制剂（促进尿糖排泄）
- 注射制剂：GLP-1 受体激动剂、胰岛素

### 5.2 并发症防治

- **肾病**：ACE 抑制剂/ARB（降低尿蛋白，延缓肾功能下降）
- **视网膜病变**：激光光凝、抗 VEGF 治疗、玻璃体切除术
- **神经病变**：控制血糖、止痛治疗（加巴喷丁、度洛西汀）、改善循环
- **心血管疾病**：降压、调脂（他汀类）、抗血小板（阿司匹林）

### 5.3 新兴治疗

- **胰岛移植**：同种异体胰岛移植，恢复胰岛素分泌
- **干细胞治疗**：诱导多能干细胞分化为β细胞
- **基因治疗**：基因编辑技术修复致病基因
- **闭环胰岛素输注系统**："人工胰腺"，自动调节胰岛素输注

## 6. 结论

糖尿病是一种复杂的代谢性疾病，涉及遗传、环境、免疫等多方面因素。其核心病理是胰岛素分泌不足和/或胰岛素作用障碍导致的高血糖，进而通过 AGEs、氧化应激、多元醇通路等机制引起全身多器官并发症。

深入理解糖尿病的发病机制对于开发新的治疗策略至关重要。目前治疗的核心是早期诊断、严格控制血糖、综合管理心血管危险因素，以延缓或预防并发症的发生发展。随着精准医学和再生医学的发展，未来有望实现糖尿病的个体化治疗甚至治愈。
