# 逻辑编排

## 定义

逻辑编排是为多个 AI agent 设计清晰的任务分工、约束规则和上下文传递机制的方法。

## context

> 你们要做的是一份逻辑编排工程字典。你自己要设定 30 个 agent，每个 agent 做什么事情，A agent 做什么，B agent 做什么。你要给它们写说明文档，每个 agent 之间怎么相互约束，怎么传递上下文，这个之间怎么传递上下文。

与 dynamic workflow 的对比：

> Dynamic workflow 解决了很多逻辑编排和工程治理相关的东西，但它可能依然解决不了这个问题。

错误做法：

> 你只是跟 Claude Code 说一句话："帮我派 30 个 agent 去做这件事"吗？那样它一定做不好。你凭什么会有这样的期待？

## 费曼一下

逻辑编排不是对 AI 说"帮我派 30 个 agent"，而是**人工设计**每个 agent 的：
- 职责边界（做什么、不做什么）
- 输入输出格式
- 与其他 agent 的依赖关系
- 上下文传递规则
- 相互约束机制

它需要"工程字典"级别的文档，类似写代码前的架构设计。目标是让 AI 能够自主运行几十个小时，仍然保持 99% 的目标达成率。

这是从"玩具"走向真实系统的关键能力之一。
